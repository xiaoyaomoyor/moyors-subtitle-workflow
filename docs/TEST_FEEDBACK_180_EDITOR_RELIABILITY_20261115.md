## 验证过程

- 先在旧实现执行新增主／副字幕取消用例，两项均按预期失败：正文恢复，但 redo 从 1 变成 0，确认测试覆盖真实缺陷。
- 修复后历史组 7 项通过（44.1 秒）：主副字幕取消后可重做／再次撤销，绑定和字幕数据不变；无输入取消不改变历史，正常提交仍清空旧 redo；历史满 100 条时取消不会丢掉最早记录。
- 光标回归先在旧实现执行，主副字幕两项均在新输入后被旧回调覆盖选区，按预期失败。修复后的首轮组合 12 通过、3 失败：新输入／按键／指针／IME 和会话身份检查已通过；三处是新夹具未选中主字幕面板、以及错误地将纯 blur 当作行内提交。补上选择并使用真实外部点击提交，保持光标／正文断言不变后复测。
- 最终组合浏览器 16 项全部通过（约 1.1 分钟）：新增 15 项加既有剧本保存重开 1 项；通过真实 `server-editor/serve.py --blank`／本机工程服务装配，使用 v4 多轨。快速输入竞态用延后回调的合成事件固定时序，正常双击／输入／外部点击提交使用真实浏览器操作；不声称完成真实系统输入法的所有交互测试。
- Node 首轮 345 通过、4 失败，失败均发生在 XML 校验辅助进程调用 uv 时，执行环境拒绝写入 uv 缓存；显式选择现有 `.venv` Python 后 349 项全部通过，不改断言和产品代码。Python 页面装配契约 19 项通过，JavaScript 语法检查通过。
