# 可选环境配置清单

不需要一次安装所有环境。先选择要用的功能，再配置对应项；标准版和 lite 的主要区别是是否携带 FFmpeg，不是功能授权。

| 功能 | 用户需要准备 | 配置入口 | 随主程序分发 |
| --- | --- | --- | --- |
| 字幕编辑／SRT、ASS 等导出 | 无模型、无 Key | 编辑器 | 是 |
| 波形、媒体转换、音频／视频导出、压制字幕 | FFmpeg + ffprobe | 启动器配置中的 FFmpeg 路径 | 标准版有；lite 自备 |
| 云端 ASR | 对应服务的 API Key／账户，网络 | 启动器的识别方式与连接配置 | 客户端有；额度和 Key 无 |
| LLM 字幕翻译／后处理 | LLM 地址、模型、Key，网络 | 编辑器「环境配置 → LLM」或启动器 LLM 配置，两者共用 | 客户端有；服务无 |
| 百炼 Qwen TTS | 百炼 Key、对应地域／模型／音色，网络 | 编辑器「环境配置 → TTS → 百炼」 | 客户端有；模型在云端 |
| 油库里 | 独立 MSW 油库里资源包，含固定 Node、WASM、音色与读音规则 | 编辑器「环境配置 → TTS → 油库里资源」安装或指定目录 | 不随主程序分发；安装后离线可用 |
| IndexTTS 2.5 | 自行安装 IndexTTS、模型权重，并启动兼容的本机 WebUI 服务 | 编辑器「环境配置 → TTS → IndexTTS」填写服务地址并检测 | 仅接入客户端；服务和权重不打包 |
| 实验性本地 Qwen3-ASR／FunASR／Faster-Whisper | 独立 Python 环境、对应依赖和模型；加速能力取决于平台 | 启动器本地模型管理或 CLI，依实际引擎入口 | 不随主程序分发 |
| 启动器 OCR 字幕去重 | 托管 OCR Python 环境、RapidOCR / ONNX 模型 | 启动器后处理工具箱的 OCR 配置 | 不随主程序分发，首次使用独立准备 |
| 实验性 MOSS 音效／音乐生成 | 独立托管运行时与模型，依已有功能要求配置硬件 | 启动器工具箱相关配置 | 不随主程序分发，不属于本轮 TTS 三引擎 |

## 三类 TTS 的区别

- **百炼云端**：本机只负责发请求与保存结果；CPU／GPU 推理由服务商管理。CustomVoice 用系统音色，VoiceDesign / VoiceClone 用对应模型的自定义音色。已有 ASR 百炼 Key 可按当前配置规则复用，但仍需模型权限和可用额度。
- **油库里本地资源**：程序下载经过摘要校验的固定资源，不要求用户安装系统 Node。也可生成同平台离线资源 ZIP；不同操作系统／架构资源不可混用。获取方法和许可见[油库里文档](EDITOR_YUKKURI.md)。
- **IndexTTS 本机服务**：MSW 调用已经运行的 IndexTTS，不为它自动安装、更新或改变 CPU／GPU 模式。参考音频、模型与显存要求以 IndexTTS 自身为准，见[接入说明](EDITOR_INDEXTTS.md)。

生成结果保存为音频后，播放、贴片与导出通常不再需要原 TTS 引擎；仍需保留音频文件，媒体转换／混音可能需要 FFmpeg。

## 数据与迁移

API Key、服务连接、音色登记、参考音频和可选运行时位于本机配置／应用数据目录；浏览器还保存主题、布局等偏好。`.mosp` 保存字幕和 MSW 扩展，收集的音频在工程旁边的 `.assets` 目录；工程不携带 Key 或模型权重。

精确保存边界见[工程保存与恢复](EDITOR_PERSISTENCE.md)。发布包不能包含开发者 `.env`、本机配置、任务数据库、参考音频、模型缓存或个人项目。排错时提供去除敏感信息的错误报告，无需提供 Key。
