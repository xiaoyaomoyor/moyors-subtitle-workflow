连接测试在后端暂存已验证的连接参数，页面操作仍有效时才提交该次测试。离开连接设置、取消步骤、切换供应商和编辑连接参数都会停止应用迟到结果。旧的模型列表请求使用相同上下文限制。无需输入 Key 的本地连接可正常验证并启用对应步骤。

Python 首次运行有两项本机 Server 探针回连失败。设置回环不走代理并在可访问该测试服务的环境中重跑后通过。浏览器用于验证流程与时序，测试只使用模拟供应商响应和合成凭据。

Windows PATH 回退按 `ffmpeg.exe` 和 `ffprobe.exe` 的完整文件名分别查找，保留显式设置、随包工具及已有目录优先级。覆盖优先存在 `.py` 和 `.exe.py` 抢占候选的工作目录，以及完全没有二进制文件的情况。使用现有正式发行包的 FFmpeg 和 FFprobe 8.1.2，确认二者均可在相同 PATH 条件下选中并运行。
