# GPT-SoVITS 配音

在“全局设置 → 环境配置 → TTS 环境”选择 GPT-SoVITS。本机安装、模型训练仍由原工具负责，MSW 接入官方 `api_v2.py`；不安装模型、不修改原工具配置。

## 首次使用

1. 选择安装位置并保存，可使用“启动服务”，也可稍后在 TTS 面板“启动并合成”。仅保存或打开窗口不会加载模型。
2. 点击“扫描本机模型”。只扫描安装目录内已知 GPT／SoVITS 权重文件夹和预训练目录，不扫描硬盘。可分别选择两个权重；缺失或变动的模型需重新扫描。
3. 上传参考音频。主参考需 3–10 秒，支持试听、按秒裁切并保存副本，原参考保留。参考存入本机库，不改动源文件。
4. 在 TTS 面板选择模型组合、参考、生成语言、参考语言，填写参考音频的真实文字。日语参考→中文：参考语言选日语，生成语言选中文。
5. 按需设置语速与断句，保存合成设置，或在环境区存为本机配音预设。载入预设后仍可修改本次参数。

“不使用参考文字”仍要求主参考音频；V3/V4 不支持省略文字。高级项折叠收纳辅助参考（最多 8 条）、Top K/P、温度、随机种子和重复惩罚；仅 V3/V4 显示采样步数，只有 V3 显示超采样。辅助参考用于音色参考，不是多人对话。

每段最多 600 字符，可利用字幕编辑器现有分段设置处理长文。主字幕、副字幕、独立草稿沿用原 TTS 操作对象；结果进入素材库，可以放入时间轴、下载，以及按生成时的配方重新生成或替换贴片。

## 服务与资源

- 本机地址仅支持 loopback HTTP；官方默认端口为 9880。已由外部启动的兼容服务可以连接，MSW 不停止其进程。
- MSW 的模型切换与推理按服务串行，跨编辑器实例使用本机文件锁。每条开始前重新设置两个权重，任一步失败都不进入推理。外部 GUI/API 客户端不受该锁控制，配音期间请勿从外部切换同一个服务的模型。
- 取消不会全局重启或停止模型服务。API 推理可能继续到本条结束，MSW 保持串行锁并丢弃迟到输出，不写入素材。连接意外中断后，等待服务完成并重新检测，再重试；不自动重复生成。
- 模型登记、参考和预设在应用数据目录的 `gpt-sovits/` 中；工程仅保存模型标识和参考摘要等配方，不保存安装目录或原始参考字节。跨电脑重生成需准备相同模型与参考；已有生成 WAV 随工程素材保存。
- 已实测当前 V2Pro 安装包的日语与日跨中；其他已安装模型会按版本显示参数，实际语言、模型配对与资源完整性仍由 API 校验。当前未对每个模型族做真实推理或音质验收。

启动、停止与日志详见 [本机 TTS 服务](EDITOR_TTS_LOCAL_SERVICES.md)。
