启动器是可选的预处理入口；编辑器内已能直接导入媒体、生成波形、发起 ASR、翻译与 TTS。

  1. 首页点「启动 Server 版字幕编辑器」（无工程时为空白编辑器）
    2. 
              
  2. 编辑器内拖入媒体并生成波形
    3. 
              
  3. 选区或整段发起 ASR
    4. 
              
  4. 保存为 .mosp 工程
    5.

  3. 生成字幕和工程
    4. 
              
  4. 打开编辑器继续精修
    5.

    4.

常见问题

          

            
            
在「更多设置 → 运行环境」中检测并设置 FFmpeg 路径；视频转音频依赖它。

          

          

            
            
密钥只保存在本机环境文件；方案与页面不包含密钥，界面仅显示遮罩与「已配置」。

          

          

            
            
工程与 .assets 目录保持相对位置整体搬移；缺失媒体由编辑器打开时提示重新定位。

          

          

            
            
使用停止按钮取消本次任务；云端响应未知时界面提供确认／检查入口，不会自动重新付费执行。

字幕切句

              

                

                  
                  
                  

                

                

                  
                  
                  

                

                

                  
                  
                  

                

              

              
字符型设置和停顿设置留空使用默认值（最大字数：18、短句合并阈值：5、停顿切句：800ms）；系统会按语言/文本自动选择字符型或单词型规则。

断句与标点

            
文稿匹配与转写后处理共用这里的断句与保留符号。

            

              
              
              
每行一个符号；逗号、句号、问号、感叹号和换行默认生效，同时对转写后处理的句尾剥除生效。

            

            

              
              
              

              
断句后仍将符号保留在字幕末尾；转写输出的这些尾部符号同样保留，其余默认剥除逗号和句号。
