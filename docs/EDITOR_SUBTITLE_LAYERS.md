# 统一多层字幕

MSWE 可以直接编辑同一时刻出现的多条字幕。例如两人同时说话、台词与画面注释、两组重叠双语，都使用普通字幕块，不再需要转换成 V叠。

## 编辑与选择

- 字幕仍分主／副角色。显示层自动计算，不是新轨道，也不是说话人身份；字幕层数不限三层。主副绑定继续使用原有卡片。
- 创建、粘贴、素材回插到已有字幕时间内，会正常增加显示层。关闭「允许字幕重叠」只限制新编辑，不删除已有重叠。
- 拖动和跨行移动只影响所选对象及明确绑定的译文。共享边界必须是同一角色、同一显示层的两端手柄同时高亮。
- 播放时所有命中字幕反馈播放头色；字幕编辑器仍编辑明确选择的那一条，跟随列表只取一个稳定锚点。
- 旧工程隐藏的叠加组仍隐藏，在字幕列表设置中可以重新显示。迁移保留颜色、表情包和配音来源。

## 识别、翻译与配音

ASR 仍先产生识别记录。在有重叠的范围应用结果时，选择实际要替换的字幕；不勾选任何目标可作为新字幕插入。取消不会改变工程。截断模式保留区外部分；缺少可靠字词时间码时保留原文并标记待校对，不猜测应该保留哪些字。

翻译只处理所选字幕，完成后由「覆盖主字幕／覆盖副字幕／存入素材库」决定去向。副字幕只按明确绑定回填，不能把另一位说话人的译文按时间接近程度配上。导入副字幕时存在多个候选的条目保持未绑定。

七种 TTS 引擎都使用所选字幕的稳定来源 ID。Mossland 跟随时长取每条自己的范围，其他引擎仍使用原生语速／倍率。显示层变化不会导致素材待复核。字幕可以多层，音频贴片仍最多三层；超限结果留在素材库。补齐字幕继续跳过冲突并列出原因。

任务期间可以继续编辑，但被修改或删除的目标不能被迟到结果直接覆盖。切换工程、取消及重试仍遵循原有快照保护。

## 播放预览和导出

媒体播放器设置中提供「同时出现的字幕自动避让」、排布顺序和组间距。新工程默认开启，主副绑定一起排布；已有手动位置或烧录样式的旧工程保留原位置，按需手动开启。字体、颜色与 ASS 样式继续使用现有设置。字幕很多或字号过大时仍需调整字号、间距和画面位置。

CSS 预览沿用播放器外观；ASS 预览和导出沿用 ASS 样式，视频烧录使用导出面板选定的样式。共同规则是保留所有命中条目、主副成组和自动避让，不能将 CSS 字体效果当作最终压制预览；最终效果请使用视频导出中的样式预览。

| 输出 | 行为 |
| --- | --- |
| 普通 SRT | 保留原时间及重叠；外部播放器可能自行排布 |
| SRT（合并同时显示文本） | 按时间边界合并当时显示的主副文本；不改工程 |
| ASS／视频烧录 | 同时保留多条事件，应用主副样式和自动避让；禁用／历史隐藏字幕排除 |
| 去空隙字幕导出 | 各条使用同一移除时间映射 |
| OTIO | 保留所支持的媒体、音频和字幕标记及身份；不包含任意画面排布与字体的无损往返 |
| 旧版工程（v1 兼容） | 仅对旧角色可表达内容开放；有同角色重叠或不兼容的旧组绑定／处理记录时明确拒绝 |

## 保存与旧工程保护

新编辑器保存为 `msw.project.v2`，后缀仍是 `.mosp`，素材仍在对应 `.assets` 目录。打开旧工程只迁移内存，首次写回前先保存原文件字节副本，默认名为 `项目名.v1-backup.mosp`；重名备份增加时间戳，不覆盖既有备份。

使用便携 HTML 的浏览器文件句柄时，首次升级会先让你选择空白备份文件。取消不会覆盖原工程；完成一次手动备份升级后才可继续自动保存。直接下载新文件也可以保留原工程不动。

启动器可以打开 v2 工程。尚未适配多层的预制识别与后处理明确拒绝 v2，应该在编辑器里处理；不要改写版本号强行交给旧工具。需要回退时打开备份，或使用明确的旧版兼容导出，不能用 v1 内容覆盖新版工程。

验证覆盖合成夹具、浏览器交互、服务器保存恢复和真实 FFmpeg 渲染。云端真实识别／翻译质量及付费 TTS 音质不属于本轮自动回归；详情见[实施记录](TEST_FEEDBACK_SUBTITLE_LAYERS_DG_20261005.md)。
