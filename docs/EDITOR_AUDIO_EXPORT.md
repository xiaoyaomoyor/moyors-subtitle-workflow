# 音频导出（D1 / D2）

通过启动器进入本机 Server 编辑器，在「文件 → 导出音频」打开面板。本机需安装或在启动器配置 FFmpeg 与 FFprobe；便携 HTML 不执行后台渲染。

## 导出什么

- **配音轨（仅音频贴片）**：将波形显示器上的未静音贴片按时间安排混成一个 WAV。未使用的素材库音频不参与；重复使用同一素材会按各贴片分别播放，重叠贴片同时发声。
- **原声 + 配音混音**：加入所选的原媒体音轨。原声与配音可分别调节总音量（−60～+12 dB）；配音仍叠加各贴片及配音轨道本身的增益。
- 成品为立体声、16-bit PCM WAV，可选 48 kHz 或 44.1 kHz。单声道复制到左右声道，保持试听电平；多声道原声由 FFmpeg 下混到立体声。

播放器的音量、临时静音和播放速度只影响试听，不写入导出。混音不会自动去除原有人声，也没有人声分离或自动压低原声功能。

## 时间与空隙

默认导出整个时间轴，保留开头、结尾及贴片之间的静音；贴片尾部可超过原媒体。也可输入源时间起止点（秒，精确到毫秒），成品从该范围零点开始。选区不改变导出范围。

「移除已标记的空隙」初始跟随当前空隙跳过设置，可以独立开关。默认保护策略只移除未被可发声贴片保护的部分；选择「配音随媒体跳过空隙」时，原声与配音使用同一保留区间，跨空隙的贴片拆段并调整音频入点。静音贴片或静音轨道不保护空隙。

面板显示预计时长、参与的贴片数与文件大小。混音时后台还会探测原媒体真实时长和音轨，实际结果以完成卡片为准。超过 12 小时的源时间轴或预计大于 4 GB 的 WAV 会拒绝导出，请拆分范围。

## 峰值与任务

默认开启「峰值保护」：浮点精度叠加所有声音后，若峰值超过上限，对整条成品统一衰减，避免硬削波并保持相对音量；卡片显示衰减量。它不是响度归一化，不会把安静片段自动放大。关闭后按原增益导出；若发生削波，卡片提示重新开启保护。

点击「开始导出」即固定工程快照，可以继续编辑或关闭面板。任务显示进度、取消按钮，成功后点击「下载 WAV」。浏览器直接接收文件，不把整条成品加载到页面内存；导出与工程保存独立。

刷新后重新打开面板，可以查看同一服务端口的近期任务并下载已完成结果。旧页面快照有明确标记；切换工程不会自动应用或下载旧任务。服务重启后未完成任务标记中断，不自动重跑，并清理该任务遗留的临时混音文件。

只检查实际参与导出的素材。未使用／静音素材缺失不会阻断；可发声贴片需要的音频缺失、哈希或采样属性不符时失败，恢复原 `.assets` 后重试。混音只接受本机服务已接管的原媒体；浏览器临时加载了其他媒体时，应先保存并在服务中重新打开。

## 保存与实现边界

工程继续保存素材引用、贴片及音量／静音／空隙策略。导出格式、范围及两类总音量属于本次选项，记录在本机导出任务中，不改变工程或试听设置，不写入浏览器长期存储。

本机应用数据目录 `editor-exports/port-<端口>/` 保存任务记录和 WAV；新提交时清理较旧结果，保留约 20 条记录、约 2 GiB 的历史输出，最新大文件单独保留。请及时下载需要长期保留的成品；它们不属于 D0 工程素材收集的 TTS 素材库。

混音以最多 30 秒的块和每组最多 16 个输入执行，不同时解码全部工程。临时浮点原声、混音、素材代理和最终 WAV 需要额外磁盘空间，后台会检查可用空间。解码、混音、编码和最终 WAV 长度全部校验成功后才发布下载；取消停止本次 FFmpeg 子进程。

前后端计划契约为 `msw.audio-render.v1`：整数输出采样点、源采样入出点、静音与增益、保留区间和源流选择，用共同手算夹具约束。导出重用试听的贴片时长、电平及空隙保护规则。浏览器实时试听精度受媒体时钟、调度和重采样器影响；导出 WAV 是离线渲染结果。

D3 / D4 已提供[视频混音与配音剪辑工程导出](EDITOR_VIDEO_TIMELINE_EXPORT.md)，复用本节的音频计划与任务队列。淡入淡出编辑和变速保音高尚未实现。
