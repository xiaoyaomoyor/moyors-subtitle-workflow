# 查找并编辑：整合方案与施工阶段

2026-10-28 制定。四个阶段已实施，施工与验证见 [第一阶段记录](TEST_FEEDBACK_FIND_EDIT_STAGE1_20261028.md)、[第二阶段记录](TEST_FEEDBACK_FIND_EDIT_STAGE2_20261029.md)、[第三阶段记录](TEST_FEEDBACK_FIND_EDIT_STAGE3_20261029.md)及[第四阶段长工程验收](TEST_FEEDBACK_FIND_EDIT_STAGE4_20261029.md)。长工程使用隔离副本，验收边界与额外旧测试套件的现存失败见第四阶段记录。

## 1. 定位与入口

用一个“查找并编辑”非模态工具面板整合批量替换、文本处理和纯文本编辑。沿用 MSWE 已有可拖动工具窗的标题、关闭按钮、主题、输入框和提示图标；支持调整大小、记住位置、越界纠正，打开后仍能操作波形和播放器。本轮设计不新增停靠模块或另一套窗口系统。

- “字幕 → 批量操作”保留一个“查找并编辑”入口；原三个入口在迁移完成后移除。
- `Ctrl+F` 打开或聚焦已有面板，不重复创建。面板内再次按下聚焦查找框；输入法组合输入和更高层确认对话框优先，不抢走其键盘操作。同步操作帮助，macOS 对应 `Cmd+F`。
- Esc 关闭当前工具面板。关闭面板清除搜索标记，但保留本工程本次会话的查询和未应用草稿，重开可继续，不为每次关闭弹出确认。草稿显示简短“未应用”状态并提供放弃入口；离开工程时若会丢失草稿才确认。切换工程必须重新解析范围，不能复用旧工程的字幕 ID。
- 不是把三个弹窗上下拼接：面板内只显示当前视图，公共范围置顶，其余按需出现。

## 2. 公共范围与布局

建议由上到下排列：标题栏 → 范围栏 → 三个紧凑视图按钮 → 当前视图工具 → 可滚动内容 → 必要的统计与操作。

范围下拉提供“全部轨道”“指定轨道”“所选字幕”：

- 初次打开和新工程默认全部轨道，包含禁用、折叠及列表筛选隐藏的字幕，避免漏查；锁定内容可以搜索、定位，显示锁定状态。
- 指定轨道使用紧凑多选，可同时查 S1主、S1副、S2；只选一条也不另设单独模式。
- 所选字幕在切换到该范围时按稳定 ID 固定，显示“所选字幕 · N 条”和一个“使用当前选择”图标。点击搜索结果不反过来把范围缩成单条；空选择保持空范围，绝不扩大到全工程。
- 文字操作默认只作用于明确范围内的正文；绑定伙伴不自动改文字，说话人名称、样式、字幕时间、轨道归属保持不变。
- 锁定匹配项仍列出，批量应用明确显示“修改 N 条，跳过 M 条锁定字幕”；遇到结构依赖锁定时阻止该次结构操作，不做半笔修改。
- 默认查询字幕正文，不查询渲染时添加的说话人名前缀，也不把两条字幕拼成一条搜索。

保持自适应布局：宽面板可同行排列范围、轨道和匹配开关；窄面板自然换行，内容滚动，底部操作不挤压提示图标。避免常驻解释段落。

## 3. 查找替换（默认视图）

- 第一行一个查找框、清空按钮、上一处／下一处图标；旁边简短显示“12 条字幕 · 18 处”。
- 默认按普通文字、不区分大小写匹配。保留现有区分大小写与正则选项，收纳在匹配设置中；空查询不自动列出全工程。
- “替换”展开后显示替换框、“替换当前”“替换全部”；可用空字符串删除匹配文字，但不得删除字幕块。无匹配、无实际变化时禁用应用。
- 结果按起点时间、轨道顺序稳定排列，一条字幕一行：`S1主_12  00:32.450` 与命中片段；同条多个匹配显示次数，当前匹配可单独导航。正文适当截断，展开或编辑时显示完整内容。
- 单击结果跳转播放头并滚动到对应波形字幕块，按现有选择规则选中，不自动开始播放；折叠轨道仅展开定位所需的目标轨道。搜索更新本身不改变播放头和选择。
- Enter／Shift+Enter 在查找框中切换下一处／上一处；在多行编辑框中 Enter 仍换行。
- 波形使用主题色的独立命中标记与局部文字高亮，当前匹配更明显。不覆盖说话人底色、选择边框、禁用效果或绑定标记，不更改工程颜色数据；只更新当前可见块。
- 结果可展开直接编辑正文，Ctrl+Enter 应用这一条，Esc 取消本条草稿。另可使用现有字幕编辑器修改，搜索结果增量同步。
- 替换先生成前后差异，沿用结果区域预览，不另弹一层确认；“替换全部”提交当前方案，一次撤销。替换后结果可能消失，以稳定 ID 保持合理的邻近导航位置，不按数组序号写回。
- 保留正则捕获组替换；错误表达式、零宽匹配、超时分别给出简短内联说明，不让浏览器主线程长时间阻塞。

## 4. 文字整理

接入现有修剪前后空白、首字母大写、前缀／后缀、去除 Markdown 标记功能，名称比“文本处理”更直观。

- 操作勾选紧凑排列；需要输入的操作勾选后才展开输入框，操作顺序固定且可在提示中查看。
- 默认处理公共范围；有查询时允许显式勾选“仅匹配结果”，显示实际处理数量。未勾选时不偷偷使用搜索结果缩小范围。
- 下方复用前后变化列表；只列实际有变化的字幕，点击可定位。“应用处理”一次提交、一次撤销；无变化不产生历史记录。
- 保留空字幕及可复用的字词时间码，不自动切分、合并或改译文。改变正文后如时间码不能逐字复用，按现有映射规则重新计算受影响部分。

## 5. 连续编辑

承接“纯文本编辑”，用于连续校对；和查找替换共享范围与定位，不与普通搜索结果混成同一个大输入框。

- 默认逐条编辑，支持跨轨范围；每条标明轨道、序号、时间，保留原 ID。正文内换行保持为同条字幕换行，不等同于新增字幕块。
- 原“整体编辑”保留为次级视图，仅单轨范围可进入；多轨时保持逐条视图，并给出选择单轨的简短提示，避免把翻译混进原文或跨轨合并。
- 整体编辑仍支持未绑定字幕的结构调整；进入时简要说明“一行对应一条字幕”，有多行正文时优先逐条编辑，不静默拆开已有多行字幕。
- 已绑定字幕允许改文字；拆分、合并、删行等改变绑定结构的操作，提示使用现有联动切分／合并，不自动解绑。
- 保留修改影响预览和词时间码映射，但覆盖率、复用率等技术信息收纳到详情；默认只显示“修改／新增／合并”等实际影响数量。
- 显式“应用修改”提交草稿，一次撤销；切视图、换范围或关闭时保留草稿并提示未应用。提交前比较受影响字幕版本；其他地方改了同一条时指出冲突，不用旧草稿覆盖，不因无关字幕变化而全盘作废。

## 6. 数据规则与性能

- 查找索引和结果使用 `track_id + cue.id + 文本版本`，不持久化数组下标。搜索标记、草稿属于界面会话状态，不写入 .mosp。
- 共用范围解析、匹配、文本变更计划和提交接口；提取新模块，而不是继续把三个实现塞进 editor.js。复用字词时间码映射和绑定校验，避免重写一套字幕模型。
- 输入约 150–200 ms 防抖；查询可取消，旧查询结果不得覆盖新查询。普通搜索只读正文索引，不转换完整工程、不调用 ASS 排布、不生成撤销快照。
- 结果列表虚拟化；波形沿用可见区域渲染。修改一条后只更新该条索引、结果和标记，增删字幕／换轨再更新相应成员关系。
- 正则匹配放入可终止的工作任务，设置查询时间和匹配数量保护；受限环境需要兼容回退，不能静默回主线程执行任意正则。
- 编辑使用受影响字幕的局部变更事务；一次批量操作合并为一次撤销和一次预览刷新。字词映射在实际提交时执行，不在每次输入时全轨计算。完整工程校验仍在必要的保存／结构提交边界执行。
- 字幕列表原来的筛选入口保留局部用途，复用匹配核心但独立保存范围；它不会限制查找面板的全部轨道范围，也不会出现两套互相覆盖的波形搜索标记。

## 7. 施工顺序与验收

| 阶段 | 施工内容 | 验收重点 |
| --- | --- | --- |
| 1. 搜索与定位 | 提取正文查询及范围服务；新工具面板、Ctrl+F、范围选择、结果列表、波形标记、点击定位。旧编辑工具暂时保留。 | 全轨／多轨／空选区准确；折叠与锁定可查；点击结果不改变固定选择范围；关闭清除标记；拖动、缩放、主题、键盘无冲突。 |
| 2. 替换与单条编辑 | 接入直接编辑、当前／全部替换、差异预览、局部事务、撤销和冲突校验。 | 空字符串、大小写、中文、换行、正则安全；不误改绑定伙伴；锁定跳过有明确数量；撤销／重做、保存重开与预览内容一致。 |
| 3. 整理与连续编辑 | 合并文本处理和纯文本编辑，保留单轨结构编辑及绑定保护；更新菜单与帮助，移除旧三处遮罩弹窗。 | 原有功能无遗漏；多轨编辑不混行；未应用草稿不丢失；字词时间码、颜色引用、说话人、绑定及结构变更验证完整。 |
| 4. 长工程与交互回归 | 使用约 6000 条字幕的隔离副本测量初查、连续查询、单条修改及批量替换；检查窗口、热键、保存和导出。 | 记录优化前后时间及主线程长任务；快速输入无旧结果闪回；查询期间播放、拖动、右键仍可响应；大批量编辑一次撤销；原工程不被测试改写。 |

不纳入本轮或首版：跨工程全文检索、AI 改写／翻译、搜索样式元数据、重新识别、自动跨轨拆合，以及新的停靠布局系统。上述内容并非此次整合的前置条件。

## 8. 现有代码衔接

- `web/editor-template.html`：三处旧 modal、批量操作入口与帮助；未来替换为统一工具面板。
- `web/editor.js`：`openReplaceModal`、`flatTextPreview`、纯文本编辑草稿、字幕列表搜索及现有定位桥接。
- `web/msw-batch-editing.js`：范围、文字处理、时间码与绑定结构保护；现有全工程复制路径应在接入批量文字事务时优化。
- `web/editor-utils.js`：文字处理、匹配与字词时间码工具。
- `createFloatingPanel`／`processing-host`：复用已有可拖动、可关闭工具窗约定；如需补充统一缩放能力，应保持其他工具窗行为。
- `tests/e2e/batch-tools.spec.mjs`、`timed-text-edit.spec.mjs`、相关 Node 模型用例：迁移既有业务断言，新增定位、范围固定、局部事务与性能回归，不只测试控件是否存在。
