# MSW 跟进上游 v1.6.0 的筛选结论

本轮只评估上游内容，另行修复编辑器 ASR；不合并上游、不创建发行标签、不发布。用户已将目标从 v1.6.1 改回 v1.6.0。

后续进展：第一阶段的依赖与 Premiere XML 修复已完成，见[第一阶段验收记录](TEST_FEEDBACK_UPSTREAM_160_STAGE1_20261109.md)。第二阶段的 ASS 换行、独立标记、日志日期及英文界面回归也已完成，见[第二阶段验收记录](TEST_FEEDBACK_UPSTREAM_160_STAGE2_20261109.md)。以下保留评估时的基线与筛选理由，第三阶段发行检查尚未执行。

## 比较基线

- MSW 基线：`7186bf19`，工作分支 `my-feature`。
- 已适配的原上游 beta.6：`42656d849f4e2cce9cb21d718add86b692cc6028`，确实是 MSW 的祖先。
- 本轮目标：上游 `v1.6.0` 标签，提交 `73691c29be8816968b4cd6f1fb6b91e08802cf5b`，2026-09-22 发布。
- beta.6 到目标共有 10 个提交（含合并及发行提交），22 个变动路径；不是 GitHub 比较页显示的一千多个功能更新。
- 2026-11-09 查询完整 Releases 列表，v1.6.0、beta.6 及更早发行仍存在。第一页只显示部分发行，不能据此认定旧版已删除。

## 为什么 GitHub 从很早开始比较

上游当前 `main` 已更换历史。原本保存的 `upstream/main` 为 `73691c29`，此次获取新主线时出现非快进分歧；新主线为 `5cd8eade`。MSW 与新主线的共同祖先是 `fbdfff23`，而与旧主线的共同祖先是 beta.6。

证据不只是版本名：旧 beta.6 `42656d84` 与新历史中同版本 `6ec65231` 的产品代码相同，唯一树差异是任务文档中一处本机用户名脱敏。原 v1.6.1 `a8bf4384` 与新历史对应的 `47bc5496` 也只有这一文档差异。历史中较早提交的编号被改变，所以 GitHub 重新把它们计入比较。

GitHub 的提交数量按历史关系计算，不是功能缺失清单。截图也比较了 MSW `my-feature` 和上游当前 `main`，而不是固定 v1.6.0。后续应继续按固定标签逐项适配，保留 MSW 的历史和独立功能；不能为了让计数好看而覆盖分支，或用一次空合并宣称全部上游内容已集成。

| --- | --- | --- | --- |

| 必要（本地识别安装） | 补齐 sherpa-onnx-core，`ca03de20` | MSW 的 `uv.lock` 锁定 sherpa-onnx 1.13.8，却没有 core 包及依赖边；干净安装可能缺少本地识别内核 | 修正锁定依赖并检查实际运行时安装入口；标准／lite 包及新环境执行模块导入检查。不要仅修开发机现成环境，也不要直接覆盖整份锁文件 |
| 验证后保留现状 | ASS 预览换行，`c9fe8885` | 上游修复的是旧 DOM/CSS 预览被容器宽度额外折行；MSW 已使用 `web/msw-subtitle-renderer.js` 的 libass 画布，工程 ASS 由共享编译规则生成，平级轨道布局使用 WrapStyle 2 | 补核长句、手动换行、字符换行、双语和窗口缩放的预览／导出一致性。不要把旧 CSS 强制不换行覆盖到 MSW 自己的换行选项 |
| 已有替代 | 恢复“从颜色组中脱离”，`788b0dc3` | MSW 已提供“标记字幕 → 独立标记”，并有说话人自动跟随和稳定引用 | 保留 MSW 入口、空心／实心规则及清除标记行为，验证独立后原组不受影响；不恢复旧菜单 |
| 已修复 | 日志清理测试依赖真实日期，`460dd014` | MSW 已使用 `_now().timestamp() - 30 * 24 * 3600`，不再使用真实 `time.time()` 计算夹具日期 | 运行现有日志测试即可，无需重复修改 |
| 按现有界面处理 | 英文词条及过期 E2E 断言，`feaf10e4` | 涉及旧双语开关、ASS 样式库、字体读取按钮和启动器本地模型面板；这些入口在 MSW 已被改造或取消 | 仅检查仍存在的界面词条与操作，不恢复旧功能，不直接复制旧断言 |
| MSW 自行维护 | 版本号、发行说明、生成页面、上游截图 | MSW 已准备自己的版本信息和简洁发行文案，但尚未发布 | 完成必要适配、产物与回归后再由用户决定发布；不带入 MAW 截图或品牌，也不复制其全部发行说明 |

## 后续施工顺序

1. 补齐本地识别依赖与 Premiere XML 字体修复，分别验证干净安装和导出载荷。
