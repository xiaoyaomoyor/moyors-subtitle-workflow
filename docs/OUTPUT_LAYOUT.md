# 输出布局与环境设置

本页说明对齐 MAW beta.2 的 B／C 阶段行为。工程仍使用 MOSP；没有自动移动或改名旧文件。

## 输出开关

在 Launcher“设置 → 常规 → 文件输出”中设置：

| 配置键 | 默认 | 行为 |
|---|---|---|
| `MSW_GUI_OUTPUT_SUBFOLDER` | `false` | 最终 SRT／MOSP 默认留在媒体旁；开启后放入媒体的 MSW 子目录 |
| `MSW_GUI_PER_VIDEO_SUBFOLDER` | `false` | 总开关开启时改用 `视频名_msw`；否则共享 `_msw` |
| `MSW_GUI_ATTACH_MODEL_NAME` | `true` | 默认字幕名附加模型／供应商段，例如 `clip.qwen-audio.srt` |

总开关关闭时，每媒体开关在界面禁用，但保存的偏好保留；缓存使用共享 `_msw`。显式指定的 SRT／公开 CLI 输出和批量 manifest 路径优先。Launcher 分配转写输出时会避开已存在的同名 SRT、MOSP 和对应 HTML；批量任务也预留这些路径。

Launcher 的 HTML 始终放入源媒体的 MSW 子目录，即使 SRT 位于其他目录。批量 manifest 未显式指定时，放入首个有效媒体的 MSW 子目录；每个媒体的输出仍独立计算。

## 缓存与兼容

新原生波形和浏览器转换缓存使用 `_msw`／`视频名_msw`。查找时依次兼容当前 MSW 根、其他 MSW 根、共享／每媒体 `_maw` 根和媒体旁旧文件；有效缓存原地复用。波形按原始媒体身份保存，转换后的播放缓存不会引起 `_msw/_msw` 嵌套。`.ReaPeaks` 保持既有位置。

底层 API 脚本的调试原始响应在未指定输出时进入 MSW 子目录；明确指定输出时仍与该输出相邻。底层脚本自带的日期前缀规则继续保留，文件名不再附加 RTF／速度。腾讯与 OpenAI 脚本原本不附模型段，`--no-model-tag` 是兼容参数；其余四个脚本会移除原有模型段。没有新增公开 `MSW.exe --no-model-tag` 参数。

## 后处理与素材

新中间任务目录为 `_msw/后处理/任务名` 或 `_msw/postprocess/任务名`（每媒体模式使用对应根）。已有 `MSW-Postprocess`、`MAW-Postprocess` 或其他明确指定的恢复目录继续原地恢复；不自动移动。

中文界面的可读后缀包括 `.后处理`、`.翻译为中文`、`.翻译为英文`、`.双语合一`、`.OCR去重`、`.匹配`、`.去空隙`、`.压字幕` 和 `.音频`；英文界面保留英文规则。编辑器原有去空隙／表情包导出同样跟随语言。旧英文和新中文翻译名称都参与重复翻译检查与媒体查找。

后处理写出中间或最终 MOSP 时收集可用音频素材，并锚定原媒体引用；工程 ID、素材 ID、素材包内部路径、轨道与贴片参数不改名。缺失素材保留引用并报告，目标位置有不同内容的同名素材时拒绝覆盖。MSW 配音 WAV、混音 MP4、含配音 OTIOZ 的专属命名保持原规则。

## 配置优先级与本地环境

读取优先级是进程环境高于配置文件；同一来源 `MSW_*` 高于 `MAW_*`，明确的空值也生效。旧名称继续可用；界面保存时更新文件中已经存在的别名，避免残留旧值。`MSW_ENV_FILE` 优先于兼容的 `MAW_ENV_FILE`，两者都未设置时使用原有配置位置。

“设置 → 运行环境”的本地 ASR 目录支持选择、拖入、手工输入；保存后扫描新目录，重启后回读。配置键为 `MSW_LOCAL_RUNTIME_ROOT`，兼容 `MAW_LOCAL_RUNTIME_ROOT`。清空恢复默认应用数据目录，不移动原目录。安装、模型准备、单项或批量转写期间暂时禁止切换。

该目录只用于非 MOSS 的本地 ASR 托管环境。MOSS 继续使用独立环境；OCR、模型权重缓存、油库里资源和 IndexTTS 服务不受影响。选择 MOSS 时不显示非 MOSS 目录输入。

Launcher 的切句参数位于“设置 → 处理设置”；模型区域保留运行环境状态与设置入口。实用工具左侧分类和右侧内容独立滚动。英文界面使用稳定 ID 对应的文案，错误状态保留具体诊断。

## 耗时

底层识别输出开始／结束时间、转写耗时和 RTF；自动后处理记录每步与总耗时，Launcher／批量日志给出流程耗时。`RTF = 转写耗时 / 媒体时长`，越小越快。保留机器状态行 `MAW_STAT rtf=...`，没有固定费用估算、RTF 文件名开关或完成后重命名。
