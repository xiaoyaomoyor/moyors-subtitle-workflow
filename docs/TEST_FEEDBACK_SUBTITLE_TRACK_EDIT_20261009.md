## 最终实现与验收

- `web/msw-subtitle-tracks-editor.js` 接入显式开发入口、轨道头及菜单、列表范围、编辑器对象标签、固定行、锁定保护和归属事务。`editor.js`、`waveform.js`、层适配器接入历史与切分合并；纯数据接口提供固定布局和归属校验。默认 v2 路径保持原有行为。
- 添加对白／画面文字轨道，保留空轨道；名称、顺序、启用、锁定、折叠和副行显式显示均保存。启用和锁定使用不同图标，禁用轨道保留可编辑的淡化块；视频画面排布仍留到下一阶段。
- 从任意一侧换轨均带上明确绑定对象，时间、稳定 ID、偏移和素材引用不变。同轨碰撞或锁定时整次拒绝；切分继承原轨道，独立副字幕切分只解绑对应对象；跨轨合并拒绝，同轨联动合并沿用已有状态规则。操作及轨道元数据均一次撤销／重做。
- 轨道筛选保持时间顺序；旧隐藏组在编辑列表可找到，在预览仍遵守原遮罩。主字幕拖动的跟随集合不依赖副字幕显示开关。固定布局拖动只更新区间索引，不重新分配编辑行。

## 使用与边界

测试页面 URL 添加 `?subtitle-tracks=1`（已有查询参数时追加 `&subtitle-tracks=1`），打开测试工程。默认入口和原工程保持 v2，不自动升级。开发页面可保存 v3 工程；首次覆盖旧文件须先另存原始备份，取消或原文件变化均停止。浏览器下载不搬运素材，工程仍需放在原目录以维持相对资源路径。

阶段 4 的注释定位／新画面排布、阶段 5 的识别／翻译／配音／输出尚未实施。开发页不绑定服务端保存或处理，相关导出与处理动作提供就地说明；预览为旧排布的近似预览。默认编辑器与后端继续拒绝 v3，防止静默丢失轨道数据。未重跑第一阶段记录中已核对的 16 项其他 E2E 既有失败，不宣称全部 E2E 仓库全绿。
