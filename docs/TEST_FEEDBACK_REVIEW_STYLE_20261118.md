## 调整与验证

- 工具栏、筛选、列表与详情统一字号／留白；名称、等宽时间码和备注分层。颜色输入改为 36×28px 色块，删除操作使用现有危险色；空备注和空提示不占行。
- 宽度不超过 340px 时，搜索框独占一行，两个筛选项并排；不超过 260px 时详情改为单列。较矮面板允许滚动，列表／详情分别保留可访问区域；顶部窗口标签使用原有公共样式。
- 隔离浏览器检查 default／alice 深浅主题，在 520×740、280×520、360×280、220×420 四种面板尺寸下均无横向溢出，主要控件字体均为 12px，底部删除操作可以滚动到达；另检查 280px 英文面板。人工查看工作区全图、宽／窄／矮面板和英文截图，文字、标签与主题正常。

- `git diff --check` 与本轮三个文本文件 UTF-8/LF 检查通过。仅修改复核相关 CSS 和文档，未更改 JS 行为、数据契约或其他模块规则。
