现有旧预览使用固定 `-38px` 整体上移；当前精确渲染没有对应避让。新实现只修改播放器的临时渲染数据，不修改共享导出布局。

实现：预览接口附带字幕组、时间及样式身份，版本升至 7；JASSUB 使用不可变原事件生成临时位置覆盖，所有写入串行且有媒体版本保护。控制条显隐不请求后端、不修改工程；较大工程与减少动态效果设置直接更新，普通字幕平滑过渡。行组冲突按同时出现区间处理，空间不足时移出控制条。

首轮测试问题均已定位：沙箱内 uv 查询被拒绝、本机测试服务不响应，改用正常本机测试环境；测试默认窗口含黑边，本来就不应避让，现明确设置会遮挡字幕的画面尺寸；刷新偏好测试原先每次覆盖 localStorage，已修正；顶部注释测试误用导入而卸载媒体，已改为原生编辑提交。以上不作为产品通过证据，修正后已复验对应项。
