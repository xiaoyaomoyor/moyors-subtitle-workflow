## 最终行为与验证

- 调用与管理分开：全局环境切换／保存不改变当前合成引擎；百炼列表支持本机名称搜索、登记外部 ID 与重命名，创建完成后由用户主动选择。IndexTTS 预设可保存、重命名、移除，移除保留参考音频；参考上传／检测期间禁止保存重载配置。
- 默认操作对象为主字幕，页面内保持选择；无选区只处理指定轨，选区仍保留此前确认的独立字幕规则。草稿首次复制当前编辑器文字，此后独立；关闭 TTS 恢复字幕编辑，刷新／换工程清空未提交草稿。单次最多 600 个 Unicode 字符，提交快照、实际音频时长随素材保存，三引擎已验证。
- 默认桌面宽度下，文本模式的 TTS 窗口会让开草稿框；窄屏仍可拖动面板。新增全局文档链接的普通／访问后颜色统一。所有文本仍通过安全 DOM API 展示。
