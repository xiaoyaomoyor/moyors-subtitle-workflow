# 便携 HTML 编辑器的停止分发与维护边界

维护者于 2026-11-09 确认：便携 HTML 退出默认分发、隐藏使用入口，不再作为受支持的编辑器形态维护。日常工作流统一使用 Launcher 启动的本机服务与浏览器页面。

## 本轮落实

- Launcher 隐藏“同时生成单文件版网页编辑器”选项。旧草稿、队列方案和识别请求中的 `generateHtml` 不再启用输出，正常 `.mosp`、字幕、媒体和波形流程保留。
- Windows／macOS／Linux 共用的 `MSW.spec` 不再打包 `blank-editor.html`；发行工作流不再生成它，源码归档也排除该旧产物。
- 官网移除在线便携编辑器链接，Pages 工作流不再生成 `/editor/`。正常官网与文档继续发布；已打开的旧页面、已有本机 HTML 不主动删除。
- 仓库保留 `edit.py` 的共享渲染函数、现有生成接口和历史 `blank-editor.html`，不承诺旧便携产物持续更新或新功能可用。历史 CLI 的显式生成参数不作为常用入口推广。

## 后续开发规则

1. **继续维护**：`web/` 前端源码、`edit.render_editor_page()` 与本机服务器的装配关系、服务器能力检测与必要的浏览器降级。它们服务于日常编辑器，不能因便携模式退出而删除。
2. **停止维护**：独立 HTML 的功能补齐、浏览器兼容修补、界面与正式编辑器同步、便携专属发行与人工验收。普通前端修改不再要求更新根目录 `blank-editor.html`。
3. **保留测试工具**：部分前端测试通过生成临时 HTML 加载共享源码。这属于隔离的前端测试夹具，不代表重新支持便携产品；遇到共享功能问题仍应修复，独立便携使用问题不作为发布门禁。
4. **明确不受影响**：解压运行的 MSW 程序包、普通 `.mosp` 工程、对比工具 HTML、便携 OTIO／素材打包等均不属于本次退出范围。
5. **未来再清理**：若决定完全删除历史生成命令或浏览器文件模式，应先迁移依赖它们的测试夹具与 CLI 调用，再单独审查；不得直接删除 `edit.py` 或批量移除所有包含 portable 的逻辑。重新支持便携模式需要维护者明确决策。

本轮只更新后续分发配置；不重写已发布版本，也不删除用户已有工程或 HTML 文件。
