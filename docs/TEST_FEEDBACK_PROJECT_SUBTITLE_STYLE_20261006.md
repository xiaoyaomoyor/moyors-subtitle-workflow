## 最终实现

- `preview.project_style` 保存完整主／副样式和动画；预设应用、校对和单次导出均使用独立副本。工程样式支持独立撤销／重做；未知样式／预设库版本明确拒绝，不自动降级覆盖，加载失败提供具体原因和重试入口。
- 媒体播放器设置统一管理工程样式与预设；校对默认跟随工程，切换后标明「仅影响预览」。字体、字号、颜色、描边、位置放在基本区，其余属性和动画收进「更多设置」。帮助文字使用提示图标。
- 视频导出只选择轨道、跟随工程或其他预设；播放器显示导出预览，关闭后恢复。开始导出时重新读取并冻结所选样式，加载未完成时给出明确提示。
- 旧输出参数首次迁移时保留；半透明底框及位置在便携 ASS、播放器和视频烧录中保持旧参数。高级属性编辑会明确提示转换。旧预览、ASS 方案及修改过的用户库保留为可选择来源；新工程不会因运行时默认几何被误判为旧工程。
- 本机首次写回旧样式工程前保存原字节备份 `.msw-style-backup-<摘要>.mosp`。原样式库不覆盖，新预设库使用 `subtitle-presets.json`。便携预设保存在浏览器，不自动与本机库同步。
- 工具箱 SRT 烧录使用共享预设和同一 ASS 编译器；外部 ASS／SSA 保留文件自身样式。
- JASSUB、Worker 和 libass WASM 随仓库提供，运行时不访问 CDN；固定依赖、可重建脚本、哈希及许可证一起保留。字体只从已登记的本机字体目录加载，请求使用已有本机令牌保护。
