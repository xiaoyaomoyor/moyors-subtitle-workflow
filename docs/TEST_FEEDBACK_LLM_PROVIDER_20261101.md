## 预制步骤模型与思考强度设计

- 校对、重新断句、翻译各自使用“供应商｜模型｜思考强度”一行；窄窗口自然换行。沿用当前控件和提示风格，不复制 API Key 与接口配置。
- 模型默认“跟随更多设置 · 实际模型名”，强度默认“跟随更多设置 · 实际强度”。两项分别继承，允许只覆盖其中一项。
- 模型下拉复用该供应商的候选列表，支持搜索及输入模型 ID；刷新列表不触发生成测试。模型在列表中不代表当前账户能生成。
- 切换供应商后回到该供应商的默认模型与强度，避免把 Gemini 模型带到智谱；提供一键恢复跟随。每个步骤互不影响。
- “跟随更多设置”和模型自身的“自动”不同：前者取本机保存值，后者不显式传思考强度。只显示模型已知支持的强度；未知兼容服务保留输入能力并清楚说明限制。
- 配置层保存非敏感的步骤覆盖与继承状态；不保存复制的默认值或密钥。开始制作时解析并冻结各步骤的实际配置，任务运行期间修改更多设置不会影响进行中的任务。
- 当前后端按供应商快照配置，同供应商的两个步骤共用一组模型。实施时应在该供应商快照上分别应用步骤覆盖，独立校验每一步的实际模型／强度，并以此组合验证连接；不能只增加前端下拉框。
- 保留当前的实际请求记录；失败、恢复和续跑沿用原任务的步骤快照，不自动换模型或付费接口。
- 验收覆盖：校对与翻译同供应商不同模型、只覆盖强度、恢复继承、切供应商、保存重开、批量队列运行中改默认值，以及失败续跑。测试不得默认发送付费请求。

## Gemini 官方核查

- [定价](https://ai.google.dev/gemini-api/docs/pricing)：3.5 Flash-Lite、3.6 Flash、3.8 Flash 的 Standard 文本输入／输出均列出 Free of charge。模型具备免费层不代表任一项目都有未用完的配额。
- [3.7 模型说明](https://ai.google.dev/gemini-api/docs/models/gemini-3.7-flash)：3.7 已弃用，API 自动路由到 3.8；两者测试失败不能作为两个独立模型服务失败的证据。
- [错误说明](https://ai.google.dev/gemini-api/docs/api-errors)：429 对应限流／配额、403 对应访问权限、503 对应服务暂不可用。旧记录缺服务端细节，无法确认账户层原因。
- [3.8 模型说明](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)：支持 low／medium／high，不支持 minimal。现有 MSW 已将该系列“最低”映射到 low，不能再把这项已处理兼容问题当作当前 503 的既定原因。
