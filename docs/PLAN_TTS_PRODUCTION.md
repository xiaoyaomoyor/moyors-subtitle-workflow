# TTS 草稿、音频批量操作与补齐字幕实施计划

用户已批准按 A–F 顺序实施，并要求最后提交推送。本记录由规划转为实施账本。开始时仅本计划文档未跟踪，已读取现有实现、AGENTS.md 和上轮 E/F 记录。本轮 A–F 为新的批次编号。

## 已确认的用户决定

- 重新生成：保留贴片在时间线上的起点，使用新音频完整时长；造成三层超限时暂不替换。
- 补齐字幕：选中贴片互相冲突时，冲突候选全部跳过，其余生成并列出原因。
- 合成后清空配音草稿的开关放在字幕编辑器设置，默认开启。
- 字幕编辑器设置从展开子菜单改为详情窗口。
- 用户已授权实施及提交推送至 origin/my-feature。
- 补充：外部导入音频也允许补齐主字幕，以文件名作为可编辑的占位文字。

## A：字幕编辑器设置详情窗口

- 菜单栏“字幕 → 设置 → 字幕编辑器设置”、模块右键设置入口统一打开同一个非模态详情窗口，入口带窗口图标。
- 使用现有字幕列表设置／波形设置的窗口组件，统一标题、宽度、关闭按钮、拖动、Esc 和窄窗口适配。
- 窗口内容按“显示”“编辑操作”“配音草稿”分组。保留跳转按钮、时间操作、表情包、Esc 取消编辑等原设置及保存值。
- 新增“合成成功后清空配音草稿”，默认开启；标明仅适用于 TTS 的“字幕编辑器内容”。
- 新增断句设置：手动换行分段开关默认开启；自动断句选择关闭／按标点／按字数／标点与字数，默认关闭。仅显示当前模式需要的参数。
- 默认标点建议 `。！？!?；;`，可编辑；逗号、顿号和小数点默认不分割。字数上限建议初值 100，可在当前引擎支持范围内调整。
- 设置即时生效并保存，关闭窗口不承担“执行合成”含义；旧项目和旧设置文件不需要手工迁移。

涉及：`web/editor-template.html`、`web/editor.css`、`web/editor.js`、`web/editor-utils.js`、`web/editor-i18n.js`；复用现有浮动窗口组件。

验收：三个旧显示选项及 Esc 行为保持；所有入口打开同一窗口；保存／刷新保留设置；窗口打开后仍可正常编辑和选择贴片。

## B：草稿分段与安全清空

### 断句规则

- 手动回车、粘贴文本中的真实换行按硬换行处理；输入框宽度造成的自动折行不分段。单靠 textarea 文本无法区分“用户敲下的换行”和“粘贴进来的换行”，两者统一处理。
- 手动换行分段开启时先按换行形成段落，再在各段内应用自动断句，不跨段拼接。关闭所有断句时保持整段一条。
- 跳过空白行；标点保留在前一段，连续结束标点及其后的闭引号随句保留，避免生成仅标点的音频。
- 按字数模式使用用户可见字符计数，不按 UTF-16 代码单元切碎 emoji；英语优先在单词边界切分，连续中文按字符处理。独立保留后端的每条字符数限制校验。
- 标点与字数同时启用时，优先自然断句，超长句再按字数切分。默认规则避免切开小数、网址等明显结构。
- 在草稿区域显示“共 N 段／最长 N 字符”；提供可折叠的分段预览。TTS 面板显示本次合成条数，无需重复放断句设置。
- 当前单条 600 字符上限改为逐段校验，不能把原始长草稿直接送给引擎；保留后端单批条数、总字数和素材容量上限。

### 合成与来源

- 前后端支持同一任务含多条 `editor_text`，每段具有稳定 key、段序号和草稿批次标识。每段生成独立音频，顺序不取决于网络完成先后。
- 默认结果仍进入素材库，不自动在波形时间线上铺放贴片。这次需求不额外引入自动铺放或新增段间静音。
- 草稿段没有真实字幕时间，不能把它们伪装成已经对齐的字幕。来源可以记录提交时播放头作为参考；补齐字幕始终使用贴片实际位置。
- 同一批中的失败项可以单独重试，已成功音频不重复合成；确认不明提交结果时复用原请求标识，不重复排队。

### 自动清空

- 仅当该批全部成功且音频已登记到素材库后清空，不在点击开始或服务器接收任务时提前清空。
- 提交时记录工程 ID、草稿版本、文本快照和清空开关。完成时只有工程和草稿版本仍一致才清空；期间输入了下一段、即使之后文本碰巧相同，也不能被旧任务清掉。
- 失败、取消、网络状态不明、部分成功都保留草稿。通过重试完成剩余片段后再按同样条件判断。
- 关闭 TTS 窗口不影响同一草稿任务的完成判断；切换工程后旧任务绝不清空新工程输入。
- 提供恢复上次自动清空草稿的操作，不把清空草稿写成删除真实字幕的历史。自动清空后保持草稿已初始化，避免重新打开又复制回当前字幕。

涉及：`web/msw-tts-core.js`、`web/msw-tts.js`、`maw/msw/tts.py`、`maw/msw/assets.py`，按需要补充任务快照的可选元数据及契约说明。

验收：三行文本得到同一批三份素材；自动折行不增加素材；长草稿分段后可合成；部分失败重试不重复；成功清空但任务期间新输入保留；主副字幕数据完全不受清空影响。

## C：处理菜单与音频批量操作

“媒体”菜单新增同级分组标题“处理”，下面依次放 ASR、TTS、音频批量操作、补齐字幕；沿用现有“设置”的分组样式，不增加不必要的悬浮子菜单层级。

- “音频批量操作”打开非模态窗口，显示选中贴片总数、可重新生成数量、可补齐字幕数量。
- 使用所选贴片的唯一 ID 集合，跨波形行显示的同一贴片只计一次；没有贴片选中时禁用操作，不默认处理全部贴片。
- 窗口内有四项独立操作，不因打开窗口或修改数字就直接执行，更不一次默认执行四项。
- 静音贴片：提供明确的“静音／取消静音”，不混用逐条反转，混合静音状态也有确定结果。
- 贴片音量增益：提供“设置为／增减”两种方式，明确 dB 单位。每条最终值遵守现有 −60 至 +12 dB；执行前列出越界项，整次拒绝而不静默截断。
- 重新生成并替换、补齐字幕在后续阶段接入各自操作。执行前展示数量；点击执行后冻结贴片 ID 及必要状态，后台任务不随新的选择变化而转移目标。
- 静音和增益每次批量执行只产生一步撤销；保持播放、热力图、源素材及保存一致。

涉及：新增 `web/msw-audio-actions.js`（界面与执行流程）及按需独立的纯逻辑模块；`web/msw-audio.js`、`web/editor.js`、模板、样式、i18n 和资源注册。

验收：跨行、三层、多选与混合静音；清空选中；切换工程；批量增益设置与增减；一次撤销／重做及保存重载。

## D：补齐主字幕

- “媒体 → 处理 → 补齐字幕”直接处理当前所选音频贴片；批量操作窗口里的按钮调用同一实现，不维护两套算法。
- 文字优先使用素材保存的 `generation.display_text`，兼容真实 `source_ref.text`；不使用读音提示替代显示文字，也不把普通文件名当成对白。外部导入且 `text_origin=filename` 的音频使用 `generation.filename`（缺失时回退贴片标签）生成占位字幕，结果标明待填写真实文字。
- 一条贴片生成一条主字幕，起止使用当前贴片的实际播放区间（包含移动和裁剪），而非素材旧 source_ref 时间；统一转换为合法整数毫秒。
- 已裁剪素材只有整段配音文本，没有可靠逐字对齐时仍使用其保存的整段文字，并在结果中提示“音频已裁剪，请核对文字”，不猜测删掉哪些字。
- 任意时间重叠都算冲突，包括仅覆盖一部分、被包住、包住已有字幕。已有空字幕、隐藏字幕、禁用字幕同样占用主轨区间，不覆盖它们。
- 首尾相接允许；先把所有候选区间转成最终整数毫秒再检查，避免原始小数秒检查通过但生成后重叠。
- 按用户决定，候选之间有重叠的双方全部跳过；与已有字幕重叠的候选也跳过。先统一标记冲突，再一次提交其余候选，不以遍历顺序决定谁覆盖谁。
- 重复执行时已有对应字幕会阻止重复创建。保留已有字幕、主副绑定和颜色／表情包引用，插入排序后正确修正基于下标的引用。
- 为新字幕分配稳定 ID；有条件时记录可选音频来源，便于识别重复和后续复核。整批一次撤销，不删除音频。
- 结果简报如“已补齐 5 条，跳过 3 条”，展开后按贴片列出原因。后续移动／重新生成贴片不会静默移动或覆盖已经补齐的字幕。

验收：油库里、Qwen、IndexTTS 的真实显示文本；外部音频文件名；主轨为空、全冲突、部分冲突、候选互相重叠、端点相接、裁剪、重复执行、撤销及保存重载。

## E：重新生成并替换

- 从每条所选贴片引用的素材读取原来的生成配方与文本，包括引擎、模型、音色、语言、速度／情绪参数及读音修正；不使用当前 TTS 面板里后来修改过的值。
- 按引擎与完整配方分组提交，混选不同服务和音色时分别处理。凭据、服务地址和本地资源位置使用当前环境配置，旧工程不能决定执行文件或任意访问路径。
- 保留当时的显示文本与读音输入；实际提交朗读的文本单独保留，避免再次套用新的读音设置或重复处理。缺少必要配方、模型不可用、参考音频丢失等只跳过对应项，不擅自换模型或音色。
- “再次生成”是新的请求，区别于查询上次请求或重试失败项；防止重复点击造成同一批重复提交。每个选中的贴片独立获得一次新结果，多个贴片引用同一素材也不共用一次抽卡结果。
- 不承诺每次声音不同：某些引擎或固定采样配置可能得到相同结果。保持原有生成参数，不为了差异擅自改变音色、随机参数或读法。
- 新音频先作为独立素材入库，旧素材保留；失败、取消、缺失参考或无效音频都不移除旧贴片。
- 按用户决定，替换保留贴片 ID、起点、轨道、增益、静音和自定义标签；新的采样入点为 0、出点为新素材全部采样，旧裁剪范围不套到新音频。
- 合成期间若贴片被删除、移动、裁剪、换素材或更改会被替换的属性，完成时不覆盖用户的新编辑，结果保留在素材库并提示原因；切换工程绝不跨工程替换。
- 批次结束后对整套候选替换结果统一检查三层容量，包括新结果之间的冲突及保留的原贴片。超限候选暂不替换，其他可应用结果合并成一次撤销；取消批次时不自动应用已完成候选。
- 完成摘要区分已替换、合成失败、超过三层、目标已变化、缺少生成配置等。未应用的新素材可以试听后手动使用。撤销替换恢复旧素材引用和旧裁剪状态，不触发重新合成。

涉及：音频批处理模块、`web/msw-tts.js` 的可复用提交接口、`web/msw-audio.js`、处理宿主与历史；后端 TTS 快照／结果映射及原配方解析，必要的可选来源字段和校验。

验收：多服务混选、原配方与当前面板不同、同一素材的多个贴片独立生成、新旧时长不同、第三／第四层边界、部分失败、取消、重复点击、任务期间编辑／删贴片／换工程、撤销／重做、保存和素材仍可播放。

## F：视频尾部说明与最终回归

现有三个选项的准确含义：

| 当前选项 | 当前实际行为 | 建议新文案 |
| --- | --- | --- |
| 超出时提示选择 | 导出范围超过原画面终点时提示并阻止开始，要求改选截断或定格；范围未超出则正常导出 | 超出时先选择处理方式 |
| 截断到画面结尾 | 成品在原画面终点结束，超出部分的音频及字幕不进入这次成品，工程内容保留 | 按视频结尾截断成品 |
| 定格延长画面 | 超出的成品范围使用最后一帧延长，音频按所选模式继续，没有原声的尾部不凭空延续原声；启用压制时字幕按导出范围输出 | 定格最后一帧并延长 |

字段名改为“导出范围超过原视频时”。例如原视频 60 秒、配音或导出范围到 65 秒：截断得到 60 秒成品；定格得到 65 秒成品，最后 5 秒为定格画面。

当前自动范围会参考原媒体／时间线时长、主字幕终点和音频贴片终点，因此尾部字幕也可能间接触发；没有尾部字幕但配音超长同样会触发。静音贴片在当前范围计算中仍可能延长范围，不能把提示写成“有声音才会触发”。本轮优先澄清呈现，不顺带改变范围计算规则。

- 在导出窗口显示原画面时长、所选源范围终点、超出时长及预计成品时长；有空隙移除时区分源时间范围与压缩后的成品时长。
- 仅超出时强调该字段和后果；三种策略保持原语义。说明只影响本次成品，不删除工程字幕和贴片。
- 前后端一致验证：视频正常范围、仅尾部配音、仅尾部字幕、自定义范围、启用／禁用字幕压制、空隙移除、没有视频、尾部截断无有效范围、取消导出。
