- `web/editor.css` 使用现有主题色，普通动画 640 ms，减弱动画仍只淡出。查看了正常动画列表／波形的实际截图。
- `tests/e2e/merge-unified.spec.mjs`：29 项通过，包含生产平级轨道下实际 C 键、两种动画偏好、异步重绘／滚动、短窗格、跨显示列、隐藏绑定侧、状态合并、复制与一次撤销。
- 测试夹具修正：生产迁移使用新字幕 ID，点击按对应显示索引定位，不能沿用旧 m1/s1 ID；初始化显式全量绘制波形；长卡片用例模拟缩小列表窗格，避免被默认三行省略误判。

## 多重字幕设置改造方向（仅说明，未实施）

沿用现有 MSWE 面板、右键子菜单和提示图标，不引入独立大面板。轨道平级、可选主副分组、具体字幕绑定和列表左右显示是不同概念。保留双栏卡片、联动切分／合并与快捷键。

| 现有项目 | 建议去向与规则 |
| --- | --- |
| 启用多重字幕、请导入第二条字幕 | 移除用户开关，多轨是常态；显示、折叠与启用分别使用现有轨道控制。读取旧工程时显式保留隐藏／禁用状态，不直接删除兼容数据字段。 |
| 允许字幕重叠 | 跨轨同时出现属于正常用法，不再依靠特殊叠加轨开关；同轨碰撞作为单独的高级规则，明确是否允许同轨重叠，迁移保留已有重叠内容。 |
| 主／副字幕语言类型 | 字幕编辑器设置新增紧凑“文字切分”分类，按实际 S 轨道选择，单词／字符模式存到轨道；不由列表左右列决定，也不与画面自动换行混用。 |
| 副字幕时波形高度 | 迁入波形显示器设置，整合为统一行高／轨道密度；沿用当前至少三条可见字幕轨道时的紧凑块高。 |
| 跨轨道吸附 | 迁入波形操作设置，明确为“吸附其他字幕轨道”；仍仅按住 Shift 时启用磁吸。 |
| 同时选中主副字幕 | 字幕编辑器设置 → 绑定与联动，改为“同时选中绑定字幕”；分组不自动绑定。 |
| 绑定时自动同步时长、批量对齐 | 同处绑定与联动；同步时明确参考字幕／参考轨道。批量对齐是针对选区的动作，放右键相应操作中，保留时间偏移和一次撤销。 |
| 交换主副字幕 | 当前生产实现 `swapColumns()` 会交换左右显示归属并反向绑定来源／目标和偏移，并非仅改名称。建议分开“交换列表左右位置”和“反转绑定方向”，不再用含糊按钮同时操作；交换样式继续留在播放器样式区。 |

移除旧子菜单后，字幕菜单保留“字幕轨道设置”和已有编辑器／列表设置入口；分组内继续使用用户指定的 S1主／S1副名称。

## 其他模块优先级（仅说明，未实施）

1. **高：拼接／合并字幕。** `autoMergeSegments()` 在多层分支直接调用所选字幕合并；面板却仍显示全部主字幕、间隔阈值和过短吸收。应按实际轨道＋所选／整轨运行参数计划，明确预计影响数量，联动绑定、一次撤销；与 C 的直接合并分开。
2. **高：批量时间与文字操作。** `subtitleTimeContext()` 仍按 main／extension 显示列取数组，无法代表实际 S 轨道。统一“作用轨道／所选字幕／整轨／联动绑定”语义；批量替换、纯文本编辑、清空等逐项审计。不要把旧选项改名后仍操作混合显示列。
3. **中：导入、导出与音频补字幕。** 导入已有实际轨道和新建绑定支持；SRT 已有实际轨道筛选。进一步统一 ASS／烧录等入口的轨道范围，默认遵循启用状态；“补齐主字幕”改为选择目标轨道，避免固定写入旧主显示列。保留日常快速导出入口，复杂范围作为可展开项。
4. **中：识别／翻译范围与帮助文字。** ASR 已有目标轨道，翻译／TTS 也已有平级处理支持，无需重做这些模块。清理“受影响主字幕”等旧提示，显示实际来源／目标轨道和数量；更新“先启用叠加字幕”等已过时快捷键说明、联动区轨道称呼。
5. **后续：音频空隙参考轨道。** 保留按音量和全部字幕／贴片外检测；将“主字幕外区段”细化为可选择参考轨道，不能用显示列隐含所有源字幕。独立实施，以免改变现有用户标记。

实施顺序建议：拆分旧多重设置 → 修正批量操作目标及参数执行 → 统一导出／音频补字幕 → 清理提示和帮助。所有仅说明项本轮不修改代码。
