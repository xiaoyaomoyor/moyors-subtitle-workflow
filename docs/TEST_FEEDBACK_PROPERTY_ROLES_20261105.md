## 实现规则

- 主副以字幕实际轨道的样式角色判断，不依赖绑定方向。同一侧可跨轨批量修改，另一侧保持原样；锁定的另一侧不阻止当前侧操作。
- 说话人的 `role_styles` 分别保存两侧外观、预设和动画。未单独设置的一侧继续使用原共享样式；恢复色系外观保留该侧动画。说话人方案和配置文件同步携带两侧设置。
- 属性切换不改变波形选区或字幕编辑器焦点；画面定位只操作当前侧，完整选区用于判断是否取消定位。
- 绑定设置复用原控件、事件和偏好值，不重置用户选择。入口为编辑器设置的编辑操作分类。
