## 验证记录

- 修复前：右边界越过起点会将 2–5 秒字幕改成约 0.91–1.01 秒；跨行间隙回退一整行；快速接近邻居时拒绝最后一次事件。
- `node --test tests/test_waveform_js.mjs`：第一阶段 61 项通过；后续增加磁吸、约束和帧单位测试，最终 65 项随全量通过。
- Chromium 新增 2 项交互回归最终通过。首轮发现已有取消函数未绑定 Esc，补上后复验通过；无遗留失败。
- Node 全量 512 项通过。首次未指定 Python 的执行中，XML 解析子进程遇到沙箱权限错误；指定仓库解释器及测试权限后全量复验通过。
- 字幕层完整 Chromium 30 项通过；新增跨轨吸附及最终单位换算 3 项复验通过，其中 1 项为新增用例，共 31 个独立用例通过。
- 含单行／多行、共享边界、主副联动、帧模式、精确到非 10ms 边界、取消、一次撤销与重做；回归发现原有重叠区拖出后不能拖回，已按手势初始范围修复并验证。
- 1 万条字幕 / 1–8 层拖动：索引保留，后续 pointermove 的 p95 约 5.7–6.9ms（本机独立 Chromium，非用户媒体性能承诺）。
- `python -m unittest discover -s tests -p 'test_*.py'`：2033 项完成，1964 通过、69 按依赖／环境条件跳过，无失败。首次自动审批超时未执行，按工具提示重试后完成。
- `playwright test waveform-history.spec.mjs multi-subtitle.spec.mjs waveform-clipboard.spec.mjs`：153 项中 137 通过、16 失败。失败项全部使用修复前 e66e256 进行对照复现（静态场景读取原始便携页面，服务场景仅替换为该提交的原始前端脚本）；同样失败，未将其计为通过。加上字幕层专项，共 168 个独立浏览器用例通过。
- `uv run --frozen python edit.py --blank`：已生成便携产物；原始三例在该产物上复验，分别得到 2.00–2.10 秒、准确贴到 4.00 秒且出现吸附参考线、跨行内及行间空白均为 17.01 秒。
- `node --check web/editor.js`、`node --check web/waveform.js`、`git diff --check` 通过；提交文本检查 UTF-8 / LF。
