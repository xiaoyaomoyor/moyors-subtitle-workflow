核对来源：[IndexTTS 官方仓库](https://github.com/index-tts/index-tts)与用户本机安装的 WebUI 源码、`/config`、`/gradio_api/info`。官方系统是参考音频克隆；示例音频与用户保存的参数预设分别处理，不伪造 Qwen 式固定说话人 ID。

初始进程查询受到系统权限限制，改用已知本机 7860 端口的只读服务元数据查询成功；无须扩大系统进程访问权限。部分 Gradio 文档网络读取失败，继续通过已安装版本源码核对协议。

Gradio 的简化 `/call` 流式读取在显式 session_hash 时按事件 ID 查找队列，返回 404；改用其正式客户端相同的 `/queue/join` 与 `/queue/data?session_hash=...` 协议后成功。独立会话调用 `on_experimental_change` 不改变用户 WebUI，会返回当前模型实际可用的情感模式。未加载文本情感模型时不静默改用另一种控制方式，也不自动重启／强行占用更多显存。

连接仅接受本机回环 HTTP 地址；不会将安装路径固化到项目。参考音频在本机独立库中可复用，原文件保留，合成 recipe 仅记录参考 ID／名称／摘要及生成参数。音色预设读取与生成分开，不因选择音色自动套用示例台词或情感参数。
