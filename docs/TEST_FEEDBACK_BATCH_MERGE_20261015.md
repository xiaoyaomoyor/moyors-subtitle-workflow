## 实施规则

- 本轮不改 C／Ctrl+Shift+C 的直接合并，不展开其他批量文字／时间工具的改造。
- 打开时优先使用当前选择所在轨道；有该轨选择时默认“所选字幕”，否则明确显示“整条轨道”。空选区不自动变为整轨，其他轨道的选区不作为本轨处理对象。
- 拼接只延长字幕填补小间隔，合并短字幕才合并正文；共同使用最大间隔阈值，0 ms 仅允许相接短字幕合并。短字幕按轨道的文字切分方式计量。
- 跳过禁用／隐藏字幕，未选中的同轨字幕构成边界；折叠和列表筛选不改变内容范围。短字幕不跨不同说话人合并。
- 已绑定字幕保持联动与关系方向；间隔调整保留原偏移。碰撞、锁定或绑定关系不兼容时整次不写入；没有弹窗或部分应用。
- 预估只计算，不修改工程。应用前以最新工程和选区重新计算，整批一次撤销；批次结果在面板内反馈。
