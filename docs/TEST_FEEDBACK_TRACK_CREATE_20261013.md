# 空轨道创建字幕入口

基线：`ee98382`，分支 `my-feature`。用户确认在普通编辑器中，N 可以在空轨道创建字幕，Ctrl+鼠标左键和波形空白右键创建不可用。本轮修复这两个入口，不将平级轨道试用切换为默认入口。已有 `.test-appdata/`、`output/` 保留。

| 项目 | 状态 | 事实与验证 |
| --- | --- | --- |
| 完成范围说明 | 仅说明 | 平级 v4 已接入编辑、处理和渲染；原位保存、完整恢复、素材重定位及部分高级音频操作未完成，普通入口仍为 v3 |
| 鼠标创建目标与占用判断 | 已修复 | Ctrl 创建和右键菜单按目标物理轨道检查；新增整数毫秒校验、创建虚影定位、稳定目标归属与 Esc 取消 |
| 回归与交付 | 已修复 | 616 项 Node、19 项 Python 资源测试通过；27 项固定轨道编辑与 2 项旧版创建浏览器场景通过，已重新生成便携页面 |

只使用合成工程和隔离本机浏览器，不读取个人工程、密钥或重启用户服务。

定位验证：新增浏览器场景在修复前复现 Ctrl 没有创建虚影、右键项目错误置灰；N 可以创建。N 重做仅重新排序归属数组，测试按身份排序比较而不要求无语义的数组顺序。

第一轮修复后 Ctrl、主副轨道归属、同轨边界与锁定通过；右键继续被固定轨道校验拒绝。进一步定位到鼠标返回小数毫秒，`layerCreateCue` 未取整，补齐创建时的毫秒整数化。Ctrl 创建预览和最终提交固定使用按下时的目标轨道，避免活动轨道变化导致误写。

后续补验发现创建虚影没有接入 Esc 取消，已补齐监听和清理。旧叠加轨测试只关闭了 v2 升级，仍自动进入 v3；按其原有测试目的补充 `subtitle-tracks=0`，两项兼容场景通过，没有放宽产品断言。

最终验证：

- `node --test tests/test_*.mjs`（PowerShell 枚举）：616 项通过。
- `uv run --frozen python -m unittest tests.test_editor_assets`：19 项通过。本轮无 Python 后端修改，未重复上一轮全量 Python。
- Playwright `subtitle-track-edit.spec.mjs`：原有及新增共 27 项场景通过；`overlay-track.spec.mjs` 的两项 Ctrl 创建兼容场景通过。覆盖主副空轨道、其他轨道同时间占用、同轨边界阻挡、锁定、目标变更保护、撤销重做、帧时间轴、上方轨道虚影与 Esc 取消。
- 已人工查看 Chromium 创建虚影截图，位置与目标轨道头对齐；截图、日志留在仓库外。
- `uv run --frozen python edit.py --blank`，重新生成便携页面；提交前检查语法、diff、UTF-8/LF 和生成内容一致性。

本轮仅修复普通编辑器的实际报告，不宣称 v4 全流程已完成。平级试用的空白指针目标处理仍需专门完善与验收，服务端原位保存等既有边界保持不变。未重启用户服务；本机页面保存后 Ctrl+F5 可加载前端修复，便携页面需打开新版文件。
