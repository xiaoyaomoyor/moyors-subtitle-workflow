# 工程保存、素材收集与恢复

本页适用于从 Launcher 打开的本机 Server 编辑器。保存字幕、素材引用、音频贴片和工程设置，不会调用云端服务。

## 保存与另存为

- **保存工程**（Ctrl/Cmd+S）：继续写回当前工程，使用原子替换并保留旁边的 `.mosp.bak` / `.json.bak`。TTS 音频自动收集到工程同目录的 `msw-….assets/audio/`。
- **另存为工程**（Ctrl/Cmd+Shift+S）：在编辑器选择保存位置，再由系统对话框确认文件名；TTS 音频自动复制。勾选「同时收集原视频／音频」后，服务器也复制它当前接管的原媒体，以相对路径写入工程。未勾选时继续引用原媒体。
- **新建工程**：使用相同的保存流程建立空白工程。另存为或新建成功后，后续保存和自动保存写回新文件。

另存为生成独立工程身份，保留音频素材及贴片 ID；原工程不改写。目标位置凭系统对话框发放的短期令牌使用，浏览器不能直接提交任意写入路径。选择位置后若目标文件变化，会拒绝覆盖；取消或素材复制失败不会切换工程。保存期间的新修改保持未保存状态，不会被错误标记为已保存。

正在执行的翻译／TTS 任务仍属于原工程。已经进入素材库的结果会收集到副本；重新打开原工程可继续检查尚未完成的任务。

自动收集包含当前工程素材库的全部登记音频，包括未放到波形上的素材；同一素材被多个贴片引用也只复制一次。收集保留原始 WAV，贴片位置、裁剪、音量和静音另外保存在工程中。

Windows 使用系统文件对话框，macOS 使用系统选择文件对话框；Linux 需要 `zenity`。系统对话框或服务不可用时，可「仅下载工程文件」保全编辑内容；这种下载不复制音频，也不建立服务器保存绑定。独立 HTML 同样保留浏览器保存／下载路径。

## 素材完整性与搬移

「文件 → 检查工程素材」检查服务器绑定的磁盘工程，区分可用、缺失与仅存在本机暂存区的音频。保存结果也在文件菜单显示素材数量。缺失音频保留引用和贴片，便于找回原文件；工程保存成功不代表素材齐全。

搬移时请一起复制 `.mosp` 与它引用的全部 `msw-….assets` 文件夹；副本可能引用不止一个素材目录。勾选收集原媒体后，整套目录可搬到其他位置或机器。未收集原媒体时仍需保留原位置，或重新加载媒体。D0 收集范围是 TTS 音频和可选原媒体；已有表情包等外部依赖继续使用原有管理方式。

## 恢复记录

「文件 → 恢复记录」列出本机的恢复草稿、最近保存和历史备份。草稿与工程自动保存开关独立：字幕输入停顿约 1.5 秒尝试记录，其他修改每 5 秒检查一次，也记录尚未结束的字幕内联输入。未命名工程也可以留下草稿。

手动保存和自动保存共用保存流程，记录不区分这两种来源；不是每次 Ctrl/Cmd+S 都产生一条历史。

载入副本前先记录当前草稿；失败时保留当前编辑内容。载入后的内容处于未保存状态，需要另存为工程。原工程不会自动回滚或覆盖；保存后重新打开工程以加载原媒体。恢复记录不等同于撤销栈，关闭页面后不能恢复逐步撤销历史。

每个工程保留最近保存、最多 3 个窗口／恢复会话草稿和最多 20 个历史备份；历史最多每分钟采样一次。全库最多 200 条记录、128 MiB 压缩快照内容，超额先淘汰较旧记录。快照不包含音频字节和可重建波形，因此仍需要工程素材或本机音频暂存。它是故障恢复辅助，不替代工程文件备份；服务断开、浏览器崩溃前尚未发送的最后几秒修改可能无法找回。

## 数据放在哪里

| 位置 | 内容 |
| --- | --- |
| `.mosp` / `.json` 工程 | 主副字幕、绑定、空隙、预览样式、工程工作区状态、素材元数据、音频贴片和音频设置 |
| 工程旁 `.assets` | 收集的 TTS WAV，以及勾选收集的原媒体 |
| 工程旁 `.bak` | 上一次被覆盖的工程文件 |
| 本机应用数据目录 `editor-recovery.sqlite3` | 有界的恢复草稿和保存历史 |
| 本机应用数据目录 `editor-assets`、`editor-jobs` | 音频暂存与索引、后台任务和逐条结果；不会随工程搬移 |
| 本机应用数据目录 `editor-exports` | 近期音频导出任务及 WAV 成品；下载后另行保管，不自动收集进工程 |
| 浏览器／本机界面设置 | 外观、快捷键、自动保存偏好等；本机 Server 另保存其支持的工作区／外观设置 |
| 页面内存 | 撤销栈、临时选区、播放状态和可重建解码缓存 |

供应商 API Key 继续保留在本机配置，不进入工程或恢复快照。

## 导出菜单

文件菜单的导出分类为「导出字幕」「导出视频」「导出音频」。「更多导出」和去空隙版本位于「导出字幕」内部。重复的「导出工程」已移除，工程副本统一使用另存为。

「导出音频」已支持配音轨和原声混音 WAV，见[音频导出](EDITOR_AUDIO_EXPORT.md)。视频渲染入口继续置灰；素材库仍可保存单条 WAV 或工程音频包。
