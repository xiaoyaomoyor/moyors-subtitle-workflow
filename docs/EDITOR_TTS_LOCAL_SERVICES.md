# 编辑器内管理本机 TTS 服务

入口：**编辑 → 全局设置 → 环境配置 → TTS**。IndexTTS 与 GPT-SoVITS 均支持服务管理与配音；GPT 的模型、参考和预设配置见 [GPT-SoVITS 配音](EDITOR_GPT_SOVITS.md)。

## 配置与启动

1. 选择 IndexTTS 或 GPT-SoVITS，选择安装文件夹。MSW 检测入口脚本和整合包内置 Python；允许选择实际目录上方两层内的父目录，多个安装时需选择明确的子目录。
2. 确认服务端口与启动等待上限，保存环境配置。仅保存、切换引擎或打开面板不会启动模型。两个引擎的本机启动端口与合成连接地址应一致；保存有效本机安装配置时会对齐连接地址。
3. 点击「启动服务」。先检查当前端口；已运行且协议兼容时复用。缺少模型或环境不完整时提示到原工具准备，不安装依赖、不下载资源、不运行训练。
4. 等待「服务已就绪」或「外部服务 · 已连接」。加载期间显示等待进度与可折叠启动日志。日志在内存中保留最近 100 行，不进入工程，关闭本机编辑器服务后清除。

Windows 后台启动隐藏控制台，不另开浏览器；只绑定 `127.0.0.1`。GPT 使用 MSW 应用数据目录中的推理配置副本，保留整合包原配置。服务由原整合包环境执行，不使用 MSW 的 Python 来运行模型。

## IndexTTS 启动并合成

先上传／选择本机参考音频，或使用之前保存的配音预设。已配置有效安装位置但服务未运行时，TTS 主按钮显示「启动并合成」。文本、实际读音与配方在点击时冻结；同一请求标识只创建一个任务。启动等待期间在合成记录中取消；切换工程也会取消本页未完成的 IndexTTS 任务，服务可以继续完成加载供后续使用。

官方示例需要先启动并连接服务才能列出；已有本机参考可直接启动并合成。重新生成素材／贴片仍复用原生成参数，连接与启动位置取本机环境配置。

文本情感需要 QwenEmotion。停止 MSW 自有服务后，勾选「强制加载文本情感模型（QwenEmotion）」并保存，再启动。实际模型能力检测仍会禁用不可用的文本情感模式，不悄悄换成其他情感。该模型可能增加显存占用。

## 停止、外部服务与故障

- 关闭 TTS 面板或浏览器页不停止模型；显式退出本机编辑器服务会清理其持有的进程树。
- 「停止服务」确认后取消该引擎的进行中及等待任务，再停止自有进程。取消单条合成不会关闭整个模型服务。
- 外部进程只连接，不提供停止操作。MSW 不通过 GPT 的全局 `/control` 接口重启或退出服务，也不根据旧 PID 记录直接杀进程。
- 切换引擎不停止前一个模型；显存不足时可先在环境配置停止不用的自有服务。
- 地址有响应但协议不兼容时显示端口冲突；修改端口或在原工具检查。加载超时与单次合成超时独立，前者在本机启动设置，后者保留 IndexTTS 连接设置的选项。
- 启动失败保留配方；展开日志查看依赖、模型或显存原因。修复后手动重试，MSW 不无限重启。两个浏览器窗口共用一个启动流程；另一编辑器进程持有端口启动锁时提示等待后检测。

仅本机 Server 编辑器能管理服务；便携 HTML 不具备启动本机程序的权限。安装位置和进程记录仅保存于应用数据目录 `tts-services/`，不随工程打包。
