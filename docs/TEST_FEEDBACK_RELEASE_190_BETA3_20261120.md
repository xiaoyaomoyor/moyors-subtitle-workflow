## 验证记录

源码核对：MSW 已有单条样式覆盖、有效样式计算、精确预览几何、外观提交及撤销机制；沿用这些机制，不新增工程字段。既有定位手势保留。测试使用隔离配置与合成媒体。

- 初次手柄测试的合成 v4 轨道样式缺少原有身份字段，补为合并原轨道样式；第二次错误地要求 ASS 使用行内缩放标签，实际正常写入单条 Style，改为核验实际 ScaleX／ScaleY 数值（既有导出按整数输出）。不改产品契约迁就测试。
- 截图发现拖动时 CSS 临时文字被精确渲染的隐藏规则遮挡，修正选择器并增加可见性断言；临时 CSS 字体度量按精确框校准，松开后恢复 libass。原工程在拖动中保持不变，只有结束才提交现有外观事务。
- 本机全量 Node `node --test`：846/846；Python `python -m unittest discover -s tests -p 'test_*.py' -v`：2578 项、23 条件跳过、无失败。第一次 Python 启动审批超时未运行，重试后完成。跳过涉及平台条件、历史波形样本、可选 NumPy／OTIO／Yukkuri 资源和真实对齐示例。
- Chromium 单 worker：`cue-scale` 与 `selected-subtitle-position` 15 项通过；最终预览修订后 `cue-scale`、波形设置与 B 阶段五个文件共 16 项通过，两组去重为 30 项。末尾取消／上限检查随后补验。日志和截图位于仓库外 `msw-checks/beta3-release-20261120/`。
