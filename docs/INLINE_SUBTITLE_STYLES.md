# 句内文字样式

打开「字幕编辑器设置」，勾选「启用 Markdown 句内样式」。开关随当前工程保存，支持撤销、重做，默认关闭。右侧提示图标可以随时查看语法。

| 写法 | 效果 |
| --- | --- |
| `**重点**` | 金色、加粗、1.3 倍字号 |
| `//文字//` | 斜体 |
| `__文字__` | 下划线 |
| `~~文字~~` | 删除线 |
| `++文字++` | 1.5 倍字号 |
| `--文字--` | 0.8 倍字号 |
| `%%文字%%` | 灰色、0.8 倍字号 |

例如：`这句只强调 **重要部分**，其余文字保持原样。` 不需要再给整句勾选样式。

仅识别成对的双符号，单符号、未配对符号和网址仍作为文字。可以嵌套不同样式，例如 `**重点中的 //斜体//**`；嵌套字号比例相乘，内层颜色优先。若要显示标记本身，在标记前加反斜杠，例如 `\**文字\**` 显示为 `**文字**`。这里是有限的字幕样式语法，不解析 Markdown 标题、链接、HTML 或原始 ASS 指令。

样式叠加在当前工程、轨道、说话人和单条字幕的有效样式之上，结束后恢复原样。启用后 `//` 始终表示斜体，`%%` 表示弱化，旧工程不自动替换标记。关闭开关后，所有原始符号都重新显示。

播放器预览、ASS 导出和视频烧录共用可见正文、换行和样式计算，也支持现有的渐变、背景、逐字和波动等字幕动画。动画继续通过 MSW 属性面板设置，本轮不引入上游的句级动画标记。

SRT、TXT 和剪辑工程中的字幕输出去掉已识别的样式标记；工程文件、查找编辑和「导出剧本」保留标记，方便继续修改或外部润色。Lottie／OGraf 动态图形导出使用可见正文和其原有样式，不输出句内样式。

普通拆分会在两侧补齐跨越切点的样式，合并时折叠相邻的同类标记。查找替换、剧本编辑等原文操作仍允许编辑标记本身；如删除了其中一侧标记，剩余未配对符号会原样显示，不会被静默吞掉。

需要移除强调效果时，在「查找并编辑 → 操作」勾选「清除句内样式」，核对筛选与勾选范围后应用。仅在工程已启用句内样式时可用，只删除已识别的成对标记，保留转义、网址、路径、单符号和未配对符号；路径中有歧义的组合保留原文。锁定轨道跳过，可一次撤销；纯样式清除保留可靠的原始词时间。整句的字体、颜色等属性不受影响。原有「去除 Markdown 标记」仍是较宽泛的清理，会处理链接和单字符符号，两者用途不同。
