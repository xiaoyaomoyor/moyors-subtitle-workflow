## 验证记录

按项目逐项记录源码／单元、服务契约、浏览器交互和未验证边界；不以本轮测试代替三平台发行包验收。

### B1

- 复用成对解析器，清除只删除确认的标记，不执行纯文本导出的反转义。网址、常见绝对／相对路径和歧义组合保守保留。入口在查找编辑的「操作」，原宽泛 Markdown 清理不改名或改规则；关闭工程句内样式时禁用新选项。
- `node --test tests/test_inline_markup.mjs`：4 项通过。初次嵌套路径案例发现标记跨入路径可误删，加入结束边界检查，歧义情况保留原文。
- Chromium `find-text-tools.spec.mjs --grep 'clear inline'`：1 项通过，覆盖范围排除、锁轨、绑定、词时间和撤销重做。首次浏览器发现通用映射对密集标记删除会丢失词时间，纯样式删除改为复用标记映射；内容改写仍走原文字映射。第一次启动因自动审批超时未执行，重试成功。

### B2a

`msw.find-edit.view.v1` 纳入公共配置的 panels 分类。只保存用户主动选择；打开其他工程、刷新及新的浏览器上下文恢复偏好，未知／不可用值回退逐条，工程和撤销记录不变。导入剧本临时切换视图不覆盖个人偏好。真实本机服务 Chromium `find-view-preference.spec.mjs` 1 项通过。

### B2b

复用剧本的显示层；四种视图均突出正文命中和当前定位项，信息行不参与。筛选继续基于原文，草稿高亮用实际草稿偏移；输入期间清除过时命中，查询仍在可取消工作线程执行。显示标记不写入 textarea，保留原生选择、复制和输入法处理。

- Node 查找／剧本 17 项通过。
- Chromium 高亮＋剧本＋文字处理共 20 个不同案例最终通过：首次 19 通过，1 条新测试错误地假设按轨道和按时间显示的顺序相同，改为核对命中文字集合后该项补跑通过。包含 6000 条剧本、窄屏中英文、隐藏信息行、复制、合成输入法事件及撤销；未以合成事件代替实体输入法人工验收。

### B2c

文件名旁用小圆点／保存中符号／失败叹号区分状态，悬浮及无障碍标签提供说明；已保存时隐藏。未保存判断直接使用 `hasUnsavedProjectChanges()`，覆盖未应用查找草稿，保存反馈复用原成功、失败与取消路径。状态不参与工程数据，切换工程按代际丢弃旧反馈。

Chromium `project-save-indicator.spec.mjs` 1 项通过：真实磁盘保存、模拟写失败、重试、保存请求等待期间的新修改、清除未应用草稿及文件名保持。初次测试误假设旧格式导入一定为已保存；实际已有规范化改动，改为先确认真实磁盘基线并在切换后核对既有脏状态，未修改产品的未保存判断。一次启动审批超时未执行，重试成功。

### B2d

服务端仅静默已知轮询路径的成功 GET（200／204／304），POST、错误、结果读取和其他路径仍记录。重断句模型调用、结果校验与字幕重建错误补范围序号、稳定 ID、时间与批次，不添加模型原始回复或正文摘录；原有错误分类与服务状态码保留。结果校验发现遗漏／非法切点立即失败，不写部分产物。

`tests.test_beta3_diagnostics`、`tests.test_postprocess`、`tests.test_resegment_boundaries` 共 99 项通过。初次 98 项通过，1 条新测试原想以禁用字幕混合触发重建错误，但既有边界保护已安全拆开；改为在有效模型输出后的本地重建阶段注入失败，验证诊断而不破坏保护逻辑。
