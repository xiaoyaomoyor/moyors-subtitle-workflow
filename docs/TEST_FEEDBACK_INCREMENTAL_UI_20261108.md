## 实现及初步验证

- `MSWCueListView` 对 1,000 条以上的平级字幕视图启用按需卡片，保留时间顺序、身份与筛选用的轻量行，不在工程数据中保存 DOM 或运行期状态。进入视口前预载，离开后回收；输入焦点、行内编辑和浏览器文字选区所在卡片暂不回收，退出编辑后继续回收。小工程及旧显示入口保持原路径。
- 变化范围只把视觉内容变化交给卡片及波形；`_dirty` 仍写入历史和工程，只原地更新卡片类名。删除／插入导致波形索引错位时会刷新该行，跨行移动覆盖原位置与新位置；布局高度变化仍完整刷新。
- 隐藏属性列表收到字幕事件时仅记待更新状态，再打开时同步；可见面板同帧多次字幕事件合并一次。没有推迟保存或模型校验。
- `node --test tests/test_*.mjs`：799 项通过。
- 新增 `incremental-ui.spec.mjs`：最终 7 项通过，覆盖 10,000 条字幕的远处编辑及撤销、搜索和轨道过滤、无关节点保留、滚动回收和选区、焦点保护、尺寸变化、切换小工程、波形非相交行保留、正文不变时显式变化 ID 的刷新，以及独立于编辑焦点的浏览器文字选区保护。
- 本机 Python 生成页面首次遇到权限限制；改在授权的本机测试进程中运行后成功，没有更换解释器或跳过产物生成。

边界：轻量行数量仍随字幕数增长，过滤和结构重排仍会遍历行描述；这次减少的是完整卡片、监听器和重复布局工作，不声称 DOM 总量恒定。后续预览与后台保存不在本次改造范围。

- 补上明确变化 ID 的保守刷新：即使文字/时间未变化，也重建涉及的可见卡片，避免遗漏复核标记等附加状态；仅 dirty 标记变化仍保留节点。初轮性能测试因此停止，保留未完成结果；最终测量改用 `output/perf-ui-20261108-final`，测量期间不更改产品源码。
- 普通绑定 10,000 条场景已完成 27 类操作与保存重开，页面错误为空，原始夹具、撤销后模型和说话人配置一致。发现跳转和文字预览反馈时间的回退候选，继续用同一夹具、同一后端对照前后前端源码；不将其从报告中剔除。
- 混合 10,000 条场景同样完成 27 类操作及完整性校验。迁移场景在 `save-changed` 第二次正式采样返回 `false`，此前编辑操作通过；该轮未完成后续保存和重开，不记作整轮成功，继续单独核查。
- 同机前后源码各 5 次预览对照确认跳转回退可复现。CPU 记录发现卡片回收交替读取尺寸与替换节点，产生重复布局；改为先批量读取尺寸，IntersectionObserver 使用已提供的尺寸，再回收节点。此修正发生在正式矩阵之后，矩阵摘要必须保留实测源码版本，不能当作修正后的完整测量。
- 只批量读取尺寸仍未消除回退；CPU 行级采样进一步定位到 `getSelection()`，也会在替换后触发布局。补齐每批读取一次焦点和文字选区，回收时使用快照。最终源码的 799 项单元及 7 项交互回归通过，最终对照结果见下文。
- 新文字选区用例最初选中了默认 `user-select:none` 的普通标签，初始选区就为空。测试改为显式可选标签以单独验证保护规则，并保留初始和滚动后选区文本断言；没有为测试改产品的卡片交互。
- 首轮保存专项 5 次成功，但重开断言比较了保存后已清除 `_dirty` 的内存对象，失败差异仅为该标记。后续验证按保存契约排除这一显示状态，继续比较完整正文、时间、轨道、绑定、样式与标记，并同时核对磁盘文件；初次失败日志保留。

## 最终结果与交付边界

原始矩阵在 `output/perf-ui-20261108-final`，可提交摘要为 [INCREMENTAL_UI_20261108.json](performance/INCREMENTAL_UI_20261108.json)。矩阵沿用第一阶段工具、每项预热 1 次和正式采样 3 次；对照第二阶段实测版本。普通／混合工程各 27 类操作完整通过，撤销还原、原始夹具未变、说话人配置还原和保存重开一致。迁移工程在保存处中止，保留已通过的编辑采样及失败记录，未补造缺项。

DOM 下降约 75%，不等于整个浏览器内存下降 75%。普通工程 100 组粘贴同步中位数 3,283 → 1,367 ms，切分 5,328 → 1,896 ms；混合工程 100 组粘贴 3,027 → 1,799 ms，切分 4,627 → 1,844 ms。普通剪切 2,365 → 2,408 ms 没有改善。它们来自回收布局修正前的完整矩阵，不能当作最终源码重新跑完的矩阵。

后续专项沿用同一夹具、同一后端，分别替换前后前端源码；各 1 次预热、5 次有效采样，另一次 CPU 采样不纳入中位数：

- `phase3-recheck-bound-v6` 曾在文字预览等待处中止，保留失败日志；没有更改产品源码或放宽断言，`v7` 复跑通过。该次未采集到足够现场，暂不归因为某一服务或组件，纳入预览稳定性后续检查。
