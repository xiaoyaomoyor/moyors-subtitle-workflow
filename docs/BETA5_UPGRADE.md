# beta.5 升级与新增功能

MSW 1.6.0-beta.5 按固定的 MAW beta.5 引用适配，保留 MSW 混合输入启动器、编辑器直接 ASR、翻译、配音和素材库。升级前备份工程、同名 `.assets` 与原媒体；旧版仍可保留用于回退。

## 叠加字幕

叠加轨用于同时出现的旁注、第二位说话人的重叠对白等，与译文副字幕和音频贴片不同。工程沿用上游 `moy.asr.project.v1` 与 `overlay_track` 字段。启用后可在列表／波形编辑、拆分合并、禁用、转轨、保存和撤销；关闭只隐藏内容，不删除数据。

- SRT 和启动器的文本模式 ASS 导入最多分为主轨与叠加轨；第三层重叠明确报错。ASS 导入仍是文字／时间导入，不是完整样式往返。
- 主轨与叠加轨通过明确的右键转轨操作切换；Shift 继续多选，Ctrl/Cmd+Shift 继续选择波形时间范围。轨内碰撞不会静默覆盖字幕。
- 转轨保留稳定 ID、已有配音素材及贴片。原副字幕绑定按转换结果解除，副轨文字保留，整次操作可以撤销。
- 启用的叠加轨参与字幕、源媒体时间线、含配音时间线及视频烧录导出；关闭的轨道不输出。允许主轨为空而叠加轨有内容。
- 当前 TTS 与翻译的对象仍是主／副字幕。选中叠加字幕时明确提示范围，不自动改成处理主轨。

## ASS 样式库与旧工程

新工程的 ASS 模式默认关闭，旧 CSS 预览和 MSW 视频压制样式继续使用。ASS 预览开关与“导出使用样式库”是独立选择：只开启预览不会改用新导出样式。

在编辑器 ASS 样式设置中管理字体、描边、阴影、对齐及动画；明确启用“导出使用样式库”后应用所选方案。视频导出冻结任务开始时的库副本，之后修改样式不会改变在途任务。Launcher 的 SRT 压制也提供独立选项，默认关闭；ASS／SSA 文件使用文件内样式。

本机 Server 编辑器与 Launcher 共用 MSW 用户目录中的 `ass-styles.json`，缺失时可读取旧 MAW 配置，原文件不移动。便携 HTML 使用浏览器副本。样式库和字体不是随所有工程自动打包的可移植资源；换机器需检查字体及样式。浏览器预览不等于完整 libass 动画渲染，最终烧录以 FFmpeg 结果为准。

FCP7 XML 默认勾选实验性原生文字，关闭后字幕轨选择禁用；序列尺寸、帧率和文字变换字段已补齐。Lottie／OGraf 尺寸默认跟随媒体，也可输入 16–7680 的整数宽高。剪辑软件的实际导入效果仍需在目标软件验收。

## 本地识别与模型准备

Launcher 的识别模块与编辑器「媒体 → ASR」都可选择本地模型，无需 API Key。FireRedASR2-CTC 使用 CPU，可选 ct-punc 标点；识别模型可用和标点组件可用分别检查。关闭标点无需下载 ct-punc。

1. 在设置或编辑器 ASR 环境配置中安装／修复本地运行环境。
2. 显式下载需要的识别模型、对齐器或标点组件。打开面板和查看状态不触发模型下载。
3. 准备完成后刷新状态，选择设备和模型目录，再启动整段或片段识别。
4. 编辑器沿用结果预览、手动应用、冲突检查、一次撤销与取消机制；任务结束不会静默覆盖已编辑内容。

普通本地运行环境升级到 v7，增加 sherpa-onnx 与 soundfile；旧环境按提示修复。MOSS 继续使用独立环境，其识别结果需要对齐时调用普通本地运行环境，避免混用 Transformers 版本。运行环境安装与大模型下载是两步；模型不随标准或 lite 主程序包附带。

## 字词时间码

Launcher「实用工具 → 字词时间码」支持已有 MOSP／JSON／SRT：选择 Qwen Forced Aligner 或 FireRed CPU，对已有字幕补 `items`。默认只补主字幕缺失时间码；“重新生成”才覆盖已有时间码。

默认使用工程源音轨（无记录时使用媒体默认音轨）。选择副字幕或叠加字幕时，必须明确指定与其文字对应的媒体及音轨编号，编号从 0 开始；译文不可直接拿原声强行对齐。SRT 本身不能保存字词时间码，结果写入新 MOSP，不覆盖输入工程。失败段保留原字幕范围并显示警告；可取消，取消后的迟到结果不会写回工程。

识别模块的“识别后补齐字词时间码”仅处理本次新识别的原声文字。FireRed 对齐包含文本匹配和插值，时间点不保证都是直接声学测量。静音、错误文字或全失配应检查警告与实际音频。

## 对比与调试

Launcher「实用工具 → 字幕对比」可打开两个独立离线 HTML：转写文本对比、字词时间码查看与对比。可直接在浏览器打开 `tools/compare.html` 和 `tools/timestamp-compare.html`，读取 SRT／MOSP／JSON；对比不上传或修改输入。文本工具支持多文件、基准切换、搜索、差异及时间分布；时间码工具支持单／双工程、字词展开和缺失／越界筛选，兼容上游嵌入报告。

调试运行保存云端响应或本地中间数据。启用输出子文件夹时进入 MSW 的 `调试`／`debug` 子目录；旧 MAW 工程和缓存仍可读，不自动移动旧文件。

同工程在相同地址恢复编辑器服务时，Launcher 不再重复打开浏览器页；新工程或新端口仍打开对应目标。恢复后原页若提示会话已变更，先保存未保存内容，再按提示刷新；可随时使用“打开编辑器”显式打开页面。
