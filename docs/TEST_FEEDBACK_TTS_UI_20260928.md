| --- | --- | --- |

| 新引擎布局对齐百炼 | 已修复 | 模型／语言双列，音色搜索与选择同一卡片，当前音色及可用试听在底行；不为无试听引擎发起付费试听 |

按顺序处理，每项记录实际测试与未验证边界。

后续实测更正：用户仍遇到目录被遮挡，最终改用专属原生所有者与显示期层级检查，见 [目录与工程清理复查](TEST_FEEDBACK_PICKER_REGISTRY_20260928.md)。下述首次实现的单次冒烟不足以覆盖延迟层级重置。

窗口前置：通过本进程、创建线程限定的窗口显示事件，仅前置本次原生对话框。实际 Windows 冒烟确认 visible/topmost/foreground 均为 true，取消后回收钩子；不改变浏览器或系统全局置顶配置。

音色卡片：Edge、MiniMax、Mossland、GPT 采用与百炼同样的背景、描边、纵向搜索和选择、当前音色底行；GPT 的已有参考试听位于底行右侧。没有供应商现成试听的引擎不发起试听合成。模型、语言及其他参数保持双列。云端与 GPT/Edge Chromium 布局及合成回归记录见后续汇总。

Mossland：已核对官方单人语音 API。MSW 不设置强制时长、不拼接尾部文字，原实现仅将服务返回完整 WAV 转码；现象更像生成模型续说，但缺少该次原始返回与明确模型 ID，不能认定具体原因已复现。补充可选 expected_duration_sec（0.1–600 秒），默认不传，随配方保存并用于重生成，提供帮助提示说明非硬性上限；不自动裁切／重试收费。云端与目录 Python 14 项通过，包含短句原样提交和时长校验。

阶段验证：布局 Chromium 12/12、Node 441/441 通过；已查看 MiniMax、GPT 与窄屏截图。扩大回归发现旧用例依赖空选区处理全文，正逐项更新为显式选择；同时补充点击菜单后同步刷新处理范围。新增空选区无请求与 Mossland 时长随重生成保留的浏览器检查。


选择范围修正已完成：核心快照只接受明确选择的字幕，未选择时禁用开始并禁止发送请求；全选后仍可处理全文，独立草稿无须选择字幕。菜单点击后更新范围；面板内点击不额外刷新批次记录，避免在单选 change 之前重建 DOM。旧测试全部／单字幕流程均改为显式选择，保留取消、恢复、字幕绑定与再生成断言。

回归过程与结果：
- 首轮 Chromium 116 项：98 通过、18 失败。主要为旧夹具依赖无选区全量处理，另有旧范围文案、字幕块定位以及程序化清除选区未触发用户事件。按真实新交互更新夹具。
- 第二轮 47 项：37 通过、10 失败。IndexTTS 14 项、云端 8 项、草稿工作区 8 项全部通过；翻译失败定位为新增 click 刷新抢在批次 radio change 前重建控件，已限制为面板外点击。
- 最终翻译／处理记录／GPT 与 Edge 回归：28/28 通过，覆盖所有上述翻译失败项、空选区阻止提交、明确全选及窄屏布局。
- Python 云端参数与原生目录协作测试：14/14；Node：441/441；Ruff、修改文件 JS 语法、UTF-8/LF 和 git diff --check 通过。便携编辑器由 edit.py --blank 重建。
- 额外百炼音色管理回归 11/11 通过。油库里可选实机夹具同步改为显式选择，本轮未重新运行真实资源包；公共范围核心已覆盖。

未验证边界：不读取用户密钥或调用真实收费接口。用户提供短句的 10 秒结果未取得原始响应及模型 ID，无法确认该音色实际改善程度；期望时长是供应商提示而非终止保证，不将异常续说标成彻底修复。MiniMax 网页声贝与开放平台普通 API Key 的计费范围以官方语音付费协议及开放平台定价说明分别解释。

收尾：本轮所需代码、文档和生成页面均已完成；以上真实付费音色质量属于未验证边界，保留原始 .test-appdata 内容，未纳入改动。
