## 推荐实施顺序与验收范围

1. 编辑可靠性小修：取消正文编辑的重做保留、延迟光标回调失效；同步核查拖动取消和保存状态，但只修复实际存在的问题。对主／副字幕、虚拟列表、剧本草稿和 v4 保存重开做定向回归。
2. 本地模型可靠性：目录记忆、HF／ModelScope 双源和完整缓存复用、MOSS 环境升级，随后 Qwen macOS 设备策略。覆盖取消、切换模型、重开、坏目录、缺依赖、旧安装修复及冻结包导入；实际下载需独立验证，不能只靠模拟响应。
3. 字幕输出小修：最终缺字诊断、macOS FFmpeg 完整版路径发现；验证正常 fallback 不误报，以及 MSW 标准／lite 和各平台行为。
4. 识别质量增强：插值切点吸附。用合成音频覆盖明显低谷、平坦波形、短片段、无依赖、已有字词／原始边界和时间偏移；保证没有新交叠或零时长。保留 MSW 800ms 默认。
5. 对最终选入内容做 MSW 回归，再确定下一次版本和发布范围。本轮没有修改版本，也没有实施上游功能。

描边／阴影不透明度可后排；独立标记层、完整标点清单和失败批次主动跳过需要另行设计。ASS 第二预览、AI 口播、LRC、绿幕输出及上游整体重构不列入推荐范围。

## 定向确认记录

- 使用隔离配置、合成字幕和已安装的 Chromium，在当前 MSW 代码生成的临时页面中诊断，不修改产品文件。取消正文编辑：撤销后重做数为 1，编辑后 Esc 取消，原文恢复但重做数变成 0，确认同类缺陷。
- 延迟光标定位：确定性地延后双击修正回调，期间派发新输入事件并将光标移至字符 2；旧回调执行后，光标从折叠位置 2 变成非折叠选区，确认旧回调仍会覆盖后续用户动作。这是合成事件诊断，不是声称人工稳定触发了毫秒级竞态。
- 首次浏览器诊断因默认路径映射找不到浏览器，指定现有路径后又受执行环境限制；在获准的本机执行中可正常启动。首轮操作因撤销清除当前选择而在填入文字时超时；补上重新选中字幕后完成诊断。上述尝试均不计作通过。
