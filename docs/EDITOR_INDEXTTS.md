# 编辑器 IndexTTS 2.5 配音

「媒体 → TTS → 引擎 → IndexTTS 2.5（本机服务）」连接已安装并启动的官方 IndexTTS WebUI。MSWE 不安装模型、不启动第二个模型进程，也不需要百炼 API Key。IndexTTS 的模型和依赖继续由独立安装环境维护。

更新 MSWE 后，先重启 **MSWE 编辑器服务** 再刷新网页，让 Python 后端和前端一起更新；已经运行的 IndexTTS 服务可以继续使用。

## 首次合成

1. 在「编辑 → 全局设置 → 环境配置 → TTS」选择 IndexTTS，在连接设置填入本机地址，默认 `http://127.0.0.1:7860`，点击「连接／检测」并保存环境配置。支持本机回环 HTTP 地址；不接受远程服务或任意文件路径。
2. 回「媒体 → TTS → 合成设置」，第一行选择「音色参考来源」（官方示例／本机音频）或已保存的配音预设；第二行选择情感控制与配音语言。下方音色框按名称或语言搜索并选择，搜索不会清除当前音色。自己的参考音频在全局环境配置的「参考音频」中上传。官方示例来自当前服务实际提供的示例集；选择示例只更换音色，不套用示例台词、情感和语言。示例语言不限制配音语言。
3. 选择配音语言、情感方式和语速。点击「保存合成设置」记住默认参数；不保存也能用当前配置合成。高级生成参数和预设添加／重命名／移除集中在全局环境配置，面板仅应用已保存预设。
4. 选择主／副字幕或「字幕编辑器内容」独立草稿，点击「开始合成」。无选区时处理指定整轨；绑定与独立字幕沿用[对象选择规则](EDITOR_TTS.md)。每条字幕或一份草稿生成一个完整 WAV，完成后进入素材库。

参考音频支持 WAV、MP3、FLAC、M4A、AAC、OGG、Opus，最大 32 MiB；非标准 PCM WAV 的格式需要已配置的 FFmpeg 转换。建议清晰、单人说话、少背景噪声；IndexTTS 2.5 的音色和情感参考均最多使用前 15 秒。MSWE 保留完整参考文件，原文件不变。「当前音色」右侧的「试听参考」和情感参考试听均自动打开素材库，使用底部播放器，可暂停／拖动进度；不新增素材或发起 IndexTTS 推理。

## 情感、时长与高级参数

| 控制 | 行为 |
| --- | --- |
| 跟随音色参考 | 默认，使用音色参考自带情感 |
| 情感参考音频 | 独立选择情感音频，可采用服务的官方情感示例或自行上传；情感权重 0–1 |
| 八维情感向量 | 喜、怒、哀、惧、厌恶、低落、惊喜、平静，各为 0–1；IndexTTS 自行完成偏置与归一化 |
| 情感描述文本 | 实验功能，填写中文／英文描述；留空时逐条使用实际配音文本判断情感，需要服务加载 QwenEmotion |
| 情感随机采样 | 用于向量／文本模式，让同一配置产生不同的情感采样 |
| 配音语言 | 中文、英文、日文、西班牙文、阿拉伯文，与官方 2.5 接口一致 |
| 语速 | 50%–200%，100% 正常，数值越大越快；发送给模型的时长系数为 `100 / 语速百分数`。未拖动滑条时精确保留已有时长系数，不因界面取整改写。不是精确填满字幕，也不自动裁剪音频 |
| 高级生成参数 | `do_sample`、Top P、Top K（0 表示不限）、温度、长度惩罚、束搜索数、重复惩罚、最大音频 Token 数、每段最大文本 Token 数 |

高级参数采用官方 WebUI 默认值；最大 Token 数同时受当前服务能力约束。将最大音频 Token 数设置过低可能导致模型在长句结束前停止。每条字幕仍限制 600 字符，较长内容先拆成多条；IndexTTS 在每条内部如何分段由它自己的模型处理。

### 当前服务没有文本情感

MSWE 在独立 Gradio 会话中检测实际能力；如果没加载 QwenEmotion，文本情感选项会禁用，不会悄悄换成另一种情感模式。官方 WebUI 会在较低显存环境中默认不加载这个模型。

需要文本情感时，在 **IndexTTS 自己的启动命令** 中加入 `--qwen_emo`，重新启动该服务，再回 MSWE 点击「连接／检测」。例如官方源码环境可使用：

```powershell
uv run webui.py --version 2.5 --host 127.0.0.1 --port 7860 --qwen_emo
```

应先结束原来的 IndexTTS 服务，再用适合原安装环境的启动方式运行；整合包需要在它的启动入口传递该参数。启用该模型会额外占用内存／显存。MSWE 不自动重启用户的模型服务。

CPU／GPU、精度、CUDA／DeepSpeed 加速等属于 IndexTTS 进程启动和模型加载配置，官方生成接口不能在每条配音时切换。本次接入覆盖其 2.5 WebUI 公开的生成参数；未暴露到 WebUI 的底层推理开关不伪装为可用选项。

## 预设与读音修正

全局环境配置中的「配音预设」分为两类；保存后可回合成面板选择并应用：

- **MSWE 本机预设**：保存音色和情感参考、语言、语速对应的时长系数、情感和全部高级参数。填写名称后保存，也可选择已有预设重命名或移除；回 TTS 面板在「配音预设」中选择即应用。移除预设保留参考文件与已生成素材；覆盖同名预设需要确认。
- **IndexTTS 服务预设**：从当前服务中读取用户已保存的预设，点击「载入服务预设」后复制参考并应用其参数。官方旧预设不保存语言和时长系数，因此保留面板当前的这两项。MSWE 不改写服务的预设目录。

如果服务在载入时警告参考缺失或文本情感模型未加载，MSWE 保留当前参数并提示检查，避免采用服务自动降级后的预设。

当最终操作对象只有一条字幕时，会出现「读音修正（可选，仅此次配音）」。可填写这一条实际要说的完整文本，保持字幕原文不变。IndexTTS 2.5 支持例如 `银<行|HANG2>` 的拼音标注、英文 CMU 音素与日语假名；格式参阅[官方 2.5 说明](https://github.com/index-tts/index-tts/blob/main/docs/README2.5_ZH.md)。此处修改只进入任务快照和素材的实际配音记录。2.5 WebUI 没有旧版的术语词表管理功能，MSWE 不启用那个接口。

## 保存、取消与素材去向

以下路径均相对于 MSWE 本机应用数据目录，不是当前工程目录：

| 位置 | 内容 |
| --- | --- |
| `tts-engine.json` | 当前 TTS 引擎偏好，兼容读取旧油库里设置中的偏好 |
| `index-tts/settings.json` | IndexTTS 连接地址、等待上限和上次保存的配音参数 |
| `index-tts/references.json`、`index-tts/references/` | 已选择／上传的参考名称、摘要、音频信息及按内容摘要保存的 WAV；相同内容复用 |
| `index-tts/presets.json` | MSWE 完整配音预设 |

工程中的 `generation` 保存本次生成参数、参考 ID／名称／摘要、原字幕和实际配音文本；连接地址、服务返回的绝对文件路径和参考音频字节不会进入工程。生成结果与其他引擎相同，存入素材库，保存时收集为工程旁 `.assets/audio/` 下的 WAV。可以直接放入贴片、混音、导出音频／视频／OTIOZ。

**已有结果跨机器可用，重新生成需要参考库。** 自动素材收集包括生成的 WAV，不包括 IndexTTS 模型或本机参考库。换机器后如需复现，可同时搬移本机 `index-tts/` 目录并重新配置服务，或重新上传参考音频。按内容摘要识别同一份参考，合成过程中再次校验文件完整性。

任务使用独立 Gradio 会话，逐条进入官方队列，避免与用户的 WebUI 操作混用状态。取消只针对 MSWE 提交的事件，后续字幕停止，晚到结果不入库；正在进行的同步 GPU 推理可能仍需完成，MSWE 不终止整个服务进程。排队和合成都计入单次等待上限（默认 600 秒，可设置 60–3600 秒）。服务报错或连接中断时不自动重试；可检查服务窗口后在合成记录里重试未完成项。

## 兼容与验证

接入契约按官方 IndexTTS 2.5、Gradio 5.45 的 26 参数 `gen_single`、参考上传和队列接口核对；接口不兼容时提前提示，不猜测参数位置。资源与安装方法见 [IndexTTS 官方仓库](https://github.com/index-tts/index-tts)。MSWE 没有捆绑或复制其模型、示例资源或运行环境代码。

实现验证包含本机真实的默认跟随、情感音频、八维向量、时长系数合成，以及隔离服务的四种模式／错误／取消／浏览器与保存测试。检测到的用户进程未加载 QwenEmotion，故没有将模拟测试冒充文本情感的本机实际推理验证。
