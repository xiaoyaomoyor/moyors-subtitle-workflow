# Edge TTS 配音

在 TTS 面板选择“Edge TTS（在线）”。这是联网服务，无需 API Key，不是离线引擎。

“全局设置 → 环境配置 → TTS 环境 → Edge TTS”提供依赖状态、连接检测／刷新音色以及等待上限。源码环境随 `uv sync` 安装锁定的 `edge-tts==7.2.8`；发行包包含适配器和依赖版本元数据。

在配音面板按语言筛选或搜索音色。生成语言由音色决定，不另设容易冲突的语言参数。列表缓存保存在本机，刷新失败不会删除缓存或当前音色。当前所选音色即使被筛选条件排除仍保留，避免无意更换声音。

| 参数 | 单位与范围 | 默认 |
| --- | --- | --- |
| 语速变化 | −50%～+100% | 0% |
| 合成音量变化 | −100%～+100% | 0% |
| 音高变化 | −100～+100 Hz | 0 Hz |

这里的音量写入生成音频，与编辑器的试听音量、贴片增益分别保存。每段最多 600 字符；支持主／副字幕、独立草稿与批量分段。

网络音频收集完成后由 FFmpeg 转成统一 PCM WAV，再进入素材库。中断、空音频、转换失败均不会登记成功素材。可以取消等待中的联网任务；失败后手动重试，不自动反复发送。实时流式播放、SSML、声音克隆与情感参数不属于该引擎的面板功能。

生成素材可以下载、打包、插入时间轴、参与混音导出；“重新生成”保留当时音色和三个参数，素材库新增结果，贴片入口按现有替换规则处理。

接口依据：[edge-tts 7.2.8 源码](https://github.com/rany2/edge-tts/tree/7.2.8)。在线服务可用性取决于网络及上游服务；本轮实际验证了中文、英文、日文短句和音频转换。
