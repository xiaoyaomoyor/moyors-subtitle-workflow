## 基线

- 开始时工作树仅有既存 `debug.log`、`.test-appdata/`、`output/`，均不纳入提交。
- 上轮全量 Python 有 1 项既存波形回退测试失败，详见上轮记录；本轮结果另记。
- 长工程副本、同一浏览器 CPU 采样条件：原预览请求约 1.72 MB，响应约 22 秒；初版优化后约 33.8 KB，响应 0.21–0.60 秒。该数字含本机负载／采样开销，不作为所有工程的固定延迟保证。
- 原代码清空 ASS 几何时，避让模块把空数组当成没有精确预览，进而测量整工程 HTML 字幕；已改为精确渲染下接受合法的空几何。
