# 素材库：音频与字幕

素材库的筛选栏依次为类型、批次、搜索和刷新。可显示全部、音频或字幕，搜索覆盖字幕文字、配音文字、音色和外部文件名。一条字幕对应一张卡片；同次复制或多文件音频导入归入同一批次。

单击卡片选择，Ctrl（macOS 为 Command）切换选择，Shift 连选。翻页保留选择，修改类型、批次或搜索会清空选择；已选数量始终显示在统计中。选择使用「选区」色描边，复制字幕原有颜色作为淡色背景。点击卡片的操作按钮不会意外切换一批选择。

## 字幕素材

在波形字幕块右键选择「复制到素材库」。复制遵循当前主副字幕选择；同时选中主副字幕时分别生成卡片，完整配对会保留。原字幕不变，系统剪贴板不受影响。

单选字幕素材后，字幕编辑器显示「字幕素材 · 独立编辑」。铅笔按钮可聚焦文字框；修改只影响该素材，不改原字幕，也不改已经插入时间线的副本。完成编辑、切换目标和保存时都会提交输入，输入停顿时也会保存。素材文字修改可撤销；原逐字时间随文字修改清除。

单条的「放入时间轴」按钮或多选后的「放入所选字幕」从播放头开始插入；也可拖动字幕素材到波形，以落点开始。最早一条对齐锚点，其余保留原时间间隔，例如原 10–12 秒和 15–17 秒，在 30 秒插入后为 30–32 秒、35–37 秒。

原副轨存在时继续放入该副轨；原副轨不存在时选择目标副轨，没有任何副轨时先创建副轨。不会自动把副字幕变成主字幕。不同来源的素材需分批放入。

与同轨现有字幕或所选素材彼此重叠的条目都跳过，其余正常插入；详情列出原因。主副轨同时出现不算冲突，首尾相接也不算重叠。完整配对的双方均成功插入后才恢复绑定。插入整体可撤销，素材仍留在库中。

字幕素材与批次保存在 `.mosp` 工程内，清空时间线不会删除素材。保存、另存为和恢复草稿均保留素材，编辑器内可复制/编辑/插入字幕而无需源视频或后端音频服务。

## 音频与显示设置

音频保留试听、单条 WAV 下载、放入时间线和删除操作。媒体 → 素材库设置或模块右键设置中，可调整卡片密度、显示搜索筛选、显示底部试听栏。隐藏试听栏后，卡片仍可播放/暂停，正在播放的音频不会因隐藏而停止。

素材统计后显示移动工程的 `.assets` 提醒。需要搬移音频时保留工程旁的 `.assets` 文件夹，或使用「导出工程与音频素材包」。字幕素材本身不依赖音频目录。

## ASR 结果与音频批量操作

ASR 面板可识别源视频、时间选区或所选音频贴片。识别后选择「存入素材库」，同次操作归为一个批次；部分完成可先入库，后续结果继续追加，重复点击不重复创建。素材保留原时间，仍按播放头加相对间隔放回时间线。详见 [编辑器 ASR](EDITOR_ASR.md)。

多选音频后点击「导出所选音频」，下载仅包含所选完整 WAV 的 ZIP。同一素材只导出一次；文件名保留原名／简短配音文字并加序号。导出不使用时间线裁剪或增益，不包含整份工程。缺失或变化的文件会使本次导出中止并列出原因；单包最多 10000 条、512 MiB，超过时分批导出。

音频卡片的重新生成图标调用该素材原来的服务与模型，保留音色、语言、语速、读音指示／实际发音文本等配置；使用当前全局环境中的鉴权。外部音频和缺少配方的旧素材禁用此按钮。新结果作为新批次入库并记录来源素材，不修改原素材和任何贴片。调用服务可能产生相应费用，具体按所选服务计费。

提交响应丢失时原卡片提示「继续确认本批任务」，再次点击复用原请求身份；不要另建任务来确认同一次提交。时间线音频批量操作中的重新生成仍按原规则替换贴片，两条入口共用任务执行流程。
