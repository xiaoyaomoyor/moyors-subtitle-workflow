# 视频与配音剪辑工程导出（D3 / D4）

从启动器打开本机 Server 编辑器，需要 FFmpeg 和 FFprobe。便携 HTML 仍用于编辑和已有前端导出，不执行后台媒体渲染。

## 导出视频

在「文件 → 导出视频」打开窗口。默认把所选原声音轨与时间轴配音混合；也可以选择仅配音来关闭原声。原声／配音增益、四种试听音量同步方式、采样率、源时间范围、空隙移除和峰值保护与[音频导出](EDITOR_AUDIO_EXPORT.md)相同。默认不采用播放器的临时音量与静音，选择同步后采用提交时快照；播放速度不影响结果。

成品为 MP4，画面 H.264、声音 AAC 192 kbps。新任务默认下载名称为“工程名_MSW.mp4”，配音剪辑工程为“工程名_MSW.otioz”；名称在开始导出时固定。导出窗口的“跳过空隙”每次打开默认不勾选，不继承播放跳过设置。画面编码默认「自动（推荐）」：完整画面为兼容的 H.264 / yuv420p 且不烧录时直接复制；裁切、跳过空隙、延长或烧录时优先使用通过短编码检测的硬件编码器，编码失败会改用 CPU 重试整个画面阶段。明确选择「硬件编码」时不静默回退；不可用或失败会提示。多个可用硬件编码器时才显示选择项。选择「软件编码（CPU）」时始终使用 libx264、medium、CRF 18。硬件支持 NVIDIA NVENC、Intel Quick Sync、AMD AMF；各自使用适合该编码器的质量参数，不承诺相同文件大小或画质。字幕仍由 CPU 的 libass 渲染，再送编码器压缩。保留可用的源帧率比例，不能确定时使用 30 fps；视频切点按累计帧边界取整，声音保持采样精度，画面边界可能相差半帧。

「导出范围对齐」默认 **对齐至视频**，提供三项：

- **对齐至视频**：画面结束时结束成品，超出的音频裁去，不足的音频补静音。
- **对齐至音频（定格）**：按所选音频结束位置导出；画面不足时延长末帧，画面较长时裁切。
- **对齐至音频（黑屏）**：按所选音频结束位置导出；画面不足时补黑屏，画面较长时裁切。

混音以当前选择的原声音轨与未静音配音的最晚结束位置为准，仅配音时只计算配音。自定义源范围仍作为边界，之后应用空隙移除；字幕末尾不会单独延长成品。不按音量自动裁掉素材内的静音。没有可用音频内容时，两种音频对齐提示改用视频对齐或调整范围。选项旁的提示图标显示所选音频与视频在源范围内的末尾差，以及三个选项的简要说明。

「烧录字幕」默认关闭，可选择主字幕、副字幕或主副双字幕。开启后，「字幕样式」直接列出「跟随工程样式」及所有内置／用户预设；导出面板不提供临时样式编辑。选择烧录后，现有播放器显示本次字幕内容及样式，并标明「导出预览」；关闭面板恢复此前的工程或校对预览。本次预设不会修改工程，开始导出时固定任务快照。

字幕外观统一在「媒体播放器设置 → 字幕样式」管理。工程样式随 `.mosp` 保存，预设库供不同工程复用；修改预设不会悄悄改变已应用到工程的样式。播放器默认跟随工程，也可选择内置或用户预设用于校对，界面明确标注「仅影响预览」。本机视频使用离线 libass 渲染与实际烧录共用的 ASS 内容；缺字体会显示回退提示。便携 HTML、纯音频或不支持 WASM 的环境使用明确标注的近似预览。这里预览字幕外观，不代替导出的剪辑、空隙移除和音频混合。

字幕随指定范围、空隙移除和分块编码同步裁切，已禁用字幕不输出。选择的轨道在导出范围内没有字幕时会提示。压制会重新编码画面，需要 FFmpeg 的 libass 支持和能显示目标语言的系统字体。表情包不烧录。HDR 重新编码涉及色彩转换，当前会明确拒绝；请先转为 SDR。原文件始终不会被覆盖。

## 导出可继续剪辑的工程

入口是「文件 → 导出字幕 → 更多导出 → OTIO → 配音剪辑工程（OTIOZ）」。原有的源媒体 OTIO、源媒体 OTIOZ、表情包导出和 FCP 7 XML 保持各自范围；它们不会自动包含新增配音。

新 OTIOZ 窗口提供与音频导出相同的范围、空隙、原声和配音选项。包内包含：

| 内容 | 用途 |
| --- | --- |
| `content.otio`、`version.txt` | 标准 OTIO 时间线和包版本 |
| `media/voice-*.wav` | 独立配音片段；裁剪、贴片增益、轨道增益、配音总增益及峰值衰减已写入 32-bit float WAV |
| `media/original-*.wav` | 所选原声音轨的独立片段，已处理增益与空隙；不会混入配音 |
| `media/source.*` | 勾选「同时打包原视频」时收集的原画面文件 |
| `originals/*.wav` | 本次时间线使用的原始 TTS，包括静音片段的原始声音，保留进一步重剪与替换的可能 |
| `reference/mix.wav` | 同一快照的混音试听参考；不作为额外音轨导入，以免声音重复 |
| `subtitles/track-*.srt` | 按同一空隙和范围映射的主／副字幕；时间线中另带字幕标记 |
| `msw-export.json` | 原始 TTS 配方、贴片来源、采样裁剪、导出计划与峰值衰减记录；不是 MSW 保存工程 |

重叠配音自动分到同一配音轨下的不同 OTIO 音轨，允许同时发声。跨移除空隙的片段会拆分，调整对应素材入点。只收集本次范围内的配音及其原始 TTS，不包含素材库未使用的音频；这与 D0 保存时收集全部登记 TTS 的用途不同。

静音片段保留位置和禁用标记，但 WAV 本身也写成静音，避免不识别静音标记的软件意外播放。若在剪辑软件中需要恢复声音，请从 `originals` 重新链接原始 TTS，并按 `msw-export.json` 恢复裁剪与音量；仅解除禁用不能让静音副本恢复声音。原始音频不带本次导出增益。

峰值保护先测量完整混音，再把同一个衰减值应用到每个可编辑片段。使用浮点 WAV 保留分轨电平的余量，避免逐轨硬削波改变最终混音；后续移动或叠加更多片段时，需在剪辑软件中重新检查成品峰值。

默认打包原视频，所有时间线媒体引用都指向包内相对位置，可以搬移。取消勾选后仍导出音频素材，但视频引用当前硬盘的绝对位置，需要在其他机器重新链接。纯音频项目没有原视频文件可收集。OTIO 时间线允许配音超出画面，此时尾部视频轨留空，不生成定格画面。

支持 OTIOZ 的软件可直接导入；只支持 OTIO 时，将包作为 ZIP 解压后打开 `content.otio`，保持旁边 `media` 目录的位置。字幕是标记和 SRT，不承诺导入后的字幕字体、位置、表情包或其他视觉效果一致。

## 任务与保存

三个导出窗口共用同一个本机队列，按开始时的快照执行；关闭面板不取消任务，后续编辑不修改正在导出的文件。可查看实际使用的编码器、回退说明、进度、取消和下载，刷新后仍可找回同一端口的近期记录。编码阶段根据 FFmpeg 已完成帧数估算“预计编码剩余约”，不包含后续音画合并；开始采样不足时显示“正在估算”，超过 15 秒未更新进度时停止显示旧估算，合并时显示“正在收尾”。估算会随画面复杂度和设备负载变化，不保证总导出时间。新旧工程任务不会相互写入。

成功文件以流式下载交付，任务结果仍保存在本机 `editor-exports/port-<端口>/`，和 WAV 共用约 20 条／约 2 GiB 的清理规则，最新大文件单独保留。取消、服务重启或失败不会发布不完整成品。成品不自动加入素材库，也不由 D0 工程保存收集；需要长期保留时及时下载。

视频按连续保留区间流式编码，不再每 30 秒重新启动编码器；CPU 解码／编码线程使用逻辑核心的一半、至少 1 个且最多 8 个，保留编辑余量。配音继续使用有界混音器；OTIOZ 音频按素材分组逐条解码和写包，原视频以流式复制收集，浏览器不持有整个成品。仍需要临时磁盘空间。源时间轴上限 12 小时，参考 WAV 受 4 GB 限制；OTIOZ 最多 10,000 个切分配音片段、每个配音轨最多 256 个重叠子轨，过大时请分范围导出。

## 验证边界

Windows 合成媒体已覆盖真实编码、非整数帧率、空隙切点、尾段、画面延迟、配音位置、峰值和素材搬移。OTIO 官方解析器用于校验包结构和媒体引用，逐轨求和与参考混音另有采样比较。

尚未在 DaVinci Resolve、Premiere 等外部剪辑软件中逐项验收，也未做小时级项目压力测试、其他操作系统或打包发行版验收。不同软件可能将音频位置吸附到视频帧、改变声道映射或解释标记方式，导入后请以包内参考 WAV 检查实际结果。

本轮 Windows 实际检测与字幕烧录验证覆盖 Intel Quick Sync；NVENC／AMF 在测试设备上不可用，自动回退及明确硬件失败另以隔离测试验证，不能视为两种显卡的实机验收。编码能力检测使用合成画面，缓存五分钟；驱动或 FFmpeg 更新后可重启服务重新检测。
