# 升级到 MSW 1.6.0-beta.6

升级前备份 `.mosp`、对应 `.assets` 和原媒体，保留 beta.5 安装目录以便回退。MSW 按自身编辑器与配音工作流适配上游 MAW beta.6，继续读取上游工程文件。

## 设置与工程兼容

- 未配置过输出选项时，默认输出到 MSW 子目录并保留后处理中间产物；已保存的关闭值、自定义路径不变。
- 新目录使用 `_msw`／`视频名_msw`，继续读取 `_maw` 和旧路径，不自动移动旧文件。
- 新后处理运行先保存 0 号原始工程和 SRT，之后按实际产物编号。旧运行目录及 manifest 继续恢复，不补写或重排历史文件。
- 保留字幕稳定 ID、副轨、叠加轨和配音资产；修改来源文字后保留贴片并提示复核，避免默默丢失配音。

## 编辑与导出

主、副、叠加及绑定字幕可拆分并保留原文，清除不再有效的字词时间码，支持一次撤销。原有中缝联动、Shift 多选和 Ctrl/Cmd+Shift 波形选区保持。

播放中点击暂停是可选设置，默认关闭；兼容源媒体、虚拟配音时钟和多选。ASS 可仅为说话人名称与分隔符着色，正文保持基础色。新工程支持名称预览／导出联动，旧工程保持原显示状态，显式关闭的导出选择继续保留。导出任务冻结名称及样式快照，执行中修改设置不会改变已提交任务。

## 新增 TTS 与近期修复

编辑器整合百炼 Qwen、油库里、IndexTTS、GPT-SoVITS、Edge TTS、MiniMax 和 Mossland，复用配音草稿、字幕合成、素材库、贴片替换、取消与原配方重生成。GPT-SoVITS／IndexTTS 按需启动；已经外部启动的服务只连接，关闭 MSW 不终止它们。

Mossland 支持逐条跟随字幕时长，重生成保留已冻结的秒数；期望时长用于生成引导，不保证严格时长，不对所有引擎统一变速。MiniMax／Mossland 音色别名按账号保存在本机。合成记录按引擎批次展示，可独立折叠，轮询刷新保留展开状态。

未选择字幕时不自动合成或翻译全文，独立草稿仍可使用。已保存的密钥以占位提示呈现，留空复用，实际密钥不回填到页面。云端失败不自动重复计费提交。

安装包不包含模型、账号或额度。参阅 [本机 TTS 服务](EDITOR_TTS_LOCAL_SERVICES.md)、[Edge TTS](EDITOR_EDGE_TTS.md)、[云端 TTS](EDITOR_CLOUD_TTS.md)。完整变化见 [CHANGELOG](../CHANGELOG.md)。
