## 实现与边界

- `msw-find-edit.js` 统一筛选、可见区渲染和文字事务；后台匹配在 `msw-find-core.js`，整段分隔格式在 `msw-find-text-tools.js`。模板、样式和中英文提示同步更新。
- 逐条与整段保留同条换行。分隔行不能改名、增删或调换；结构修改继续使用切分／合并。混合选中状态显示半选框。
- 处理顺序：手工正文 → 替换 → 文字整理。应用后重置操作勾选以防重复添加前后缀。绑定伙伴不会被自动改字。
- 查询按原正文筛选，替换使用当前草稿；输入不会因不再匹配而突然失去焦点。
- 本轮不改用户工程，不调用识别／翻译服务。只在测试副本保存和导出。
