## 4. 分组升级清单

### 4.1 工程契约与叠加字幕轨

新增／修改 `maw/project.py`、`maw/postprocess_io.py`、`maw/project_preview.py`、`JSON_SCHEMA.md`、前端工程加载／序列化和历史记录。

- 保持 `moy.asr.project.v1`，采用上游公共 `overlay_track: {enabled, segments}`；轨内排序且不重叠，允许与主轨重叠。关闭时保留原数据，不显示／导出。没有该字段的旧工程按关闭且为空处理。
- 保留原有稳定 ID；缺失 ID 按上游叠加轨规则确定性补齐。颜色／表情包 `headIdx` 仅在本轨内解析；轨道转换、拆分合并、删除和撤销后不得悬空。
- SRT 导入最多拆成主轨＋叠加轨；第三层明确报错，不截断或静默丢句。需要顺序语义的文稿匹配继续严格拒绝重叠。
- MSW 新启动器另有 `_read_ass` 导入器，现状仅提取时间／文本、不导入 ASS 样式。必须同步给出一致的重叠处理／报错，不能宣称新增样式库就等于完整 ASS 文档往返。
- MSW 前后端、普通保存、另存、自动备份、恢复、便携 HTML、导入／接管／重新打开都要保留叠加轨。不能把未知字段可原样留存等同于该轨可编辑／可导出。
- 多重副字幕的 `bindings` 仍指向主轨，不能移到叠加轨后保留失效绑定。转换前确定解除／迁移策略，保留副轨文本、已有音频文件和贴片位置，整次操作可以撤销。
- MSW 素材／贴片的来源 ID 需在转轨后仍可解释；必要时扩展来源轨道标识及校验，但 D1 未扩大前不新增叠加轨 TTS／翻译提交入口。无效对象选择明确提示，不回退为主字幕。
- 双语 SRT、分色导出、源媒体 OTIO/OTIOZ、含配音 OTIOZ、FCP7、MP4 烧录分别明确是否包含启用叠加轨；不能只升级 `web/editor-utils.js` 而漏掉 `maw/msw/subtitle_export.py` 等独立导出链路。
- 时间线剪空隙、范围导出和贴片混音沿用同一时间映射；叠加字幕跨保留区间时正确裁切。不让叠加字幕关闭或空主轨导致整份工程内容丢失。

### 4.2 编辑器交互与拆分修复

修改 `web/editor.js`、`editor-utils.js`、`editor-template.html`、`editor.css`、`waveform.js/css`、`editor-i18n.js`，联动 `msw-range-selection.js` 等现有模块。

- 为叠加字幕补列表／波形轨道、序号、选中计数、播放预览、文字编辑、颜色／表情包、禁用、拆分合并、轨道转换及撤销。合并仅同轨且符合连续性要求。
- 点击行为遵循 MSW 全局“选中／跳转／自动播放”设置；选择叠加轨时不能留下另一轨的隐含操作对象。多选、快捷键、右键、播放跟随同步更新。
- 按 D4 保留现有手势优先级；范围工具与普通选择工具分别测试，Ctrl 拖动新建和 Ctrl 点击多选分清点击／拖动阈值。主轨与叠加轨共同边界不能跨轨联动。
- 吸收 `alignItemsToText` 顺序保持对齐、`placeUnalignedSplitItems` 和拆分漂移提示。处理改字、插入英文／括号、删语气词、重复词、全失配；保留 MSW 词间静音和强制切点规则。
- 上游对齐使用动态规划和大输入回退，但仍需验证超长单句／大量重复词的响应时间和递归风险；不能仅凭有阈值就宣称不会卡顿。
- 波形更高行高档位可以吸收，保留 MSW 设置窗口／搜索。上游移动设置分类时，只迁移入口和必要字段，不重建另一套偏好，也不重置用户现有配置。
- 吸收字体可搜索下拉、键盘选择、fixed 浮层、右键与模态遮罩层级修正；覆盖 MSW TTS、素材库和其他浮层，避免统一 z-index 后挡住现有面板。
- beta.4 已修复的阅读锚点、异步 seek、自动保存中继续编辑和跟随播放必须全部回归，不能用上游整段 `renderAll` 路径覆盖。

### 4.3 ASS 样式库、预览与导出

新增 `maw/ass_styles.py`，接入 `server-editor/serve.py`、Launcher 压制链路；适配 `maw/msw/subtitle_style.py`、`subtitle_export.py`、`web/msw-subtitle-style.js`、`web/msw-audio-export.js`。

- 采用上游 `moy.asr.ass_styles.v1` 库结构，包括 styles、assProfiles、SRT 默认样式、ASS 输出方案和副字幕默认槽位。MSW 用户目录写入，旧 MAW 配置兼容读取，不自动移动原文件或覆盖原项目配置。
- localhost Editor／Launcher 共享本机样式库，file:// 便携编辑器保留浏览器副本。样式库是用户级资源，不是完整嵌入每份上游工程的可移植素材；缺失样式时明确回退，不能承诺换机器像素级一致。
- 新增样式库读写接口继续使用 MSW 请求令牌、体积限制、输入校验和原子持久化。合并时核对库版本、默认槽位、删除后引用及异步保存竞争。
- 支持字体／颜色／描边／阴影／对齐等样式，以及 fad/fade/move/t 参数。非法标签、引号字体、路径与控制字符必须正确处理，不直接拼进 FFmpeg 滤镜。
- 独立读取 `preview.subtitle.ass_color_style`，保留历史 CSS `color_style: shadow` 的兼容。用户仅开启 ASS 预览不能改写字幕文本或旧 CSS 样式。
- 副字幕开启状态决定 ASS 副轨输出；叠加轨采用独立层及锚定样式，主／副／叠加的边距不互相挤占。上游 Overlay 不复用主字幕绝对 move 坐标，需保持这一差异。
- 预览按 PlayRes 和舞台实际尺寸缩放；全屏、弹出小窗、竖屏、4K、说话人标签一致。浏览器预览并非完整 libass 排版／动画渲染器，必须按实际支持能力说明。
- 按 D2 明确旧预览、旧 ASS 导出、MSW 压制快照和新库的优先级。正在导出的任务使用开始时冻结的方案，修改共享样式不影响在途任务。
- FCP7 补序列视频／音频参数、GraphicAndType 变换参数与 Vector Motion、字体与分辨率缩放；保留 MSW 品牌及原字幕／素材路径，不把“XML 字段测试通过”当成 Premiere 真机导入验收。
- Lottie／OGraf 弹窗自动匹配视频尺寸，新增自定义 16–7680 整数宽高；验证输入上下限、横竖屏、缺失元数据与手动值。保留已有字体轮廓和便携导出流程。

### 4.4 本地识别、时间码与运行环境

新增 `alignment_models.py`、`timestamp_alignment.py`、`punctuation.py`、`punctuation_runtime.py`、`local_debug.py`；修改 local ASR／模型／worker／runtime、CLI、`gui_config.py`、`gui_workflow.py`、依赖和冻结打包清单。

- FireRedASR2-CTC 作为 CPU 本地识别，ct-punc 可开关并保留原始词时间；ct-punc 未安装时需区分“CTC 可用”和“所选标点步骤不可用”，不能都显示成模型损坏。
- Qwen ForcedAligner 与 FireRed 对齐器独立管理，复用可共享的模型缓存。能力字段控制选项，仅在确有需要时追加对齐；不覆盖已有可信的原生 items。
- MOSS 与普通 local runtime 的依赖隔离继续保留。MOSS 先输出段级识别，再通过普通本地运行时对齐，不能向 MOSS 的 Transformers 5.x 环境塞入冲突的 qwen-asr。
- 运行环境升级 v6 → v7，加入 sherpa-onnx、soundfile；安装自检覆盖关键包，并正确识别 soundfile.py 单文件模块。旧环境按提示修复／重装，不自动下载大模型或破坏仍可用的旧环境。
- 吸收冻结依赖清单过期检测，但其当前实现主要比较包名是否覆盖，不等于完整版本约束验证；MSW 仍需锁文件、一致性和冻结产物检查。
- 新时间码工具提供“仅补缺失”和“重新生成”，保留字幕文本、段起止、说话人、稳定 ID、MSW 字段及素材。结果写新 MOSP；SRT 无法存放字词 items，界面不能用“只导出 SRT”冒充成功保存时间码。
- **必须适配选轨和取消**：上游 `_extract_audio_span` 未显式映射 MSW 选择的音轨，并用阻塞 subprocess.run。应复用 MSW 媒体／进程能力，传入实际音轨，支持取消、清理和严格 FFmpeg 设置，避免用错语言音轨或取消后继续写回。
- **必须适配对象范围**：上游 `align_project` 会遍历主轨、叠加轨和副轨；按 D5 增加显式范围。FireRed 对齐含识别文本匹配和插值，不应宣称所有返回时间码都是直接声学测得；全失配、静音、译文等给出失败或明确质量提示。
- 按 D3 接编辑器时，复用任务快照、源媒体代次、区间偏移、重试、取消迟到结果隔离、应用前冲突检测和一次撤销；已编辑主字幕不能被后台完成的本地任务静默覆盖。
