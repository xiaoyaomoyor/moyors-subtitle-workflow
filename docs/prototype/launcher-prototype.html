实用工具

独立文件工具：每次生成新文件，不修改工程。

提取音频

视频／音频 → AAC/M4A

从视频或音频中提取一个音轨，输出新文件；不修改源文件。

压制字幕

SRT/ASS + 视频 → 新视频

文件级压制现有 SRT/ASS；含配音贴片的完整合成仍由编辑器导出。

媒体重组（FFconcat）

清单 + 媒体 → 新媒体

按 FFconcat 清单重组媒体；不回写工程、不重映射时间线。

口播对齐（高级）

工程 + 文稿 → 新工程

交互式入口：人工选择 take 后导出 source.aligned.mosp，再接回预制流程。

媒体信息

媒体 → 信息报告

读取时长、音轨、编码、帧率与尺寸；无写入副作用。

使用指南

启动器是可选的预处理入口；编辑器内已能直接导入媒体、生成波形、ASR、翻译与 TTS。

直接进编辑器

  1. 首页点「启动空白编辑器」
  2. 编辑器内拖入媒体并生成波形
  3. 选区或整段发起 ASR
  4. 保存为 .mosp 工程

提前预制工程

  1. 预制页选择媒体（可批量）
  2. 勾选识别与字幕整理模块
  3. 开始预制，得到 .mosp
  4. 打开编辑器继续精修

纯配音与素材

  1. 编辑器内导入配音文本或主副字幕
  2. 使用 TTS 配方生成音频
  3. 素材入库后插入时间线
音频素材导入与 TTS 预制模块属于后续扩展阶段。

常见问题

在「更多设置 → 环境配置」中检测并设置 FFmpeg 路径；视频转音频依赖它。

密钥只保存在本机 .env / 应用数据目录；方案文件不包含密钥，页面仅显示遮罩。

工程文件与 .assets 目录需保持相对位置；整体搬移后仍可打开，缺失媒体由编辑器提示重新定位。
