## 边界

本轮不改动云端音色或连接配置。用模拟服务验证任务交互。上一轮已确认的旧固定轨道／工程保存断言失败不与本轮混为一谈；若触及部分失败重试，应同步修复与覆盖。

## 实现细节

- 批次与逐条 DOM 在轮询中复用；仅展开批次才读取记录详情，按 revision 缓存，失败时不循环重试。重新加载使用图标，迟到结果检查工程代次，避免进入其他工程。
- 生成内容保持原文，错误作为文本渲染；图标具有名称与悬停提示，并遵循系统减少动态效果设置。
- 合成记录使用一层滚动，底部合成操作始终可见。去除开始合成后长期占据底栏的大段说明，关闭窗口不取消任务的说明收进提示图标；请求失败仍正常反馈。
