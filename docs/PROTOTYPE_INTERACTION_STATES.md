依据：`docs/PLAN_LAUNCHER_REDESIGN.md` §3–§5、§7。原型：`docs/prototype/launcher-prototype.html`。
本表规定 B–D 阶段实现交互时的状态集合；「同一状态不得复用一种灰色表达多种含义」。

## 2. 最近工程卡片（首页）

| 状态 | 表现 | 交互 |
| --- | --- | --- |
| 默认 | 卡片底 + 弱边框 | 单击进入选择 |
| 悬浮 | 边框加深 | |
| 已选择 | 紫描边 + 紫选中底 + 右上小勾 ✓ | 再次单击取消；主按钮变「打开所选工程」 |
| 无选择 | — | 主按钮「启动空白编辑器」；首次进入默认无选择 |
| 失效路径 | 元信息行显示警告色「文件已移动或不存在」 | 提供「重新定位」；不默默打开同名其他工程 |
| 已固定 | 右下「已固定」紫色小标 | 菜单：固定／取消固定、打开所在文件夹、从最近记录移除 |
| 键盘 | Tab 聚焦卡片，Enter/Space 选择，Enter 执行当前主按钮 | 双击直接打开 |
| 统计未知 | 显示「读取中」 | 不伪造统计；封面仅用已有缓存，无封面用水母占位图形 |

## 3. 预制模块（右栏勾选 + 左栏配置区）

| 状态 | 徽标 | 含义 |
| --- | --- | --- |
| 未配置 | 灰底 `unconfigured` | 已勾选但必填参数未填 |
| 就绪 | 绿 `ready` | 可执行 |
| 条件不满足 | 警告（rail 项标注原因，如「需字幕」） | 依赖缺失；点击显示缺少条件 |
| 运行中 | 紫动效 `running` | 提交快照执行中 |
| 完成 | 绿 | 产物路径可开 |
| 失败 | 红 + 卡片红边 + 自动展开聚焦 | 定位到错误字段 |
| 已取消 | 灰 | |

规则：

- 勾选 → 左侧按依赖顺序插入配置区、展开并滚动到可见；取消 → 移除配置区但保留草稿设置（不清路径/提示词/替换规则）。
- 序号按当前可见顺序连续（01/02/03…）；模块身份用稳定 ID 持久化，不用序号。
- 折叠只改显示不改启用；标题下保留一行摘要（如「Qwen · 中文 · 说话人颜色」）。
- 「选择媒体」在媒体预制模式固定启用不可取消（输入卡是必需结构）。
- 首版不提供拖拽排序；运行顺序由契约决定并显示在「本次处理顺序」摘要。
- 不可用模块（如批量下的文稿匹配）必须在勾选/预检时说明原因，不静默跳过。

## 4. 按钮层级

| 层级 | 样式 | 使用 |
| --- | --- | --- |
| 主操作 | 紫色填充 | 每屏仅一个（打开所选工程／开始预制／预制并打开编辑器） |
| 次操作 | 抬高层底 ghost | 保存方案、空白启动、选择文件 |
| 弱操作 | 透明 subtle | 语言切换、日志入口 |
| 危险 | 红描边 | 仅对应情境显示（停止任务、移除记录确认） |
| 禁用 | 45% 不透明度 + not-allowed | 未选择工程时「打开所选工程」 |

## 5. 底部操作栏（预制页）

- 固定于内容页底部（高 64px），不覆盖最后一项表单（滚动区留出间距）。
- 布局：左＝运行摘要（`就绪 · N 个文件 · M 个模块`），右＝保存方案 / 开始预制 / 预制并打开编辑器。
- 运行中：摘要换成任务状态；「停止」按钮出现；切换导航不取消任务。
- 存在校验错误时摘要显示错误计数，左侧对应卡片自动展开并聚焦错误字段。

## 6. 表单与草稿

| 行为 | 规则 |
| --- | --- |
| 切页／折叠／主题／语言切换 | 保留草稿 |
| 保存方案 | 显式动作，不等于发起任务 |
| 提交 | 冻结输入快照；后续改表单不影响当前任务 |
| 字段错误 | 字段下方红色文字；模块卡片红边 |

## 7. 日志

- 固定运行反馈区（不作为可关闭的执行步骤）；右侧栏「显示处理日志…」仅控制展开。
- 展开后可滚动；不改变底部主按钮位置。
- LLM 流式输出进日志详情；大段 JSON/思考输出默认折叠。

| 对象 | 状态 | 表现 |
