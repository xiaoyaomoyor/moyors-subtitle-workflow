# 音频贴片

在本机 Server 编辑器生成 TTS 后，把素材库中的音频行拖到波形显示器，松手处就是贴片起点。也可以点击素材行的「放入时间轴」，放在当前播放头。已有配音素材不必重新请求云端。

## 编辑

- 配音排在字幕下方，主、副字幕同时存在时自动压缩为较薄的文字条。
- 重叠贴片自动分配子行，同时发声。配音区域最多同时显示三行，更多重叠时在该区域内滚动查看；不会无限挤高波形窗口。
- 拖动贴片移动位置；拖动左右边缘裁剪。裁剪保留源音频，右键「恢复完整音频」可恢复入出点，保留当前放置位置。
- 单击选中并把播放头定位到鼠标点击的时间位置，Ctrl／Shift 加选；方向键移动 10ms，Shift 加方向键移动 100ms。Delete 删除所选贴片，Ctrl+Z／Ctrl+Y 撤销／重做，不会删除素材或重新计费。
- 右键「静音音频贴片」或按 M：不参与播放，文字显示删除线，音符变为划线的静音音符。再次操作取消静音。右键也可调整所选贴片音量（−60 至 +12 dB）。
- 贴片文字取生成时的显示文本。后续修改、删除或移动来源字幕，不会改变已经放置的配音。

## 颜色与播放

默认热力图反映音频各时刻的 RMS 电平。固定色标从暗蓝低电平逐渐到明亮暖色高电平，约 −60 至 −6 dBFS；不同贴片共用色标，不分别归一化。分析约每 100ms 更新，窗口约 400ms，短音频使用实际可用样本。它表示信号电平，不是 LUFS 感知响度或最终混音是否削波的判断。

「媒体 → 波形显示器设置」可关闭「音频贴片热力图」切换纯色。颜色计入贴片／轨道增益；播放器的监听音量不改变颜色。关闭热力图只改变显示，静音才会关闭声音。

贴片轮廓与字幕块一致。纯色模式使用半透明「强调色」，静音时改用「字幕块」颜色并隐藏热力图，选中轮廓使用「选区」颜色。字幕列表、主／副字幕块和未静音贴片的文字统一跟随「字幕文字」；静音贴片文字改用「弱文字」，均可在自定义颜色中调整。

空格、播放器按钮和波形双击控制原媒体及配音的同步试听。带未静音配音时使用 1×，倍速／倒放暂不可用。播放器音量控制试听总音量；素材库的单条试听会暂停时间轴。Seek、暂停、缓冲或切换工程会撤销旧声音；需要解码时暂停时间轴，准备完毕续播，等待期间按暂停可取消续播。

配音长于原视频时可继续播放尾段；没有原媒体时也可试听配音。这里只解码配音素材，缓存预算 128MiB，单素材估算上限 64MiB，最多同时加载两条。超过限制或素材丢失会提示并标记贴片；恢复工程旁的素材目录后，可右键「重新加载素材」。

## 空隙与保存

默认「保留配音覆盖的区间」：即使空隙已设为跳过，未静音贴片覆盖的部分仍保留。波形设置中的「配音与空隙」可改为「配音随媒体跳过空隙」，播放跨过这些区间时配音也跳到对应源采样位置。静音贴片不保护区间。原空隙编辑决定保留，移除贴片后重新生效。

热力图开关、空隙策略和贴片编辑随工程保存，并支持撤销。音频仍在同目录的 `.assets` 文件夹，移动工程时一起移动；素材库「导出工程与 TTS 音频」可以打包工程和素材。便携 HTML 保留贴片数据，但读取音频需通过本机 Server。

C 阶段提供编辑与试听。现有视频、音频和剪辑工程导出尚不混入贴片；配音轨 WAV、原声混音与视频导出是 D 阶段。
