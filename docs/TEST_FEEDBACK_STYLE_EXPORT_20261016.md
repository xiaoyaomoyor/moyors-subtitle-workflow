## 决策与验证

- 用户确认：参数立即应用于工程，预设保留名称并标记“已修改”；显式覆盖用户预设，内置预设只能另存。保留旧工程已有的独立样式数据。
- “继承工程样式”表示轨道读取工程默认样式；选择预设或改参数后保存为该轨道组的独立快照。库中预设不是实时链接，不会自动改写其他工程或其他轨道的快照。
- 样式测试初次 1 通过、1 失败：Playwright 的 `toBeDisabled` 不识别原生 option；DOM 已正确有 disabled，改为属性断言后 2 项均通过。
- 扩展运行旧 `project-subtitle-style` 13 项时，9 项因仍读工程默认样式、直接改旧主副数组或选择已移除的烧录 main 选项而失败；迁移测试夹具至平级轨道，保留图像对比和真实保存断言，最终逐项通过。没有为旧夹具放宽产品的数据校验。
- 旧未绑定用例原先隐含主副配对排布；当前模型仅绑定字幕共享排布组，轨道分组本身不建立绑定。按 `msw-track-presentation.js` 现有契约，将未绑定用例更新为独立避让、不产生绑定、浏览器与 FFmpeg 一致性检查；绑定用例继续严格检查上下顺序和负间距。另修正原生颜色 fill 已触发 change、重复派发造成两步历史的测试写法。本轮没有改变排布算法。
