# 编辑器直接导入与 ASR

本机编辑器可以直接导入音视频、生成波形、识别、翻译和配音。启动器仍用于批处理；编辑器复用同一套 Python 后端和本机服务配置。

## 直接启动

- Windows 发行包：双击与 `MSW.exe` 同目录的 `Start-Editor.vbs`，或运行 `MSW.exe --editor`。
- macOS 发行包：双击 `Start-Editor.command`，或运行 `MSW.app/Contents/MacOS/MSW --editor`（lite 对应 `MSW-lite.app`）。
- Linux：运行 `./MSW-Linux-x86_64-版本.AppImage --editor`。
- 源码：`uv run python maw_gui.py --editor`。可接工程路径；`--blank` 打开空白工程，`--port 0` 自动选端口，`--no-open` 仅启动服务。原 `server-editor/serve.py` 入口继续可用。

省略工程时沿用编辑器的恢复流程。直接运行主应用仍打开 Launcher。纯 HTML 页面可手动编辑，ASR、翻译和 TTS 后台任务需要本机编辑器服务。

## 导入与波形

1. 使用「文件 → 加载媒体」选择原视频／音频，也可以直接拖入媒体文件。无需先生成字幕工程。
2. 本机选择保留原文件引用；浏览器拖放会分块缓存，上传期间可以取消。导入失败保留此前工程。
3. 波形默认在后台生成，可以继续编辑。在「波形显示器设置 → 媒体分析」调整「自动波形」或手动重新生成、取消。无波形、取消或无音轨时使用装饰波浪线，不代表真实音量，也不限制手动字幕或纯文本 TTS。
4. 多音轨媒体在同一设置分区选择源音轨；「源音轨 1（eng）」表示文件第 1 条音频流，eng 是文件标注的英语，切换用于选择原声、译配或解说音轨，不能从同一条混音中分离人声。波形、识别和播放代理均使用该音轨。展开「播放代理」可生成或取消兼容副本，工程仍引用原媒体。上述设置不再常驻波形工具栏，导入进度仅在导入期间显示。
5. FFmpeg / FFprobe 路径位于「全局设置 → 环境配置 → 媒体工具」，也可从波形设置跳转。无需导入媒体即可保存。标准包携带两者，lite 需自行准备；如果路径由启动环境固定，界面只读。

无内容工程暂时显示 20 秒可编辑空间；该占位长度不会成为导出时长。真实峰值是可重建缓存，不能替代源媒体。

## 整段与片段识别

在「媒体 → ASR」选择整个源视频，或按住 **Ctrl+Shift**（macOS **Cmd+Shift**）在波形上拖动建立时间选区。分割工具右侧的「选区编辑」工具还支持：普通左键拖动替换选区、Shift+拖动加选、Ctrl/Cmd+拖动减选、拖动任一选区边界扩大或缩小，可拖到前后行，或横向越过行末。加选会合并相交片段，减选可以把选区切成多个不连续片段；Ctrl/Cmd+Shift 的临时选择操作继续保留。切回「选择」工具可继续操作字幕块和音频贴片。

支持反向拖动、跨行和滚动；选区内只有波形画布反色，字幕／音频贴片保持原色。Esc 清除选区，拖动中 Esc 撤回此次选择并恢复全部片段；普通播放和 Seek 不会清除它。

选区右键可「识别所选片段（ASR）」，也可精确输入起止秒数，多个片段时可在精确编辑窗口选择要调整的片段。起止秒数并排显示，下方显示时长；Enter 应用，取消或 Esc 放弃本次输入。内部使用整数毫秒。多个选区分别创建任务，逐片段预览、应用与撤销，中间未选中的字幕保持原样。片段识别限定在真实源媒体范围内，不会因为选择无效自动改成整段付费请求。

任意波形工具下，在空白处或时间选区内右键可「加选播放头到鼠标位置」：将打开菜单时的播放头红线到鼠标位置灰线之间的区域加入选区，两端次序不限，已有选区保留并合并重叠部分。工具栏不再显示选区时间和清除按钮；精确编辑、清除选区仅在选区右键菜单中提供，Esc 也可清除。

空白处菜单依次为创建字幕、添加空隙、添加时间选区、加选播放头到鼠标位置、波形显示器设置。「添加时间选区」在鼠标处添加默认 1 秒片段（媒体末尾裁短）并打开起止时间弹窗；已有选区保留，相交时合并。

选区内右键字幕块或音频贴片时，优先显示对应对象的菜单。字幕删除项之前的「配音所选字幕（TTS）」打开 TTS 并使用所选主／副字幕，仍需手动开始合成。字幕和贴片菜单不包含时间选区操作；贴片删除显示红色和 Delete 提示，音量控件标为「贴片音量增益（dB）」。

如果选区切穿旧字幕，必须先调整选区或明确点击「扩展到完整字幕边界」；扩展后的范围会在提交前显示。不会删除未选中半句的文字。

在「全局设置 → 环境配置 → ASR」保存服务连接参数：地域、Workspace ID、API 地址与 API Key。无需导入媒体即可保存，复用 Launcher 的 Key 与参数校验。ASR 面板以两列显示服务、模型、语言与识别范围；自定义模型、说话人、热词和上下文按当前模型能力显示，高级断句参数可展开调整。本次识别使用面板当前参数；点击「保存识别设置」记住默认值，未保存的环境连接草稿不参与调用。Key 不写入工程、候选导出或任务记录。本轮未开放本地实验引擎、隐藏服务和非官方免 Key 入口。

「识别记录」统一折叠任务，每条记录下有独立的结果预览。用「选择结果」确定底部操作对象，当前结果的模型和范围会显示在按钮上方；应用、搁置、导出候选工程、导出候选 SRT 四个按钮始终在折叠区外，收起记录或预览不改变选中的导出对象。

任务后台运行，关闭面板不会取消，可继续播放和编辑。任务列表提供取消、失败重试、结果预览和候选导出。取消后的迟到结果不会写入字幕。连接中断导致提交状态未知时，「确认上次提交」复用原请求 ID，避免重复创建任务。服务重启中断的任务需要手动重试，刷新不会自动再次发起识别。

## 应用与撤销

- 主字幕为空，且当前页面、源媒体和目标范围仍匹配时，无冲突结果自动加入；已有主字幕时先预览替换数量再手动应用。
- 片段结果只替换所选范围内的主字幕，时间从提取音频映射回原视频一次。没有语音时保留全部旧字幕。
- 片段识别应用时，新字幕继承时间重叠最多的旧字幕颜色（重叠相同时采用前一条）；包括颜色组成员和未设颜色的默认色。继承色只覆盖新字幕自身时长，不保留指向被删除组头的引用。无重叠旧字幕时保留识别结果自己的颜色；整段识别继续使用识别结果颜色。
- 旧副字幕和音频素材／贴片保留，失效绑定解除，相关内容显示需复核。提示不会静音音频或改变导出；重新翻译成功覆盖对应副字幕后清除其标记。
- 应用是一次撤销操作，主字幕、绑定、复核标记和应用记录一起恢复。颜色／表情包分组若跨越替换区，范围外剩余组会修复组头引用。
- 提交后若目标范围内字幕被编辑、增加、删除、拆分或移动，或源文件／音轨改变，结果保留供导出，禁止直接覆盖。范围外编辑不阻止应用。
- 不自动触发翻译或 TTS。应用后可继续使用原有「媒体 → 字幕翻译／TTS」、素材库和导出功能。

首次保存选择 `.mosp` 位置。可保存零条字幕、零贴片或纯 TTS 工程；迁移时保留源媒体及同目录 `.assets`。临时恢复草稿不是长期备份。保存与收集细节见 [工程保存与恢复](EDITOR_PERSISTENCE.md)。

## 候选结果与播放、波形说明

- **搁置结果**：将已完成结果标记为暂不应用并收起预览，不删除当前字幕；仍可从任务列表重新预览、应用或导出。它不是取消正在运行的任务。
- **导出候选工程**：把该次识别的候选字幕、字词时间等结果和源媒体引用导出为独立 `.mosp`，方便另开工程审核。它不是当前完整编辑工程的备份，不含现有副字幕、音频贴片等内容，也不复制视频。
- **导出候选 SRT**：只导出该次识别的候选字幕及其在原媒体上的时间码，可交给其他播放器或编辑软件使用。两种导出均不要求先应用结果，也不修改当前字幕。
- **生成播放代理**：本机 FFmpeg 生成浏览器易于播放的 MP4 副本（视频 H.264、音频 AAC），适合原编码无法预览或需要切换源音轨的情况。生成需要时间和缓存空间；原媒体引用不变，ASR 仍读取原媒体和所选源音轨。
- **原生 / REAPER 波形**：原生由 MSW 从音频分析生成，当前本机实现先重采样到 1000 Hz，再计算约每秒 100 组峰值；REAPER 来源读取现有 `.ReaPeaks` 的最细波形层，保留其原采样率峰值信息，包络细节可能更完整。两者都只影响波形展示，不改变音频或识别质量。频谱颜色另需频谱缓存。
- **切换与默认值**：该下拉框切换已有形状数据，不是缓存格式转换器。两套数据齐全时可随时切换；选择 REAPER 但没有其数据时回退到现有波形。显示偏好默认 REAPER 优先；全新导入且无缓存时，编辑器后台自动生成的是原生波形，不会自动生成 `.ReaPeaks`。后台分析会优先复用匹配源文件和音轨的已有缓存，包括可读取的 ReaPeaks。

## 当前验证边界

本轮自动化使用真实 FFmpeg、合成音视频与本机模拟 ASR 服务；真实供应商精度、额度和服务大小限制仍取决于用户账户和对应服务。Windows 浏览器交互与发行包检查单独记录于 [实施账本](TEST_FEEDBACK_EDITOR_ASR.md)，macOS／Linux 的原生窗口和发行包需对应平台验收。超长素材可分段识别；单次任务最多 10000 条候选字幕。
