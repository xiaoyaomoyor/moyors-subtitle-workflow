# 配置管理

启动器：**更多设置 → 配置管理**，与其他设置同页切换，不另开弹窗。编辑器：**编辑 → 全局设置 → 配置管理**。两处使用相同的配置库和操作规则。

## 导出与导入

1. 在“导出”中勾选需要的分类，保存为 `名称.mswconfig`。文件内部是 UTF-8 JSON；不必改成 `.json`。
2. 在另一环境的“导入”中选择该文件、勾选需要恢复的分类。
3. 在文件选择后的“导入机制”中选择如何处理本机配置，点击“预览变更”，查看分类差异及需要重新配置的资源。
4. 点击“确认应用”。配置保存在本机，界面偏好在重新打开／刷新窗口后读取。不会自动刷新正在编辑的窗口。

“配置分类”前的复选框用于全选／全不选；部分勾选时显示中间状态。导入时只控制文件内可用的分类。

**保留本机**：已有字段不覆盖，只补充缺失项。字幕预设和自定义主题按标识／名称保留本机冲突项，补充不同的预设。

**使用导入配置**：覆盖所选分类，文件未包含的字段恢复为模块默认。未勾选的分类不变。预览与确认之间如果其他窗口修改了配置，必须重新预览，不会用旧预览覆盖它。

导出独立预览偏好时，会同时带上其引用的用户字幕预设。导入时若缺少这个预设，会提示一并导入；不会悄悄换成别的字幕外观。字体文件不打包，目标机器仍需安装所用字体。

## 分类与边界

| 分类 | 内容 |
| --- | --- |
| 界面与编辑操作 | 编辑／播放／列表偏好、主题与颜色、语言、浮窗位置 |
| 波形与工作区 | 波形显示、默认 Dock 布局、命名工作区及内置布局覆盖；不包含工程导航记录 |
| 启动器 | 常用语言／模型、预制模块、断句限制、主题、缩放和页面记忆 |
| 字幕样式预设 | 用户预设库；不修改已经写入工程的轨道或单条样式 |
| 说话人方案 | 可复用的人物名字、译名、颜色、外观与动画；导入后在工程中确认对应再应用 |
| 预览偏好 | 跟随工程或独立预览预设的选择 |
| 翻译与文本处理 | 翻译偏好、提示词、替换规则和后处理流程参数 |
| 配音设置 | 已接入引擎的非敏感合成参数、IndexTTS／GPT-SoVITS 的命名参数预设；Edge／油库里可带公共音色选择 |
| 工程备份设置 | 是否启用、间隔、保留数量；不搬运工程恢复文件 |

旧“ASS 样式库”和“首次使用提示”不再作为可选分类：前者已由字幕样式预设统一管理，后者只是引导完成／跳过状态。现有内部数据保留；导入包含这些分类的旧文件时，只应用勾选的现有分类。ASS 预览、导出和烧录能力不受影响。

密钥、业务空间、账号音色、参考音频、本地模型、服务地址和媒体／文稿路径不进入普通配置文件。配方导入本机时保留本机资源；迁往新机器后需重新选择这些资源。后处理的文件和轨道范围不搬运，文稿匹配等步骤需要补齐输入才能执行。

面板中的“详情说明”区分工程、个人配置、不导出内容和导入生效规则。工程字幕、绑定、说话人、样式、动画、位置、音频贴片、空隙、工程工作区及保存时的播放位置随 `.mosp` 保存；媒体保存引用，原视频、音频和素材文件仍需保留。任务使用提交时的参数；导入不取消任务，也不改动正在编辑的工程。

## 跨工程使用说话人方案

1. 在原工程的 **全局设置 → 说话人色系** 配好人物，用“另存为说话人方案”图标保存。
2. 打开另一工程，选择同一方案，点击“对应并应用”。表中显示当前人物的字幕数量和示例；为各人选择方案里的对应人物，再确认。
3. 未对应的工程人物保持原样。需要补入尚未出现的人物时，勾选“补充方案中未对应的说话人”。多个人物编号可对应同一个人，但不会自动合并字幕或身份。
4. 换机器时，在配置管理中只勾选“说话人方案”即可导出／导入 `.mswconfig`。本机服务版跨浏览器和端口共享方案库；便携 HTML 用配置文件搬运。

不同视频的 SP1 不一定是同一个人，编号和颜色不会用来自动猜测对应。已确认的对应随工程保存，下次选同一方案可直接预选。名称仍按轨道语言显示。

应用后可一次撤销；单条手动样式仍优先。修改方案不自动更新其他工程，需在相应工程再次确认应用。更新方案默认只更新已对应的人，可勾选加入新的工程人物；其他集数才出现的人物保留。删除方案也不会删除工程里的说话人或改变预览。

## 配置备份与旧工作区

配置管理只保留导出和导入。需要自行保留可恢复的设置时，导入前先导出一份 `.mswconfig`，之后可用同一导入流程恢复。

实际导入前仍在内部自动备份，供故障排查使用；没有常驻恢复入口，也不会删除既有备份。内部最多保留最近 20 份，存放在应用数据目录的 `config-snapshots.json`。它不包含工程内容，与工程恢复记录无关。

原“界面配置”导入导出入口已并入配置管理。旧 `.workspace.json` 可导入为一个命名工作区，名称取文件名；它只添加／更新该名称，不覆盖其他工作区。重新打开编辑器后，从“窗口 → 切换工作区布局”选择它。当前工程布局不会在导入时被替换。

应用数据目录中的 `user-settings.mswconfig` 是内部配置库，包含修订与迁移信息。跨机器搬运使用“配置管理”导出的文件；不要用导出文件直接覆盖内部库。

## 便携 HTML

没有本机服务时，配置只保存到当前浏览器。可导入导出界面、波形／工作区、字幕预设、说话人方案、预览偏好；配置备份保留最近 10 份。文件中的启动器、处理、配音和工程备份设置在此处不导入，面板会明确提示；这些分类需要使用本机服务版。

浏览器限制或存储空间不足时，操作会显示失败；原配置不会因预览而改变。真正的跨浏览器自动共享需要本机服务，便携 HTML 使用配置文件显式搬运。

## 波形缓存

波形缓存保存已经计算的音频波形数据，下次打开媒体时可直接复用，减少等待；不是用户配置，也不是工程备份，日常使用无需手动管理。

正常生成或读取有效完整缓存时会自动整理重复副本，无需分析或清理按钮。只检查当前媒体及当前音轨，校验数据一致后移入回收站；清理失败保留文件，不影响波形使用。便携 HTML 不直接管理本机缓存。

预制工程、独立波形工具和编辑器媒体分析使用同一生成流程。同一源媒体的生成任务串行执行并复用结果，不为每个编辑器任务额外复制一份波形。不同源音轨分别校验和存储，不用默认音轨代替所选音轨。

- `.quapeaks` 是完整缓存容器，可包含基础波形、多级波形、响度和可选频谱；**不需要勾选频谱颜色才会生成**。
- 有有效基础层的 `.quapeaks` 优先；缺少生成内核或完整缓存不可用时，继续使用 `.mopeaks`。旧 `.waveform.json` 和 `.ReaPeaks` 保持可读。
- 新生成完整缓存时，不再先写一份重复 `.mopeaks`。旧回退缓存只有与有效完整缓存的基础数据、采样率和精度一致时才自动整理。
- 清理只把确认重复的 `.mopeaks`／旧基础 JSON 移入回收站。不同精度、损坏或唯一回退缓存保留；不会删除媒体、工程、频谱或恢复记录。
- 缓存读写沿用媒体的 `_msw`／`名称_msw` 目录，兼容旧目录；只读目录回退到本机缓存目录。媒体连同缓存搬移且指纹仍匹配时可直接复用，源内容改变则重建。仅移动媒体、不带缓存时，允许重新生成。

缓存不写入 `.mswconfig`；它是媒体派生数据，不属于用户偏好。跨机器配置迁移仍使用导出／导入页。

## 文件结构

```json
{
  "format": "msw-config",
  "version": 1,
  "kind": "preferences",
  "categories": ["interface"],
  "sections": {"browser": {"mawe.language": "zh"}}
}
```

文件不带内部修订、操作 ID、迁移标记或项目历史。未知版本、未知分类、类型不符、凭据字段以及超过 4 MB 的文件拒绝导入。服务端仍需现有本机令牌，不增加任意路径读写 HTTP 接口。启动器文件读写只能通过本机文件选择器。
