## 设计约束

- 关键帧按通道覆盖“舒展”的同名参数，未设通道继续使用舒展；不透明度与淡入淡出、闪烁相乘。每通道最多 32 点，平滑使用无过冲的 smoothstep，首末点之外保持端点。
- 渐变使用 ASS 原生逐字颜色标签，沿阅读顺序在两个颜色间变化，空格不占步长，换行不重新开始。单字内部仍为纯色。可交换首尾颜色，支持中文、组合字符和打字机。
- 暂不使用裁剪条带模拟字内平滑渐变：ASS 没有原生连续渐变，条带会增加事件数，且运动/旋转时必须同步裁剪。明确功能名称与限制，不用 CSS 效果替代实际导出能力。
- 参考：[Aegisub ASS 标签](https://aegisub.org/docs/latest/ass_tags/)。
