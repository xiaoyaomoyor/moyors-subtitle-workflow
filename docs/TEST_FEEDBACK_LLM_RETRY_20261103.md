# LLM 临时故障重试与批次恢复

用户反馈：Gemini 连接测试通过，预制工程校对在 c0161–c0200 收到 HTTP 503。要求有限退避重试，失败保留进度，后续不重复处理已完成内容。

| 项目 | 状态 | 处理 |
| --- | --- | --- |
| 临时 HTTP 故障重试 | 已修复 | 408/429/500/502/503/504 最多追加三次，约 2/4/8 秒加微量抖动；JSON 修复共享重试预算；明确额度、余额错误不重试 |
| 等待、取消与日志 | 已修复 | 支持 Retry-After 秒数及日期；超过 60 秒交由稍后继续；等待可取消，保留取消状态；预制日志显示字幕范围与重试次数 |
| 校对／翻译恢复 | 已修复 | 沿用既有逐批缓存、配置指纹、结果校验与原子写入；失败不清理目录，不写部分最终结果；恢复跳过已完成步骤和批次 |
| 原工程及真实云端调用 | 仅说明 | 未修改用户工程，也未调用付费模型；使用合成输入与模拟 HTTP 响应验证 |
| 跨启动器会话恢复入口 | 仅说明 | 现有按钮依赖当前会话，磁盘缓存仍保留；本轮不新增跨会话任务管理界面 |

## 实现

- `maw/postprocess_llm.py`：公共 completion 重试，响应关闭、元数据保留和非临时错误保护；连接测试保持单次。
- `maw/postprocess_pipeline.py`、`maw/gui_web.py`：可取消等待、重试事件与日志。取消异常经批次包装后仍标记为取消。
- `maw/msw/jobs.py`：使用同一客户端的编辑器翻译任务在等待期间也可取消。
- 复用 `TranslationProgress`，未引入第二份进度文件或更改缓存身份规则。

## 验证

- 491 项相关 Python 回归：490 通过、1 项既有条件跳过。范围涵盖 LLM 连接、后处理、预制流水线、校对保护／恢复、翻译恢复、启动器平级轨道、编辑器翻译、GUI 桥接。
- 新增模拟 HTTP 集成：201 条字幕，前四批成功、第五批连续 503；恰好三次重试后停止，缓存保留四批。恢复仅发送 c0161 与 c0201 开头的两批；前置文字处理步骤不重复执行；校对和翻译分别验证。
- 校验取消、Retry-After 数字／日期／无效值／过长值、错误脱敏、连接测试不重试、JSON 与 HTTP 预算不相乘、流式显示重置及响应关闭。
- 首轮测试受系统临时目录写入与本机网络权限限制；切换到工作区临时目录，并允许回环测试服务后通过。未放宽应用运行权限。
