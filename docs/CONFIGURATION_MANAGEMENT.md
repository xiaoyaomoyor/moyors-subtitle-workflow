# 配置管理

启动器：**更多设置 → 配置管理**。编辑器：**窗口 → 配置管理**。两处使用相同的配置库和操作规则。

## 导出与导入

1. 在“导出”中勾选需要的分类，保存为 `名称.mswconfig`。文件内部是 UTF-8 JSON；不必改成 `.json`。
2. 在另一环境的“导入”中选择该文件、勾选需要恢复的分类。
3. 选择冲突规则，点击“预览变更”，查看分类差异及需要重新配置的资源。
4. 点击“确认应用”。配置保存在本机，界面偏好在重新打开／刷新窗口后读取。不会自动刷新正在编辑的窗口。

**保留本机**：已有字段不覆盖，只补充缺失项。字幕预设和自定义主题按标识／名称保留本机冲突项，补充不同的预设。

**使用导入配置**：覆盖所选分类，文件未包含的字段恢复为模块默认。未勾选的分类不变。预览与确认之间如果其他窗口修改了配置，必须重新预览，不会用旧预览覆盖它。

导出独立预览偏好时，会同时带上其引用的用户字幕预设。导入时若缺少这个预设，会提示一并导入；不会悄悄换成别的字幕外观。字体文件不打包，目标机器仍需安装所用字体。

## 分类与边界

| 分类 | 内容 |
| --- | --- |
| 界面与编辑操作 | 编辑／播放／列表偏好、主题与颜色、语言、浮窗位置 |
| 波形与工作区 | 波形显示、默认 Dock 布局、命名工作区及内置布局覆盖；不包含工程导航记录 |
| 启动器 | 常用语言／模型、预制模块、断句限制、主题、缩放和页面记忆 |
| 字幕样式预设 | 用户预设库；不修改已经写入工程的轨道或单条样式 |
| 预览偏好 | 跟随工程或独立预览预设的选择 |
| ASS 样式库 | 样式、输出配置及其库内关联 |
| 文本处理默认值 | 翻译偏好、提示词、替换规则和后处理流程参数 |
| 配音配方 | 已接入引擎的非敏感合成参数、IndexTTS／GPT-SoVITS 的命名配方；Edge／油库里可带公共音色选择 |
| 备份策略 | 是否启用、间隔、保留数量；不搬运工程恢复文件 |
| 首次使用提示 | 完成／跳过状态，默认不勾选导出 |

密钥、业务空间、账号音色、参考音频、本地模型、服务地址和媒体／文稿路径不进入普通配置文件。配方导入本机时保留本机资源；迁往新机器后需重新选择这些资源。后处理的文件和轨道范围不搬运，文稿匹配等步骤需要补齐输入才能执行。

工程字幕、动画、位置、素材、空隙和工程工作区继续随 `.mosp` 保存。任务使用提交时的参数；导入不取消任务，也不改动正在编辑的工程。

## 回退与旧工作区

每次实际导入／回退前，保存一个配置快照。在“快照回退”中选择时间，再按分类预览与确认即可。最多保留最近 20 个快照，存放在应用数据目录的 `config-snapshots.json`；回退操作自身也有恢复点。

原“界面配置”导入导出入口已并入配置管理。旧 `.workspace.json` 可导入为一个命名工作区，名称取文件名；它只添加／更新该名称，不覆盖其他工作区。重新打开编辑器后，从“窗口 → 切换工作区布局”选择它。当前工程布局不会在导入时被替换。

应用数据目录中的 `user-settings.mswconfig` 是内部配置库，包含修订与迁移信息。跨机器搬运使用“配置管理”导出的文件；不要用导出文件直接覆盖内部库。

## 便携 HTML

没有本机服务时，配置只保存到当前浏览器。可导入导出界面、波形／工作区、字幕预设、预览及首次提示；快照保留最近 10 个。文件中的启动器、处理、配音和备份策略在此处不导入，面板会明确提示；这些分类需要使用本机服务版。

浏览器限制或存储空间不足时，操作会显示失败；原配置不会因预览而改变。真正的跨浏览器自动共享需要本机服务，便携 HTML 使用配置文件显式搬运。

## 波形缓存

本机服务版的“配置管理 → 波形缓存”可以分析并清理重复缓存。编辑器分析当前工程媒体；启动器通过文件选择器选择媒体。先分析、再点击“清理重复缓存”；如果媒体或缓存已改变，需要重新分析。便携 HTML 无法管理本机缓存，不显示这个入口。

预制工程、独立波形工具和编辑器媒体分析使用同一生成流程。同一源媒体的生成任务串行执行并复用结果，不为每个编辑器任务额外复制一份波形。不同源音轨分别校验和存储，不用默认音轨代替所选音轨。

- `.quapeaks` 是完整缓存容器，可包含基础波形、多级波形、响度和可选频谱；**不需要勾选频谱颜色才会生成**。
- 有有效基础层的 `.quapeaks` 优先；缺少生成内核或完整缓存不可用时，继续使用 `.mopeaks`。旧 `.waveform.json` 和 `.ReaPeaks` 保持可读。
- 新生成完整缓存时，不再先写一份重复 `.mopeaks`。旧回退缓存不会自动删除；只有与有效完整缓存的基础数据、采样率和精度一致时，才列为可清理。
- 清理只把确认重复的 `.mopeaks`／旧基础 JSON 移入回收站。不同精度、损坏或唯一回退缓存保留；不会删除媒体、工程、频谱或恢复记录。
- 缓存读写沿用媒体的 `_msw`／`名称_msw` 目录，兼容旧目录；只读目录回退到本机缓存目录。媒体连同缓存搬移且指纹仍匹配时可直接复用，源内容改变则重建。仅移动媒体、不带缓存时，允许重新生成。

缓存不写入 `.mswconfig`；它是媒体派生数据，不属于用户偏好。跨机器配置迁移仍使用导出／导入页。

## 文件结构

```json
{
  "format": "msw-config",
  "version": 1,
  "kind": "preferences",
  "categories": ["interface"],
  "sections": {"browser": {"mawe.language": "zh"}}
}
```

文件不带内部修订、操作 ID、迁移标记或项目历史。未知版本、未知分类、类型不符、凭据字段以及超过 4 MB 的文件拒绝导入。服务端仍需现有本机令牌，不增加任意路径读写 HTTP 接口。启动器文件读写只能通过本机文件选择器。
