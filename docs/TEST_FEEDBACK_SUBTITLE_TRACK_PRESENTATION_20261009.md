## 使用与边界

- 开发入口为 `?subtitle-tracks=1`。媒体播放器设置 → 字幕样式 → 画面排布选择“固定轨道排布”；旧工程不会自动改变。编辑对象选择工程默认或具体轨道，轨道头菜单也可直接进入对应样式。
- 画面文字可选择“轨道位置”或“当前字幕位置”；数字输入与播放器拖动使用同一归一化坐标，已绑定主副作为一组。当前覆盖不随轨道位置修改，恢复“跟随轨道位置”可移除覆盖。轨道快照随工程保存，删除本机预设不会破坏工程样式。
- 对白以真实浏览器字体、换行、缩放和描边测量，按轨道顺序及字幕显示期间的实际相交内容预计算位置；原文与译文未明确绑定时保持独立。播放中的其他字幕开始／结束不会触发位置重算，远处长句不扩大当前间距。
- 注释不自动避让或缩小；定位时给出碰撞／越界提示。默认不开新气泡，边框使用现有选区色。移动动画叠加于定位锚点；静态占位不保证完整动画运动路径没有碰撞。
- 仍是开发阶段的浏览器近似预览。v3 的 libass、ASS、烧录、识别／翻译／配音闭环留到阶段 5；普通 v2 工作流不自动升级。本轮未使用个人工程或媒体，也未重启 8250。
