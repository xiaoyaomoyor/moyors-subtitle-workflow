混音使用现有配音保护后的区间，临时暂停仅用于排空旧音频，随后从跳转终点继续播放。手动暂停取消自动续播。实测初版门控在跳转完成后仍偶发约 16 ms 的旧样本，加入缓冲排空后复测通过。

关闭前的正常流式事件仍通过事件队列投递。进入关闭时已落盘的日志可回查，界面队列丢弃，迟到的启动请求也不重启事件泵。真实 WebView2 窗口释放尚待按打包版复核。
