## 剩余可考虑的内容

| 优先级与内容 | 当前差异 | 建议适配方式 |
| --- | --- | --- |
| 可选，优先考虑：完整断句标点设置 | MSW 已共享句尾处理并保护英文缩写，但 `postprocess_match.py` 仍用固定基础标点加 `extraSplitPunctuation`，用户不能移除基础逗号、句号。上游改为完整可配置清单，换行单独保留。 | 可让用户决定逗号、句号等是否触发断句，并明确区分“用于断句”和“保留在句尾”。沿用 MSW 设置和识别预设，共用于编辑器、启动器及相关处理入口；保留现有默认行为、800ms 停顿阈值、英文规则和旧预设兼容，不重切已有字幕。不能只改字段名称或照搬上游默认值。 |
| 可选，按复核需求决定：独立 Marker／Region | MSW 的说话人颜色、贴图、音频空隙和处理复核状态不等于独立的时间点／区段备注。长视频校对时可以用于待听校、术语或场景疑点。 | 若需要，先做备注、跳转、筛选和解决状态，接入现有工程保存与撤销。必须独立于会改变播放跳过和导出结果的音频空隙；不移植上游整套时间轴模型。 |
| 低优先级：一句字幕内部的局部样式 | MSW 已有整条字幕的字体、下划线、删除线等设置；`cue_style.py` 的整条样式不等于一句中仅部分字词加粗、变色或缩放。 | 只有确需强调个别字词时再设计。优先通过选中文字设置样式，避免把剧本文字里的普通符号自动解释成样式。需要同时处理切分／合并、查找替换、剧本往返及纯文本导出，不能作为简单补丁移植。 |

## 不建议跟进或保留 MSW 实现

| 上游内容 | 处理建议与原因 |
| --- | --- |
| FFmpeg 截帧式 ASS 实际画面预览、独立对照窗口 | 不新增第二套常规预览。MSW 已使用 JASSUB／libass WASM 在播放和暂停时渲染，后端 ASS 编译与烧录共用布局；上游截帧方案不能直接解决 MSW 新缺口。如实际遇到原生 FFmpeg 与 WASM 的字体／版本差异，再做定向诊断。共享 ASS 不代表所有环境逐像素一致。 |
| 双语空副轨编辑、导入、主／副／合并 SRT | 已有 v4 多轨、绑定和字幕导出，不替换为上游主副轨模型。 |
| 失败的 LLM 批次保留原文并继续输出 | 不直接启用。上游对特定瞬时错误的自动降级与 MSW 的严格翻译、补齐、审查和缓存恢复语义不同，可能让未处理原文混入最终产物。以后如有需求，应显式提供重试／跳过和待复核状态。 |
| 上游默认字号、边距、强调色和默认淡入淡出 | 保留 MSW 现有样式及用户预设，不改变旧工程外观。 |
| 浮窗遮挡旧下拉菜单、选中轮廓和波形状态重构 | 上游部分触发界面已被 MSW 替换；拖动、取消、保存状态沿用 MSW。只有定向回归实际发现同类缺陷时才修复，不复制不适用的补丁。 |
| AI 口播重录整理 | 当前字幕精修需求不足以支持新增判断和删除流程，暂不引入。 |
| LRC 导入、字幕绿幕视频 | 当前无明确用途，暂不引入。自动烧录流水线继续遵循用户已明确的“不实现”决定。 |
| 上游前端拆分、宿主／状态容器、品牌及图标 | 不整体移植，不覆盖 MSW 的工程模型、模块和发行素材。macOS 英文快捷键提示只作常规检查，当前没有据此确认新的产品缺陷。 |

## 下一阶段建议与验证边界

1. 若目标只是吸收这个 beta 中适合 MSW 的改进，当前已完成主要功能筛选与实施；下一步应对当前分支做整体验收，而不是为版本号补入无需求功能。
2. 若希望再扩展，建议先单独讨论完整断句标点设置；独立复核标记和句内局部样式继续暂缓。它们不是这次跟进的必备条件。
3. 本轮没有重新运行产品测试、真实模型推理或三平台打包。此前回归详见各任务记录；真实 macOS MPS 推理、GB 级模型下载及包含精选改进的新安装包，不因本轮代码复核而视为已验收。
4. 本轮文档检查：UTF-8、LF、末尾换行、相对链接及 `git diff --check`。未修改产品实现、版本、工作流或发布说明；没有创建标签或 Release。
5. 原有 `debug.log`、`.test-appdata/`、`output/` 和 `tests/test_data/_msw/` 保留；`main` 保持原位置。本轮评估记录按仓库既有授权提交至 `my-feature`，不代表实施上述可选功能。
