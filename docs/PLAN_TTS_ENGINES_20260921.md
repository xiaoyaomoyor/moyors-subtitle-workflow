# 编辑器 TTS 多引擎扩展实施方案（精简修订版）

初稿：2026-09-21；修订：2026-09-27。修订核查基线：`0617050`，分支 `my-feature`，保留工作区其他未提交改动。

本文记录修订规划与已授权阶段的实施进度。本文替代初稿的“覆盖全部公开能力”要求；下述 A–G 是 **TTS 扩展自己的阶段**，与已经完成的编辑器音量／ASR／翻译 A–F 无关。

## 1. 修订结论与范围

目标改为：**参考本地 GAG 的日常推理工作流，提供模型／音色选择、参考配音、常用声音控制、预设、批量合成，以及本机服务的按需启动。** 不以暴露供应商全部接口或模型全部推理开关作为验收条件。

保留七个引擎的目标：已有百炼、油库里、IndexTTS；新增 MiniMax、Mossland、GPT-SoVITS、Edge TTS。用户提到的“GPT-SoVIST”统一采用正式名称 GPT-SoVITS。已有功能和旧素材配方继续兼容，不因本次精简删除。

本次新增确认：

- GPT-SoVITS **和 IndexTTS** 都支持在 MSW 编辑器内检测、启动、查看状态和停止由 MSW 启动的服务。
- 已运行的兼容服务直接连接；未运行且安装位置有效时，用户可点击“启动服务”，或点击“启动并合成”完成同一次操作。
- 配置目录不意味着一打开工程就加载模型。保存设置、切换引擎、展开面板不自动启动；首次实际操作无需再要求用户前往外部终端。
- 模型训练、模型下载、环境安装和升级仍由原工具处理；MSW 使用已有安装与模型。

结果继续走现有流程：操作对象 → 冻结本次配方 → 合成记录 → 素材库 → 贴片／补齐字幕 → 保存与导出。复用已有草稿分段、试听、素材管理，不复制一个独立的 GAG 窗口。

## 2. GAG 与本机安装的核查依据

已找到本机 `GAG_v0.4.3.exe`，读取 `GAG_config.json` 的字段结构，未输出个人参考路径、台词或配置值。公开主程序也标注 v0.4.3；本轮未运行可执行文件，公开源码不能证明本机二进制逐字一致。

本地预设包含：GPT／SoVITS 模型、主／辅助参考、参考台词、参考语言、生成语言、语速、切句、无参考文本选项，以及采样、批处理等参数。顶层配置包含 API 地址、解释器、自动启动和批量合成设置。

公开源码补充核对：GAG 有语音合成、API 管理、批量合成三个页面，提供模型切换、预设与试听；API 管理有启动／停止和自动启动选项。MSW 参考其功能粒度，采用自己的界面和按需启动时机。[GAG 主程序](https://github.com/AliceNavigator/GPT-SoVITS-Api-GUI/blob/main/gsv_api_gui.py)、[合成界面](https://github.com/AliceNavigator/GPT-SoVITS-Api-GUI/blob/main/GAG_tools/tts_gui_tab.py)、[API 管理](https://github.com/AliceNavigator/GPT-SoVITS-Api-GUI/blob/main/GAG_tools/api_manager_tab.py)、[批量合成](https://github.com/AliceNavigator/GPT-SoVITS-Api-GUI/blob/main/GAG_tools/batch_tts_tab.py)。

### 2.1 MSW 如何取舍

| 类别 | MSW 规划 |
| --- | --- |
| 模型组合、音色／参考、参考台词和语言、生成语言、语速、切句 | 常用区直接提供，按引擎能力显示 |
| 预设保存／选择、参考试听、批量执行、失败项重试 | 复用现有 MSW 工作流，补齐新引擎适配 |
| GPT 辅助参考、无参考文本、Top K／Top P／温度／种子／重复惩罚 | 放默认折叠的“高级参数”；模型不支持时不发送 |
| GPT 采样步数、音频超分 | 只在实际支持的模型族中显示于高级区 |
| batch size／threshold、分桶、并行推理、片段返回、传输分块 | 适配器内部兼容默认值；不增加普通用户控件 |
| GAG 自身波形、裁剪、输出格式、批量文件列表 | 使用 MSW 的波形／参考选段、导出面板和批次记录，不再实现一套同类模块 |
| GAG 随程序启动 API | 转为 MSW 实际合成时按需启动，避免打开编辑器就占用显存 |

“高级”只保留少量确实影响声音、随机性或质量的选项，不设置任意 JSON／任意启动命令输入框。表中为 MSW 的取舍，不表示 GAG 只具有这些能力。

### 2.2 两个本机服务

| 引擎 | 本次只读核查结果 | 实施基线 |
| --- | --- | --- |
| GPT-SoVITS | 安装包具有 `runtime/python.exe`、`api_v2.py`；入口支持绑定地址、端口和配置文件；有 `/tts` 及 GPT／SoVITS 权重切换接口 | 启动原生 API；使用 MSW 自有运行配置副本，模型选择串行化 |
| IndexTTS | 嵌套安装目录内具有 `.venv/Scripts/python.exe`、`webui.py`；入口支持 host、port、模型目录、版本和情感模型开关 | 启动现有 2.5 WebUI 所提供的 Gradio 服务，沿用 MSW 已实现的协议，不假设存在统一原生 REST API |

IndexTTS 的安装根目录存在多层同名目录，检测应在有限层级内定位“入口脚本＋解释器”，显示解析后的实际位置；不能要求用户猜哪一层才有效，也不递归扫描整盘。两个解释器都已确认存在；**未验证本轮启动或实际推理成功**。个人绝对路径不写进仓库或工程。

## 3. 界面与配置分工

### 3.1 TTS 面板

沿用现有宽度、关闭按钮、两列字段背景和图标。长说明放字段名后的 ⓘ；窄窗降为单列，内容在面板内滚动。

```text
操作对象                  引擎
模型／模型组合            配音预设
音色／参考                生成语言
语速等常用控制            情绪（有支持时）
参考台词及参考语言（参考配音引擎）
▸ 高级参数
本机服务状态与启动操作（仅本机服务）
                    保存合成设置  开始合成／启动并合成
▸ 合成记录
```

- 常用区先满足不展开高级区即可合成；没有模型或语言选项的引擎不留空字段。
- 参考台词等长文本占整行。参考试听播放已有文件，不能因选择音色自动生成试听。
- “保存合成设置”保存默认配方；“开始合成”使用当前草稿并冻结快照。保存设置不启动服务。
- 各引擎保留自己的选择；切换引擎不串用隐藏参数，应用预设不改动其他引擎。
- 合成记录沿用现有批次、取消、部分失败和重新生成流程。此轮不附带重做整个记录面板。

### 3.2 全局设置 → 环境配置 → TTS

保存 API Key、账号地域／服务地址、超时、本机安装目录、检测出的解释器、端口和启动配置。提供模型登记、参考资源管理和配音预设管理。

本机服务区提供“检测”“启动服务”“停止服务”、状态和折叠日志；TTS 面板保留同一服务的状态及快捷启动入口，不要求为日常启动跳转设置。

模型／音色、语言、语速、情绪、参考台词属于本次调用内容。已有 IndexTTS 的低频高级设置可以保持原入口；为统一体验迁移时只移动入口，保留旧设置值及预设，不能强迫旧素材改用新默认参数。

### 3.3 与现有生产流程衔接

- 沿用主／副字幕、选中／整轨、字幕编辑器独立草稿；手动换行与自动断句仍由现有草稿设置决定。
- GPT 的“切句方式”是单条请求内部的推理分段，不改变本批素材数量，也不能与 MSW 草稿分段混为一谈。
- 朗读修正只影响实际配音文字，字幕原文保持；不支持的音素／标记不能冒充通用能力。
- 引擎合成音量、试听增益和导出音量保持现有分工，不重复叠加，也不混用倍率、百分比、dB。
- 素材库重新生成只新增素材；贴片重新生成保留起点、使用完整新时长，三层超限不替换。
- 按原素材冻结配方重新生成；安装地址和凭据留在本机，缺模型／参考时显示重新关联提示。

## 4. 本机服务启动的统一设计

### 4.1 状态与入口

| 当前情况 | 界面与操作 |
| --- | --- |
| 已有兼容服务就绪 | 显示“已连接”；正常合成，不重复启动 |
| 尚未配置有效位置，服务也未连接 | 显示简短配置提示；不能伪装为可启动 |
| 配置有效、服务未运行 | 环境设置／面板均可“启动服务”；合成按钮可显示“启动并合成” |
| 启动或加载模型中 | 显示进度与折叠日志，禁用重复启动；可取消等待的合成 |
| 服务启动失败 | 保留当前配方，显示原因与重试／日志入口，不无限重试 |
| 地址被其他程序占用或接口不兼容 | 提示端口／协议冲突，不把 HTTP 可达当成模型就绪 |
| 服务由用户或其他工具启动 | 标注“外部服务”；MSW 可连接，但不提供终止外部进程的操作 |

“启动并合成”先冻结本次文本与配方，再确保服务就绪，最后提交一次。加载期间切换工程或取消任务，不能等服务启动完后继续提交旧工程。两窗口同时请求启动时合并为一次；同一服务只建立一条启动流程。

### 4.2 启动方法

1. 原生目录选择器登记安装位置；检测解释器、入口脚本、必要配置与模型文件。缺依赖时指向原工具，不自动安装或更新。
2. 后端用参数数组直接运行检测到的解释器，设置正确工作目录，隐藏控制台窗口。启动参数来自受控配置，工程文件不携带可执行命令。
3. GPT-SoVITS 使用 `api_v2.py` 的地址／端口／配置参数；为 MSW 生成配置副本，不覆盖整合包原配置。
4. IndexTTS 使用现有 `webui.py`，显式限定 `127.0.0.1`，模型版本匹配现有 2.5 协议；不打开额外浏览器，不启用公网分享。
5. IndexTTS 文本情感依赖的 `qwen_emo` 放环境配置的启动选项；缺模型时禁用相关模式。改变启动选项需重启自有服务后生效，不在每条合成时临时切换设备／精度。
6. 就绪检查验证协议、模型状态和必要能力，不用付费请求或正式合成来探活。GPT 不调用全局重启／退出接口充当健康检查。
7. 启动超时与单条合成超时分别处理；内存／显存不足、依赖缺失、端口占用及模型加载失败给出不同短提示。

### 4.3 进程归属与生命周期

- 记录自有进程的 PID、启动时间、服务类型、端口和配置指纹；停止前复核身份，避免 PID 复用造成误操作。
- 关闭 TTS 面板或浏览器页不停止模型服务；之后仍可在环境配置中停止。
- 明确退出 MSW 本机编辑器服务时，清理由该服务启动并持有的模型进程树；异常退出后先探测残留，不盲目新开第二份。恢复不了归属证据时只作为外部服务连接。
- 停止自有服务前，如有合成任务，提示停止会中断任务；确认后取消队列，再结束自有进程。单条取消不等于关闭整个模型服务。
- 切换引擎不擅自结束前一个引擎。可能同时占用显存时显示已有服务状态，用户可先停止闲置服务；不新建显存调度系统。
- GPT 全局模型切换与推理串行执行，冻结 GPT＋SoVITS 组合；任一权重切换失败不得继续使用不确定组合。外部客户端操作无法由 MSW 内部队列隔离，应在外部服务状态说明。

### A. 公共基础

- 整理小型引擎注册表，统一设置读取、能力、预检、调用与结果规范化。未知引擎明确拒绝，不默认落入百炼；不搭建通用插件框架。
- 只为保留的功能定义能力和配方字段；沿用历史 generation，必要时增加兼容版本。保存实际文本、模型、音色／参考摘要及生效参数。
- 收敛原有固定长度校验：至少按引擎显示合理限制，超限明确提示使用现有分段；不以长篇不限字数作为目标。
- 保留请求身份、取消、工程切换、失败重试、结果待确认和重生成。云端生成结果不明时不自动重复收费提交。
- 参考资源只登记必要信息和摘要；不新增跨引擎完整参考资源产品。结果用编辑器统一素材格式，转换失败不得入库为成功。

涉及：`maw/msw/tts.py`、`api.py`、`jobs.py`、`assets.py`、`project_codec.py`、`web/msw-tts.js`、`msw-tts-core.js`、素材库／贴片重生成、`JSON_SCHEMA.md`。按需要增加一个小型注册模块，避免先大拆重构。

验收：已有三引擎及旧工程可用；旧素材的冻结参数不丢失；切换引擎不串参数；凭据不进入工程、打包和日志。

### B. 本机服务管理

- 按第 4 节实现受控启动器、状态探测和自有进程管理；两个引擎各自适配命令与就绪协议。
- 首先连接现有 IndexTTS 流程：环境配置登记位置，面板快捷启动，合成前确保就绪；不改动已验证的 Gradio 参数顺序与取消机制。
- GPT 的检测／启动与模型状态基础同时完成，实际合成在 C 验收。
- 新增公共本机服务管理模块和引擎适配器；更新 TTS 环境配置、面板状态以及 IndexTTS 文档中“必须外部启动”的说明。

验收：服务已运行／未运行、外部服务、嵌套安装根目录、带空格路径、启动失败、端口冲突、两窗口重复启动、任务取消、退出清理；只停止自有进程。Windows 隐藏后台启动不弹额外控制台。

### C. GPT-SoVITS

- 常用项和高级项严格按第 2.1 节范围实现；默认值来自当前安装包，避免按不同版本的网上示例硬套。
- 模型组合与参考保存为预设；加载预设后仍可调整本次配方。参考语言与生成语言独立，保留日语参考→中文等跨语言用法。
- 参考音频支持选择、试听及必要的范围裁剪，保留原文件。按实际模型路径检查参考时长、台词和语言；不能把“无参考文本”误称为“无需参考音频”。
- 支持的模型族才显示采样步数／超分，无参考文本等模式需实际核验；未安装权重不算已支持。
- 权重切换和推理使用服务级串行队列；辅助参考作为音色参考，不是多人对话。取消后拒收迟到结果。
- 生成完整可用音频后入库，使用原生 HTTP；不照搬 IndexTTS 的 Gradio 请求。

涉及：建议 `maw/msw/gpt_sovits.py`、协议适配、本机服务管理、相应前端字段与测试。

验收：当前安装包短音频、中文／日文与跨语言、主参考／辅助参考、预设、模型切换失败、队列及取消、两种重新生成。模型质量实听与接口通过分开记录。

### D. Edge TTS

- 固定兼容的依赖版本，环境配置提供联网／依赖检测，界面没有 API Key 输入。
- 音色列表可缓存、搜索及按语言筛选；暂时断网不清空已选音色。语言由音色决定。
- 提供语速、音量、音高；使用库允许的单位和范围，转换为编辑器素材。
- 网络分块收集属于内部实现，完成后才试听／入库；不新增流式试听界面。边界信息若可可靠获得可留存，但逐字时间码不是本轮验收要求。

验收：主副字幕／草稿、常用中英日音色、取消与断网、批量及两种重生成、导出。Edge 是在线服务，不标成离线引擎。

### E. MiniMax

- 环境区配置账号地域／连接与 Key；面板选模型、已有音色，搜索或填写音色 ID。
- 常用项限制为第 5 节范围；发音修正先复用实际朗读文字入口，不搭建独立词典管理器。
- 处理正常音频返回、下载／转格式、鉴权／额度／限流和业务错误；返回 URL 不成为工程的永久音频地址。
- 保存实际生效配置，素材重生成不依赖当前面板。已有账号音色失效先提示，不擅自换声音。

验收：实际支持的常用控制、已选音色、批量部分失败、结果待确认、素材与贴片重生成；无需完成高级音色创建接口才算此阶段完成。

### F. Mossland

- 核实当前云端单人配音契约；将产品展示名、请求模型与版本分开，不能套用本地 MOSS ASR 或开源研究模型参数。
- 选已有音色／登记 ID；若用户使用参考音频且接口要求先创建 voice ID，提供必要的单次创建和登记状态。
- 后端需要异步轮询时内部实现任务 ID 持久化与恢复，不给用户增加“同步／异步协议”选项。
- 输出完整音频后入库；无可靠对齐信息就作为整句／整块素材，沿用现有补齐字幕规则。

验收：单人配音、必要的音色登记、任务恢复／取消、失效音色和下载地址、两种重生成。原生多人对话与声音设计不影响本阶段验收。
