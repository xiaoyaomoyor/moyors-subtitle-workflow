## A　依赖安全

使用 uv 0.13.6 重新锁定，解析到 certifi 2026.10.23、urllib3 2.8.0、hf-xet 1.8.0。核对 PyPI 的 pip 26.2.2 wheel 哈希，Windows 与 Unix 托管安装均按该包引导。通过 hf-xet 发行标签核对其锁定的 rustls-webpki 0.103.16 和 webpki-root-certs 1.0.10，沿用现有 Hugging Face 和 ModelScope 链路。

主锁校验通过。本地 ASR、OCR 和 MOSS 清单重新生成并确认安全版本。Windows 可安装、导入四个安全版本，既有 Hub 客户端识别并能构造相同的 Xet 下载参数，使用新依赖访问 PyPI HTTPS 接口通过。运行环境、对齐模型及打包契约单元测试 87 项通过。运行环境清单版本为 9、3、4，旧清单会提示在现有入口升级。

## B　播放与工具

- 原生播放器事件、逐帧刷新和音频任务共用空隙定位守卫。虚拟音频时钟负责自身跳转。
- Launcher 自动路径实际变化时清除旧错误，保留手动路径。
- 多句表情包引用跟随各自字幕区间。显式延长及旧工程已存的连续时间保留。
- 标准拆分模式恢复列表来源的切点闪标，沿用波形切点和忍者模式动效。
- Chromium 九项通过，覆盖重复定位、配音保护、路径联动、多句表情包、列表与波形 B 键、波形右键及撤销重做。真实 WAV 播放只发起一次 seek，并越过空隙继续播放。

## C　正文时序与查找

迁移到当前工程时，轻度空白、标点漂移下可通过一致的正文字符重新匹配字词时间。查找结果按字幕缓存正文处理，应用前仍重新检查工程现状、锁轨和草稿来源。6,000 条字幕用例改单条时只调用一次正文处理。

## D　字体兼容

在服务端渲染时解析字体别名。Windows 实测 ArialMT 解析到 Arial，度量一致，预览字体清单可加载。ASS、预览文件来源和排版度量复用同一规则。精确字体族名优先，歧义保持原名，旧工程保存值不变。macOS 额外发现指定 MobileAsset 字体目录。
