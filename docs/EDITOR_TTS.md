# 编辑器 TTS 与素材库

从启动器打开 MSWE Server 编辑器，在「媒体 → TTS」配置百炼服务。北京和新加坡使用不同密钥；北京可以复用本机的 `DASHSCOPE_API_KEY`。密钥只保存在本机配置中，工程、任务记录和导出包不包含密钥。

同一窗口也可切换到[油库里（本地）](EDITOR_YUKKURI.md)，支持中英文、八音色和语速调节；资源可在线安装或从离线包加载，不需要 API Key。以下云服务参数与计费提示仅针对百炼。

## 选择与声音设置

- 选中字幕时处理选区；没有选区时处理整轨。项目同时有主、副字幕时，全量处理前必须选择主字幕或副字幕。
- 选区涉及连锁字幕时必须选择主／副对象，同一绑定只合成一次。混合选区里的独立字幕仍按原选区合成，未绑定副字幕可以独立配音。
- 空白文本跳过。单条上限 600 字符，超长时请先拆分；提交前显示实际数量，不会静默把空选区误当成全部字幕。
- 支持 Qwen3-TTS-Flash、Instruct-Flash 和列出的快照模型。音色可以输入百炼系统音色 ID；不同快照的音色兼容范围以[官方音色表](https://help.aliyun.com/zh/model-studio/qwen-tts-voice-list)为准。
- Instruct 模型支持声音描述及指令优化，可用中文或英文描述语速、情感和语气。应用限制 1600 字符，仍须符合百炼 1600 Token 限制。普通 Flash 不发送这些参数。语言应尽量与文本一致，多语言可选 Auto。

点击「开始合成」后可继续编辑。来源文本和时间在提交时固定，生成的音频保留完整时长，不会跟随后续字幕编辑变化，也不会自动裁剪到字幕长度。两种引擎的音频均可拖入波形显示器成为[音频贴片](EDITOR_AUDIO_CLIPS.md)，再[导出配音轨或原声混音 WAV](EDITOR_AUDIO_EXPORT.md)。

## 素材库

「窗口 → 显示窗口 → 素材库」可调出面板。首次产生结果和任务结束后自动显示；隐藏的面板插入布局右下区域，已停靠的面板保留位置。窗口支持原有的标签组合、拖动、关闭和布局保存。

素材按生成批次整理，可以搜索文本、音色或模型，每页最多 90 张卡片，列表内可滚动。默认每行三张，在「媒体 → 设置 → 素材库设置」用滑条调整为 1–5 列，也可右键素材库选择「素材库设置」切换密度；面板上不再占用一行设置。设置显示期望列数，窗口过窄时自动减少实际列数。密度保存在当前浏览器，不进入工程。卡片文字最多两行，完整文本及音色、时长、来源等信息可悬停查看。

卡片底部依次为播放／暂停、下载 WAV、放入时间轴、删除素材图标，支持键盘焦点与悬停提示；也可拖动卡片放置贴片。共用一个播放器，每次只加载一条音频。试听会暂停原媒体，原媒体开始播放会暂停试听，避免同时出声。超过来源字幕时长的素材显示「长于字幕」。

删除已被贴片使用的素材时，确认框说明受影响贴片数量；确认后同时移除素材及其所有贴片，可以一次撤销／重做。工程保存删除记录，重新打开或刷新后台结果不会重新加入已删素材。此操作移除当前工程引用，保留原始导入文件、已有 WAV 和缓存，供撤销、恢复历史和既有导出任务使用；不会立即回收磁盘空间。

「导入音频」位于「导出工程与 TTS 音频」之前，支持多选 WAV、MP3、FLAC、M4A、AAC、OGG／Opus，每次最多 100 个文件，每文件最多 32 MiB。标准 PCM WAV 直接验证；压缩／浮点音频使用本机 FFmpeg 转为 48 kHz、双声道 PCM WAV。解码结果也须小于 32 MiB，超限或损坏会报告失败，不导入截断音频。「停止后续导入」在当前文件结束后停止批次，编辑器仍可继续使用。导入结果以文件名作为卡片及贴片文字，不自动转写；和 TTS 音频一样支持试听、贴片、保存与导出。

单工程最多登记 10000 条音频，提交前会核对现有素材与排队任务的容量。批次下拉展示最近 200 个批次；更早素材仍可以通过全文搜索查看。

每条音频可以导出 WAV；「导出工程与 TTS 音频」生成 ZIP，解压后打开 `project.mosp`。包中包含字幕工程和当前素材库全部音频（含外部导入且未放置贴片的音频），原视频仍沿用工程的媒体引用。

已绑定本机工程时，保存会把音频复制到同目录的 `msw-<工程身份摘要>.assets/audio/`，先保存素材，再写工程。移动工程应同时移动该 `.assets` 文件夹。未保存工程的生成结果先保存在本机应用数据目录，可通过 ZIP 导出带走。单独下载 JSON 工程只含相对路径引用，不含音频字节。

「文件 → 另存为工程」也会自动收集 TTS 音频，可选同时收集原视频／音频；成功后继续保存到新工程。另有素材完整性检查与本机恢复记录，详见[工程保存与恢复](EDITOR_PERSISTENCE.md)。

音频不可变，字幕撤销／重做不会删除素材或重新请求云端。丢失文件时保留工程引用，可恢复原 `.assets` 文件夹后重新试听。纯便携 HTML 没有本机处理服务时保留素材元数据并显示能力限制；请用本机 Server 打开工程来合成和试听。

## 任务恢复与重试

TTS 窗口底部的「合成记录」可收起，展开后通过内部滚动条查看全部记录；合成按钮仍位于外部。导出音频、视频和配音剪辑工程的「导出记录」采用相同布局，刷新进度时保留收起状态及滚动位置。

每生成一条，立即下载并验证 WAV，再登记到素材库；云端临时下载链接不写入工程。成功项可在后续字幕仍处理时试听。失败、取消或服务重启不会删除已成功的音频。

点击「检查未完成项」查看错误，再按需重试。请求超时或取消不能保证云端没有处理，重试可能再次计费，因此不会自动重发。重新打开相同工程与服务器端口可以查看任务记录；素材独立登记，在其他端口也可按工程身份恢复。旧工程应先保存生成的工程身份，方便重开后关联。

「WAV 音频不完整」表示云端已返回音频，但本地文件校验失败，与 API Key 留空不同。生成音频若使用常见的流式长度占位值，编辑器会在下载结束后按实际采样数据补全 WAV 头，再保存和计算时长；普通声明长度不符或采样帧缺失仍会拒绝，并显示长度详情。旧版本校验失败的下载没有保留，更新后需重启本机编辑器服务，再手动重试未完成项；仅刷新网页不会更新后端。

本实现使用 [Qwen-TTS 非实时 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-tts-api)，不把实时 API 独有的音量、采样率或语速滑块混入非实时请求。后续引擎可通过独立适配器接入同一任务与素材边界。
