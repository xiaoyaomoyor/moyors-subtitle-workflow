## 实施与验证记录

- 初始检查：工作分支与评估基线一致。编辑器已有自动／软件／硬件编码选择和 CPU 回退；画质、速度、AAC 码率仍为固定值，启动器手动压制仍使用固定软件编码。
- 高级选项采用紧凑的可展开区域；默认保留现有质量、速度和 192kbps 音频。自动模式下修改视频质量／速度应触发重新编码，避免直接复制画面后忽略设置；只改音频码率不强迫视频重编码。
- 编码基础与取消测试 24 项通过。首轮综合 Python 启动配置不正确（未加入 tests 模块路径、全局 FFMPEG_PATH 干扰夹具），另有本机网络探测受限；修正隔离启动后执行 423 项，2 项错误、1 项条件跳过。两个错误均是已有媒体夹具仍传入非接口值 `cpu`，现改为现用软件编码值 `h264`，保持动画／音画时序断言。
- 首次浏览器启动被本机权限限制阻止；使用允许的隔离浏览器重跑，32 项中 30 通过、2 失败。编辑器真实输出与快照、直接复制／重编码区别均通过。启动器发现旧 `applyBatchModeLocks()` 调用已无定义，实际点击压制会中断；删除失效调用并补页面错误断言。另一项为旧设置导航测试遗漏已有“配置管理”，更新完整七项列表断言。
- 已检查编辑器参数区截图；两端后续复测、英文与小窗口检查继续进行。
- 编码阶段复测：媒体夹具两项及新增真实 SRT 样式压制共 3 项通过；浏览器失败两项、启动器工具入口及英文小窗口共 4 项通过。原 32 项浏览器去重全部通过；已查看编辑器、启动器参数区截图。新值 `23 / fast / 128kbps` 在真实编码与 CPU 回退中保持，音频码率单独修改保留画面直接复制。当前设备检测并完成 Intel Quick Sync 真实编码；不宣称已实测其他厂商硬件。
- 波形 Node 70 项通过；首轮浏览器 25 项中 24 通过，包括普通／多行实际几何、边界反馈、跨行、磁吸及悬停。综合多轨流程在配音步骤超时；最初怀疑测试凭据，追踪实际响应后确认合成 Key 和音色均已就绪，首次字体／预览初始化与配置读取重叠超过旧 10 秒点击等待。测试改为等待配置就绪后再点击，仍使用原有隔离合成 Key，不改产品配音逻辑。附加旧空隙测试暴露共享服务的语言／折叠状态串扰（2 通过、3 失败、24 未运行），在每例建立明确状态，保持字幕过滤与撤销断言。
