## 验证记录

- XML 新增回归在修复前 3 项均失败：复现首段 31 帧而非 30 帧、长时间轴累积误差、短片段膨胀。修复后 `tests/test_editor_utils.mjs` 与 `tests/test_waveform_js.mjs` 合计 348 项通过。
- 初次运行完整 Node 测试因默认 `uv` 缓存路径不可写导致 XML 解析子进程失败；指定项目现有 `.venv` 为 `MSW_TEST_PYTHON` 后重跑通过。新测试中的副轨夹具亦已改为项目支持的 `multi_subtitle` 格式。
- 临时页面装配通过：新 `editor-utils.js` 与 XML 导出入口正确嵌入，没有重建根目录便携页面。浏览器连接隔离的本机编辑器，通过导出窗口实际下载 XML；第二／三媒体片段起点为 30／131 帧、终点 552 帧，字幕边界一致，页面运行错误为 0。最初浏览器与服务处于不同受限环境而无法连接，改在同一本机环境后通过。
- 最后补测发现极短保留区间与尾帧向上取整组合可能使媒体源出点多出一帧，已限制源范围并重新运行 348 项 Node 回归，全部通过。

## 取消修复范围与阶段验证

- `maw/gui_web.py`：取消事件与进程登记同步交接；界面调用不等待进程树终止；重复请求不重复派发；捕获当前进程，防止迟到的清理误用下一任务引用。
- `maw/postprocess_ffmpeg.py`：提前取消时不创建进程；注册／进度回调异常也清理子进程，关闭输出管道并释放资源。MSW 样式预设的媒体探测取消转换为启动器的正常取消结果。现有烧录、提取音频继续在取消时清除 `.part`，不覆盖源文件。
- 媒体重组经复核为独立同步入口，本轮不新增其取消功能。已更正原评估的范围表述；编辑器独立音视频任务系统保持原实现。
- 新增取消回归中，晚登记、锁交接及非阻塞返回三项在旧实现上均失败；第一轮使用未配置的进程模拟进行“提前取消”诊断未正常输出总结，随后修复为取消前直接检查，不创建进程。
- 初次相关 Python 回归受到临时目录和本机通信限制；固定隔离目录后 367 项中只剩 2 项本机健康探测失败。正常本机环境复核该探测测试类，4 项通过。
- 完整 Python 首轮执行 2347 项，95 项条件跳过，4 项失败来自 `MSW_ENV_FILE` 覆盖了旧测试只重置的 `MAW_ENV_FILE`，6 项错误来自 Windows GBK 解码 UTF-8 子进程输出。改用旧名隔离变量并启用 `PYTHONUTF8=1` 后，这 10 项定向复核全部通过。
- 第二轮完整 Python 只剩最近工程测试失败：复用了第一轮隔离目录中的 `guard.mosp` 测试登记。使用全新目录后，新增取消回归与整个工程登记测试类共 18 项通过；最终完整运行改用每次唯一的数据根。不修改产品或旧测试来掩盖环境残留。
- 最终代码的浏览器复核通过，实际下载仍为 30／131／552 帧；另核对极短片段输出 25 帧、源范围 5–30 帧，没有越过 30 帧的源文件。
