# ASR 与素材库升级实施计划

最初制定本计划时仅调整字幕悬浮提示。用户随后批准依次执行 A、B、C；现已完成，实施与验证见 `TEST_FEEDBACK_ASSET_LIBRARY_ABC.md`。D–G 的后续升级仍待执行指令。以 `my-feature` 为基线，保留已有外观调整。

## 已确认的产品决定

- 素材库统一容纳音频素材和字幕素材。
- **一条字幕一个卡片，同一次 ASR 或复制操作归入同一批次。**
- **字幕素材放回时间线时，从播放头开始，保留所选字幕之间的相对时间。**
- 字幕素材可在字幕编辑器中修改；音频素材支持多选导出和按原配置重新生成。
- 素材库重新生成只新增音频素材；波形音频贴片的重新生成维持现有替换行为。
- ASR 保留识别记录与每条记录中的预览，删除搁置与两种候选导出操作。

其余边界规则以下标为「建议」，作为执行方案的默认提案；不把这些提案记为用户已确认。

## 当前代码事实与改动方向

| 当前事实 | 需要修改 |
| --- | --- |
| `msw-asr.js` 与后端 `asr.py` 绑定源媒体，范围仅 whole/range | 引入贴片来源快照、裁剪音频读取、结果时间映射；不能只增加下拉项 |
| 素材列表、筛选、试听、下载都在 `msw-tts.js` 中 | 提取公共素材库控制器，使 ASR、复制字幕和 TTS 共用素材接口 |
| `msw.assets` 与前后端校验均只接受音频 | 新增字幕素材与批次契约，检查保存、恢复、另存为和撤销链路 |
| 字幕编辑器已有时间线编辑与 TTS 文本草稿 | 新增明确的字幕素材编辑目标，避免改到原字幕或误清空素材 |
| 已有音频重新生成配置与贴片替换逻辑 | 提取可共用的生成部分，区分「只入库」与「替换贴片」 |
| 现有 asset-bundle 导出的是工程及音频包 | 为多选音频增加独立导出入口，不把未选素材及整个工程混入 ZIP |

## B 阶段：素材库布局、设置与选择

状态：已修复。公共素材库、筛选与多选、数量提示及试听栏设置已实现。

1. 筛选行固定顺序为：**类型 → 批次 → 搜索 → 刷新**。类型为全部/音频/字幕；搜索同时覆盖字幕文本、配音文本、音色和外部音频文件名。
2. 批次选项随类型筛选；切换类型后若原批次不适用，回到全部批次。同批字幕按原时间排序，批次按创建时间排序，避免一批字幕顺序打乱。
3. 使用统一卡片底色与选区色描边，音频/字幕用类型图标区分；已有颜色标记保留并轻度着色。字幕首个操作按钮是铅笔，音频对应位置仍是试听。
4. 支持单击选择、Ctrl 切换选择、Shift 连选；按钮点击只执行对应操作，不意外改变多选范围。建议翻页保留选择，改变类型/批次/搜索时清空选择，防止操作到筛选后不可见的对象。
5. 显示筛选数量/总数及已选数量：全部模式使用「条素材」，音频使用「条音频」，字幕使用「条字幕」。
6. 把 `.assets` 提醒放在数量后面，窄宽度允许自然换行；生成/导入进度与失败信息仍使用独立状态位置。提示文案改为通用「工程与音频素材包」，与既有导出按钮名称同步。
7. 「素材库设置」增加「显示底部试听栏」，建议默认开启并记忆。关闭时隐藏底部整栏但保留卡片播放/暂停；切换设置不停止正在试听的音频，不影响时间线播放。
8. 公共素材库控制器负责列表/选择/试听，TTS 模块保留服务面板及生成任务。同步加载顺序、便携编辑器打包、国际化与用户文本防翻译规则。

主要文件：`web/msw-tts.js`、拟新增 `web/msw-asset-library.js`、`web/editor-template.html`、`web/editor.css`、`web/editor.js`、`web/editor-i18n.js` 及资源打包入口。

验收：三种类型筛选、分页多选、窄布局、暗亮主题和按钮键盘焦点正常；隐藏试听栏仍可在卡片停止播放；数量与提示不会挤掉操作按钮。

## C 阶段：字幕素材复制、编辑与放回时间线

状态：已修复。复制、独立编辑、插入/拖入、冲突处理与主副配对已实现。

1. 波形字幕块右键增加「复制到素材库」，遵循当前主/副字幕选择对象；多选一次复制形成一个批次。保留原字幕和系统剪贴板现有用途。
2. 单选字幕素材时，字幕编辑器加载对应文本；铅笔按钮聚焦编辑区域。显示清晰的素材编辑身份，避免和时间线字幕、TTS 草稿混淆。建议多选时不批量覆盖文本，保留单条编辑目标并显示多选状态。
3. 编辑前提交原目标未完成输入；切换素材、筛选、删除或打开工程时正确处理编辑目标。字幕素材修改不触发「TTS 合成后清除草稿」，也不改音频素材的原始合成文本。
4. 提供「放入时间线」，并支持素材卡片拖入波形；多选按钮插入以播放头为锚点，拖入以落点为锚点。
5. 计算方式：选中素材最早起点对齐锚点，其他素材按原相对间隔偏移。例如选中原 10–12 秒和 15–17 秒两条，播放头为 30 秒，则放入 30–32 秒和 35–37 秒。
6. 建议跨批次多选按保存的原时间统一计算相对间隔；不同源媒体的原时间不具备统一语义，跨来源批量插入应提示分批放入，避免猜测拼接顺序。
7. 建议复制素材恢复主副轨角色；找不到原副字幕轨时要求选择目标副轨，不自动落入主轨。ASR 字幕素材默认放入主轨。插入生成新字幕 ID，并正确重建所选范围内的颜色和配对引用。
8. 素材插入不等于 ASR 覆盖：建议与目标轨已有字幕或所选素材彼此冲突的条目全部跳过，其余插入，并列出原因；跨轨同时出现不算冲突。保留时间间隙，不自动压缩文本持续时间。
9. 插入为复制：素材继续保留，已插入的字幕不会被后续素材文字修改联动；一次批量插入可整体撤销。

主要文件：`web/waveform.js`、`web/editor.js`、公共素材库模块、字幕转换/插入核心逻辑。

验收：主副字幕复制、独立编辑、保存重开、单条/多条放入、拖入、颜色保留、冲突跳过与撤销；素材文字不能误写当前时间线字幕。

## D 阶段：ASR 识别所选音频贴片

状态：待处理。依赖 A；面板与结果展示接入 B。

1. 「识别范围」移至 ASR 面板第一个操作位置，选项为整个源视频/时间选区/所选音频贴片，保持两列布局及保存设置、开始识别顺序。
2. 贴片模式显示选择数量、总待处理用时及不可处理原因。没有选中贴片时禁用开始按钮；只有音频素材、没有源视频时仍允许贴片识别。
3. 每条贴片独立提取当前裁剪范围内的音频；同一素材被不同贴片引用时按各自裁剪分别处理。同一时刻重叠的贴片不混音后识别。
4. 建议识别使用素材原始音频及当前裁剪，不叠加试听增益/静音，也不受素材库试听速度影响。这样静音的贴片仍能识别。当前工程贴片播放速率固定为 1，未来若支持变速需同步补充映射契约。
5. 快照记录项目、贴片 ID、素材 ID/内容版本、裁剪样本范围、时间线起点和目标字幕。后端从项目合法素材读取，检查文件缺失、长度变化和越界，不接收任意本机路径。
6. 引擎结果首先按提取音频的相对时间保存；覆盖时间线时映射到贴片起点，入库则同时保存相对时间与原位置。严禁把素材裁剪起点再加到时间线起点上造成双重偏移。
7. 多选对应一个识别批次和多个可追踪子任务，显示进度、逐条错误及可用结果；部分失败允许保留已完成结果并仅重试失败项。沿用现有网络未知状态确认和防重复提交机制。
8. 对三个范围分别检查凭据与来源条件；切换项目时旧任务结果不能写入新工程。时间线期间被移动/裁剪的贴片，其结果仍可入原工程素材库，但直接覆盖必须重新检查快照。

主要文件：`web/msw-asr.js`、`web/msw-asr-core.js`、`web/editor-template.html`、`maw/msw/asr.py`、`maw/msw/api.py`、任务快照及素材读取接口。

验收：无源视频的贴片 ASR；不同采样率、非零裁剪与非零起点；重叠贴片分别识别；素材缺失、移动贴片、项目切换、部分失败及重试去重。

3. 存入素材库按用户确认的粒度拆为一条字幕一张卡片，以同次识别为一个批次；重复入库给予已入库反馈，不重复制造素材。结果为空时不创建空卡片或清空原字幕。
4. 覆盖的范围明确提示：整个源视频覆盖该视频范围内主字幕；时间选区只覆盖所选范围；贴片只覆盖所识别贴片的时间范围。多个不连续范围之间的原字幕保持原样。
5. 覆盖前显示受影响条数并验证任务期间字幕/媒体是否变动；保留现有颜色继承、主副绑定处理与副字幕需复核标记。一次应用作为一次撤销操作。
6. 建议边界切穿现有字幕时阻止覆盖并指出冲突，不直接删掉范围之外的字幕内容；用户调整原字幕或先存素材库。多个贴片的识别范围彼此重叠时，也暂不批量覆盖，允许全部存入素材库。
7. 「已应用」与「已入库」分别记录：允许入库后再覆盖、覆盖后再入库；删除搁置按钮不等于删除识别记录，也不立即销毁任务结果。历史结果继续遵循现有保留策略。

主要文件：`web/msw-asr.js`、`web/msw-asr-core.js`、`web/editor.js`、模板、国际化及 ASR 应用记录校验。

验收：三种范围均能选择去向；空结果、重复点击、分段间隙、字幕颜色、边界冲突和撤销恢复正确；被移除操作无残留入口。
