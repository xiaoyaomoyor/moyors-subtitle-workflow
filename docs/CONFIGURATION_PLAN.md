# 配置体系重整

独立配置文件使用 `名称.mswconfig`，内部为 UTF-8 JSON。以下是用户确认的六阶段范围，后续按此文档推进，不从上下文猜测施工顺序。

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| 1 | 配置盘点与规则统一：归属、默认值、保存来源、可导出性、生效时机及格式 | 用户偏好、工程内容、任务参数、机器环境与凭据明确分开 |
| 2 | 公共读写接口、浏览器／服务器／旧文件迁移、多窗口冲突 | 重启、换端口和浏览器后共享配置，个人设置不丢失 |
| 3 | 分类导入导出、校验、预设依赖、冲突预览和快照回退 | 可完整恢复，部分导入不波及其他分类，不导出密钥 |
| 4 | 配置管理与启动器／编辑器入口，整合旧工作区导入导出 | 不改坏工程、不中断任务，作用范围清楚 |
| 5 | 波形缓存统一、有效 quapeaks 优先、回退及冗余分析 | 不重复生成，兼顾损坏、多音轨及移动 |
| 6 | 新旧工程、预设、多窗口、浏览器、便携版与新环境全流程验证 | 可迁移、可恢复，工程预览及导出不变 |

## 归属与优先级

- 工程：字幕、绑定、轨道／单条样式、动画、位置、素材、空隙、播放头及项目恢复记录留在 `.mosp` 或原工程恢复存储；用户配置不能覆盖这些数据。
- 用户偏好：界面、操作、波形显示、预览偏好、工作区预设、用户样式库及处理默认值使用公共配置接口。浏览器存储作为离线缓存和迁移输入，不再作为本机服务器版唯一真源。
- 本次任务：媒体路径、选中轨道、识别／导出快照和任务队列不写入可迁移用户偏好。任务开始后继续使用自己的快照。
- 机器环境／凭据：工具与模型路径、服务启停信息、API Key 和账号音色资源保持专用存储；不通过浏览器配置迁移或普通配置导出搬运。环境变量的显式覆盖仍优先。
- 默认值由现有模块的规范化函数定义；缺省配置使用代码默认，不把某个工程的当前状态当成默认。

## 文件契约

内部库使用 `format: "msw-config"`、`version: 1`、`revision`、`sections`。独立导出文件使用同一格式与版本，加上 `kind: "preferences"` 和 `categories`，不导出内部修订／迁移记录。未知分类／未来版本拒绝写入。

用户库放在 MSW 应用数据目录的 `user-settings.mswconfig`。修改采用文件锁、原子替换与版本备份。客户端仅提交实际变更及原值：不同字段可合并，同一字段冲突明确拒绝，不用旧窗口的整份快照覆盖新设置。

旧数据只读迁移，保留原文件及浏览器原始快照；已经迁入的值不会被另一个端口的旧缓存覆盖。首次迁移、失败、冲突和离线边界须有自动化验证。
