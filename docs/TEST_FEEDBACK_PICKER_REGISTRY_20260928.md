问答与后续建议（本轮不扩展实现）：
- 期望时长：Moss API 支持 expected_duration_sec。MSW 当前 IndexTTS 服务适配的是 duration_factor 倍率，GPT-SoVITS 是 speed_factor，MiniMax／Edge／油库里是语速，百炼当前接口未提供同义的目标秒数，不能简单复制同一参数。真正的统一“适配字幕时长”可另做合成后保音高变速，与模型生成引导分开，不默认裁切或重复付费调用。
- Mossland 同排可设计“期望时长（秒）＋跟随字幕时长”：勾选后每条以自身 (end-start)/1000 秒计算，手动值禁用；提交时冻结到每条配方。主／副使用实际处理对象的时间；无字幕时长的草稿禁用跟随；超出合法范围明确提示，不能偷偷截断或取整批跨度。
- 所给 UUID 是音色 ID，模型 ID 是 moss-tts-1.5-flash 等。官方音色列表的 name 可以为空，MSW 当前以 ID 回退；手填共享音色若不在账号返回列表也无法取得名称。可增加本机别名，优先本机别名→平台名字→短 ID，完整 ID 放到详情／复制，不随意编造人名。
- 合成记录当前是标题＋状态＋按钮堆叠；“检查未完成项”只拉取并追加结果，没有反向折叠状态，确实是交互缺口。建议统一卡片背景与细描边；折叠箭头＋引擎名（MiniMax／Mossland／百炼等）＋批次序号在首行，右侧状态／成功数；音色名与模型放次行；未完成项做独立可逆折叠、记住状态、内部滚动，轮询不重置展开。失败简述一行、完整报错按需展开，按钮只保留当前状态必要动作。引擎不用大面积不同背景色，沿用主题卡片色，状态仅用小色标。
