# 平级字幕 v4：普通编辑器与数据契约

平级轨道已正式接入普通 MSWE 编辑器。原菜单、可停靠面板、设置和双栏卡片保持原样；文件菜单不再展示独立试用入口。每条字幕归属一个独立轨道，主／副只表示列表显示位置和工程样式槽，不再表示父子存储。

## 日常编辑

- 轨道头使用紧凑的 S1、S2 编号按钮，点击启用／禁用本轨道；右键分组、锁定、折叠或删除空轨道。轨道栏空白右键提供新增、展开折叠轨道和字幕样式窗口入口。编号不回收已删除编号。
- 直接拖动字幕块跨时间行／轨道，保留绑定与一次撤销；多选同栏字幕保持相对轨道间隔，锁定、同轨碰撞及绑定双方同轨会阻止放置。列表筛选收进右键“轨道”子菜单，编号保留选中高亮。
- 右键独立轨道选择“设为副轨道”，指定一个未分组的主轨道后显示 S1主／S1副。一组仅一主一副，不能嵌套；解除分组恢复各自原来的独立编号。分组只管理名称和样式，不移动字幕，也不创建或解除字幕绑定。旧工程中明确且唯一的主副轨对应自动迁入分组；新建翻译目标在来源只有一轨且可分组时自动组成主副轨。
- 卡片编号使用 S1主_1、S1副_1、S2_1；后缀按本轨道时间顺序计算。字幕编辑器下方显示 S1主字幕_1 等编号，不再重复显示顶部轨道名称。
- 自动排布仍按现有轨道次序避让同时出现的字幕；固定位置独立定位。轨道上下移动入口已移除，切换归属直接拖动字幕块。
- 绑定的一对字幕继续以原来的双栏卡片显示，沿用界面中的“绑定”名称；底层对应关系就是这份绑定。跨轨建立绑定后不会合并轨道。换轨仅移动所选字幕，绑定伙伴留在原轨，关系和时间差保留。
- 时间拖动、边界调整、切分和合并仍支持绑定联动；同轨防重叠和锁定检查保持。一次撤销恢复整个操作。
- B 展开联动切分确认，Ctrl+B 快速联动切分，Shift+B 单切并解绑。C 累加状态合并，Ctrl+Shift+C 共有状态合并；跨物理轨道不能直接合并，需先换轨。
- G 绑定不同轨道的两条所选字幕，先选的字幕作为参考；Shift+G 解绑，H 按参考字幕对齐。右键“绑定操作”提供反转绑定方向；对齐／新绑定若发生同轨碰撞或涉及锁定轨道，整次拒绝。Ctrl+C/V 复制粘贴，复制双方保留绑定。N、Ctrl 拖动和空白右键均可在指定空轨道创建字幕。
- 导入字幕可新增独立轨道，并与当前轨道的未绑定字幕匹配；替换只作用于指定轨道，其他轨道保留。字幕列表设置中的“交换两侧位置”仅对调卡片左右显示，不改变绑定方向、时间偏移、字幕内容、物理归属或轨道样式。
- 多轨始终可用，不再需要“启用多重字幕”。字幕编辑器设置管理实际轨道的文字切分方式及绑定偏好；波形设置统一管理行高和其他字幕轨道吸附（按住 Shift 才吸附）。旧禁用、隐藏状态继续保留。
- 媒体播放器的字幕样式工具栏左侧选择轨道组；主副组随后显示主字幕、交换外观、副字幕，独立轨道只显示组选择。预设、默认值和动画作用于当前组，字体等细节按当前一侧调整；交换外观保留双方位置。预览预设可独立于工程样式。“排布与画面位置”保留自动排布／固定位置及画面定位操作。

## 处理、保存与导出

原识别、翻译、配音、素材库、音频贴片和导出入口继续使用；服务环境也沿用本机配置。

- 识别明确写入启用且未锁定的目标轨道。原生识别范围目前不能穿过现有字幕边界，范围内已有绑定时应识别到新轨道，避免覆盖和静默解绑。
- 翻译可使用任何轨道的所选字幕；同时选择绑定双方时按左栏去重。译文默认沿用绑定目标，否则新建轨道，也可明确选择。候选需检查后应用；字幕内容、时间、绑定或目标变化时拒绝迟到结果。候选修订可再次应用，一次撤销恢复整批写入。
- 配音使用所选字幕的真实全局身份与物理轨道；素材、配音贴片及旧来源引用保留。历史来源通过迁移别名解析。旧 v3 识别／翻译候选不会冒充 v4 快照写回，可重新处理或存入素材库。
- 所有启用轨道参加精确字幕预览、ASS 及视频烧录。绑定自动轨道成组排布，固定位置按自身锚点处理。视频仍保留编码选择、范围对齐、跳过空隙、取消、进度与剩余时长；没有新增临时样式编辑。
- Ctrl+S、另存为、恢复草稿和恢复版本均使用 v4。旧工程首次原位升级备份原字节，普通保存继续保留上一版 .bak；另存为生成独立工程身份并收集配音素材。原媒体收集仍由原选项控制。
- 更新后需保存工程并等待任务结束，再重启本机服务、刷新页面。便携 HTML 可编辑和保存；识别、翻译、配音、精确预览和媒体渲染仍需本机服务。Launcher 的旧批处理不直接改写多轨工程。

旧独立试用页面保留为开发回归工具，可通过显式查询参数 flat-subtitles=1 访问，日常使用普通入口即可。显式 subtitle-tracks=1 保留 v3 兼容验收；它不能打开或覆盖 v4。

## 数据模型

顶层版本为 `msw.project.v4`，字幕模型为 `msw.subtitles.v1`。`subtitles.cues[*].content` 是唯一可编辑字幕正文；不再在根部保存 `segments`、`multi_subtitle`、`subtitle_tracks`、`subtitle_layers` 或 `overlay_track`。

```json
{
  "schema": "msw.project.v4",
  "media": "clip.mp4",
  "subtitles": {
    "schema": "msw.subtitles.v1",
    "tracks": [
      {
        "id": "track-a", "name": "原文", "purpose": "source", "layout": "auto",
        "enabled": true, "locked": false, "collapsed": false,
        "style": {"mode": "inherit", "slot": "main", "base": "dialogue"}
      },
      {
        "id": "track-b", "name": "译文", "purpose": "translation", "layout": "auto",
        "enabled": true, "locked": false, "collapsed": false,
        "style": {"mode": "inherit", "slot": "secondary", "base": "dialogue"}
      }
    ],
    "cues": [
      {"id": "cue-a", "track_id": "track-a", "content": {"start": 0, "end": 2000, "text": "Hello", "items": []}},
      {"id": "cue-b", "track_id": "track-b", "content": {"start": 100, "end": 2100, "text": "你好", "items": []}}
    ],
    "bindings": [
      {"id": "pair-a", "source_id": "cue-a", "target_id": "cue-b", "start_offset_ms": 100, "end_offset_ms": 100}
    ]
  }
}
```

### 轨道与字幕

- 轨道 ID、名称与字幕 ID 均为非空字符串，最多 160 个 UTF-16 单元。轨道与字幕的 ID 各自在工程内唯一；轨道数组决定顺序。没有父子轨道、隐式副轨或第二份轨道内正文。
- 普通编辑器补齐轨道 `display_number`（组编号，正安全整数）和模型 `next_track_number`（大于当前编号的正安全整数）。同组主副轨共享编号，不同组及独立轨不得重号；S1主／S1副后新增 S2，解除分组为副轨分配下一个编号。轨道 `secondary_for` 可选，引用组内主轨 ID；每条轨道至多参与一个二元组，不得自引用、成环或嵌套。`name` 由编号和分组生成；分组不决定 `bindings`、字幕归属或原有 `style.slot`。删除空轨时清理分组引用，保留伙伴的组编号。兼容旧 v4 逐轨独立编号和缺少字段的工程：规范化时让副轨使用主轨编号，仅回收连续的末尾副轨预留号，不改已有独立轨编号或删除轨道留下的预留号；已有编号的工程不会根据后来的字幕绑定重新推断分组。
- `purpose` 是可选用途的枚举，必须保存为 `none`、`dialogue`、`source`、`translation`、`annotation` 之一。它不决定绑定方向、操作权限或样式。`layout` 独立为 `auto`／`fixed`。
- `enabled/locked/collapsed` 必须为布尔值。`position` 可选，使用画面内的 `{x,y}` 比例；`language` 可保留旧语言轨标记。
- 可选 `split_mode` 仅接受 `auto`、`word`、`continuous`，缺省与 `auto` 相同。它控制文字切分计数、近似切点和合并连接符，不控制画面换行。旧主侧的 `multi_subtitle.main_split_mode`／顶层 `split_mode` 和语言轨的 `split_mode` 迁入对应物理轨道；浏览器还迁移旧本机主侧覆盖和旧 `subtitle_view` 两侧偏好。显式轨道值优先，左右显示交换不改变它。
- 每条字幕恰好归属一条轨道。同轨字幕不可重叠，边界相接合法；跨轨允许重叠，禁用字幕也占据自己的区间。
- 字幕 `content` 承载原文、整数毫秒时间、逐词时间码、可选帧时间码、颜色／表情包、说话人、字幕定位及未知扩展字段。旧 `id` 移到身份映射，其余字段不因新轨道字段而被覆盖；例如旧正文的未知 `track_id` 留在 `content.track_id`。
- 逐词条目按时间排列且位于字幕范围内；允许旧契约中的零时长词条。毫秒时间与成对帧时间均保留，不在迁移时重新量化。
- 字幕级 `hidden` 仅用于保留旧隐藏叠加组的显示状态，独立于 `content.disabled`。默认查询隐藏轨道／隐藏字幕会被过滤；`include_hidden/includeHidden` 可取全量内容。

轨道 `style` 沿用现有 `mode: inherit/snapshot`、`value`、`custom`、`selection` 契约，增加 `slot: main/secondary` 与 `base: dialogue/annotation`。这两个字段是旧样式的查找位置，不是字幕的存储身份或绑定限制。已有独立样式、注释样式、工程预设及位置完整保留，普通预览和输出按每条轨道的样式槽读取。

单条定位存入 `content.subtitle_position`，支持旧 `{x,y}`（组中心／顶部）和新 `{x,y,alignment}`（本条的 ASS 对齐锚点）。新格式还可有 `base:{x,y}`，仅用于从旧位置转换时保留原组的排布依据，不接受其他字段；base 只允许 x/y，不可嵌套。x/y 为 0–1 有限数字，alignment 为 1–9 整数，不能使用布尔值。新覆盖在基础排布完成后应用，不重新挤压未选中的绑定伙伴；两侧被实际选中时按相同位移分别保存锚点，不把它们叠到同一坐标。它不复制字体、动画或样式，也不改变绑定；修改轨道预设不会清除覆盖。删除字段恢复轨道排布。切分继承位置，合并保留本轨参与合并的最早字幕位置。ASS 预览和烧录共享锚点编译；SRT 忽略这些字段。旧编辑器不理解新锚点格式，需使用当前版本打开。

### 对应关系与引用

- `bindings` 仅表达明确建立的一对一关系。每条字幕至多参加一组，双方在不同轨道；不根据时间接近程度自动绑定，也不因换轨自动解绑。
- `source_id/target_id` 标识关系方向，不强制双方用途。可从任意一边建立关系。两个偏移分别等于目标字幕的开始／结束时间减来源字幕相应时间；不一致、重复端点、失效引用均拒绝。
- 底层 `move` 仅移动显式传入的字幕 ID；绑定另一侧留在原轨，关系保持。移动到同轨冲突、与绑定伙伴同轨或涉及锁定轨道时整次拒绝。普通编辑器换轨遵循所选对象；时间编辑仍支持绑定联动。
- 颜色／表情包引用由易变的 `headIdx` 转为 `cue_id`，直接指向含实际标记的字幕。字幕数组重排和换轨不改变引用；不允许失效、自引用、引用与头标记并存或循环引用。

当前仍保持一对一关系，未扩展为同一字幕同时绑定多个翻译目标；所有语言轨道及未绑定内容都会迁移，不会合并成单一副轨。

## 旧工程迁移

`migrate/migrate_project` 接受无版本／v1／v2／v3 工程。先复用既有 v3 迁移（生成缺失 ID、合并旧叠加内容、保留显示元数据），再按“旧显示归属＋原语言存储”拆成平级轨道。旧主字幕轨保留 ID；副字幕所在轨得到独立 ID。空主轨和空语言轨也保留。

每条旧字幕使用 `(role, track_id, cue_id)` 生成稳定的全局 ID；主副原 ID 相同也不会冲突。算法是 UTF-16LE 的 FNV-1a 64 位标识编码，**不用于安全校验**；发现碰撞立即拒绝，不合并字幕。新建字幕应由调用端分配不重复的稳定 ID，不再使用旧角色作为身份。

迁移结果附带 `subtitles.migration`：

| 字段 | 内容 |
| --- | --- |
| `schema` | `msw.subtitle-migration.v1` |
| `identities` | 新字幕 ID 与旧角色／存储 ID／字幕 ID 的对应；必要时保存被新标记引用占用的旧扩展字段 |
| `structure` | 旧结构配置快照；原正文数组改为新字幕 ID 列表，不保存第二份正文 |

迁移记录用于来源解析和兼容校验，不参与平级轨道的归属决策。旧配音素材、贴片、任务结果、缓存、媒体相对路径和预览配置保留；历史任务中的原文快照仍是历史数据，不是可编辑字幕真源。已删除字幕的来源映射可以保留，查询返回空，不以数组位置或同名字幕补配。

`resolveSource/resolve_source` 支持旧配音来源 `{id,track_id}`、素材库来源 `{source_cue_id,track_id}`，以及新显式引用 `{subtitle_cue_id}`。显式新引用失效时不回退到旧字段；纯配音草稿 `kind: editor_text` 不解析为字幕。普通编辑器及原生处理服务使用此接口解析配音来源。

### 兼容视图边界

`legacyProjection/legacy_projection` 用于生成可核查的 v3 视图。它会重新迁移并比对完整轨道、正文与关系，只有能无损表达时才返回。初次迁移可以精确还原规范化后的 v3；由该视图生成的 ASS 和精确预览与迁移前一致。

这是兼容验收工具，不是自动降级保存。平级轨道新增、独立换轨、关系变更等无法由旧来源结构表达的修改，或没有迁移来源的原生 v4，都明确拒绝还原。当前实现对原数组顺序也采用保守比对。v1 迁移沿用既有规范化，不承诺 JSON 字节相同；原文件备份保留原始字节。

## 接口与读写

| JavaScript | Python | 作用 |
| --- | --- | --- |
| `validate` | `validate` | 严格验证新字幕契约，不修补失效引用 |
| `migrate` | `migrate_project` | 纯迁移；再次迁移 v4 幂等 |
| `createIndex` | `SubtitleIndex` | 按稳定 ID 查询、查轨道、对应字幕和旧来源 |
| `addTrack` | `add_track` | 添加独立轨道，拒绝重复 ID |
| `move` | `move` | 按显式字幕 ID 原子换轨 |
| `bind/unbind` | `bind/unbind` | 原子建立／取消对应关系，保留内容 |
| `legacyProjection` | `legacy_projection` | 无损 v3 兼容视图，无法表达则拒绝 |

JS 模块为 `web/msw-flat-subtitles.js`，便携与本机页面提供 `MSWFlatSubtitles`；Node 可 `require`。Python 为 `maw.msw.flat_subtitles`。修改操作返回新对象，不改变传入工程；索引属于快照，编辑后重新建立。原生 v4 不要求 `migration`，可直接使用新 ID、平级轨道和关系。

独立读写模块 `maw.msw.flat_subtitles_io` 提供 `read_project`、`serialize_project`、`save_project`。默认命令只检查，不写文件：

```powershell
uv run python -m maw.msw.flat_subtitles_io "synthetic-project.mosp"
```

命令行实际写回需显式传 `--write-v4`。普通编辑入口已可直接打开、保存 v4。第一次升级在同目录创建短名称 `.msw-tracks-backup-*.mosp`，保存原 BOM、空白与换行等字节；工程写回原位置，不改变相对媒体和 `.assets` 目录。

两代轨道迁移工具共用互斥锁。写回前及原子替换前检查取消和原文件字节；检测外部修改就拒绝覆盖。备份／临时文件 fsync 或替换失败会保留原文件。忽略本工具文件锁的外部程序仍不可在最终操作系统替换瞬间并发保存。

独立 Python 读写工具拒绝重复 JSON 字段、非有限数值、无法在 JS 精确表达的整数、无效字幕结构和未来版本。v4 字幕契约与 JSON 可保存性由新模块验证；正式工程边界还会验证 msw 附属数据、媒体元数据、时间基准和预览设置。旧 codec 不能用旧快照覆盖磁盘上的 v4。

## 操作视图与处理边界
