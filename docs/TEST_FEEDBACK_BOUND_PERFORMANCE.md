## 边界

- 仍有全列表过滤、选择刷新与布局成本；100 对粘贴约 1.98 s、松手约 0.62 s，不能称为完全无卡顿。首次移动回调最大 118.4 ms，后续典型回调约 14 ms；本轮没有引入全面列表虚拟化。
- 使用基础 min/max 波形，没有测频谱着色层额外成本；测试预设的 Alibaba PuHuiTi 3.0 在隔离服务中提示缺失，前后都使用同一回退字体。没有据此宣称缺失字体本身已修复。
- 本任务只写独立副本。结束时原工程由其他会话发生变化（字幕数已从开始快照的 6166 变为 6158，播放头也改变），因此原文件末尾哈希不等于开始值；没有覆盖或回滚该文件。所有前后性能和数据验收均使用固定的 6166 条快照。
- 测试脚本早期的媒体重置、锁定后目标被编辑焦点重新选择、保存与草稿写入竞争，以及 `_dirty` 比较差异已分别修正测试流程；不是遗留产品失败。无本轮阻塞项。
