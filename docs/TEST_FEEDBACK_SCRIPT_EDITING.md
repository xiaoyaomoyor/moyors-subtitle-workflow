## 实现及操作边界

- `msw-find-text-tools.js` 生成含字幕身份、只读信息范围和正文范围的文档；`msw-find-script-editor.js` 保留原生整段选择／复制，拦截元信息修改并维护正文草稿撤销。装饰层只负责弱化信息颜色，与输入字体、换行及滚动对齐，不参与内容保存。
- 五项显示偏好保存在本机。复制范围是当前筛选结果，包含手工草稿；完整复制补齐隐藏信息，不改筛选范围，不把替换或文字整理预览当作正文复制。
- 外部完整回贴只修改正文，校验全部信息与顺序，失败时保留已有草稿。正文中含完整的整行结构标记可能导致边界歧义，此时拒绝整段回贴，可在对应单条正文内原样粘贴。
- 锁定、来源变更、草稿恢复、应用后一次撤销及真实服务保存继续复用原有事务；工程切换销毁旧编辑文档。信息显示开关不修改字幕数据。
