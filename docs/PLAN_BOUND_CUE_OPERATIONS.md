2026-10-26。本轮只定位和设计，不修改产品代码或用户工程。

## 统一规则（建议）

1. **轨道组、字幕绑定、参考方向、显示列相互独立。** S1主／S1副表示轨道分组；绑定表示两条字幕的关系；参考方向只服务“按参考字幕对齐”等明确有方向的操作，不能决定哪一边拖动才联动。
2. **拖动正文双向联动。** 从任意一端拖动，合并实际选区及其绑定伙伴，以稳定字幕 ID 去重，统一计算时间差与目标轨道。保持原来的主副时间差、长度、词级时间码和绑定；边缘手柄的时长编辑与正文平移分开。
3. **组到组按角色映射。** S1主→S2主，S1副→S2副；落在 S2 任意一端都识别为该目标组。不能按剪贴板第一条、内部显示列或点击顺序猜测。独立多轨内容按相对物理轨道关系整体映射；轨道不足或关系无法唯一对应时不猜、不拆散，也不自动创建轨道。折叠不能改变映射。
4. **复制按实际选区。** 完整选中一对时复制两条及内部绑定；仅复制一侧时，新副本为独立字幕，不绑定回原件，也不改变原绑定。“同时选中绑定字幕”继续只控制选区。复制允许读取锁定源轨道，移动和写入仍遵守锁定。
5. **粘贴落点明确。** Ctrl+V 以播放头为时间锚点，以鼠标当前所在轨道／轨道组为目标；鼠标不在有效波形轨道上时回退到明确的当前轨道，不使用过期鼠标坐标。保留所有块的相对时间差；重复粘贴创建新 ID，绑定只在本批新块之间建立。
6. **冲突整笔处理。** 任意目标锁定、缺失或实际被占用，整次操作不提交；不自动挤压原字幕，不把另一半留回原轨。拖动保持上一个有效候选位置，松手目标仍无效则整组回原位。失败反馈指出具体轨道和时间范围，不显示泛化的数据校验错误。
7. **手动绑定不影响移动方向。** 同组主副的默认对齐参考取主轨；普通轨道绑定保留明确参考关系。保留现有“绑定时自动同步时长”偏好，关闭时不改原时间差。已经互相绑定则不重复操作；涉及第三条的旧绑定不能悄悄替换。旧绑定不批量改写时间或主副列。
8. **外观与引用有明确归属。** 保留文字、说话人标记、单条样式／动画、禁用等内容；未单独覆盖的属性继承目标轨道。复制外部颜色／表情包引用时物化必要值，避免新块依赖源块下标；不擅自复制或移动 TTS 音频贴片。

## 界面与事务

- 沿用现有右键菜单与快捷键，不增加常驻面板或确认弹窗。
- 拖动显示整组半透明落点，能同时看到两端的目标轨道和时间；冲突端使用现有错误色，其他颜色沿用主题。Shift 吸附对整个操作只求一个时间差，不能让两端各自吸附。
- 粘贴成功选中新块并短暂高亮；正常成功不反复弹通知，真实失败才给简短气泡。
- 复制只读取选中内容与必要依赖；新轨道模型只走一份剪贴板流程。先提交正在编辑的字幕草稿；用户选中文字时的原生复制粘贴优先，不抢占输入框。
- 提取共用的操作计划：受影响 ID、原状态、目标轨道、共同时间差、绑定与引用映射、冲突结果。拖动预览和最终提交使用同一个计划，避免落点与结果不一致。
- 粘贴采用“新增字幕＋绑定”的局部历史，移动采用局部时间／归属历史；一次撤销完整恢复。一次投影／校验、一次提交，更新受影响卡片与预览，不为少量字幕复制整工程多遍。
- 空选区、空剪贴板、没有实际变化不创建撤销记录；剪切后的粘贴失败不丢剪贴板，仍可撤销剪切。

## 施工顺序与验收

1. **共用操作计划与双向绑定移动。** 先补从主／副两端、正／反选择顺序、同列／跨列、多组选中、折叠与锁定的回归；保留有意设置的时间差。修正跨组归属和整组预览。
2. **复制粘贴及轨道映射。** 覆盖 S1→已有 S2 组、从任意一侧指定目标、普通多轨、半对复制、重复粘贴、空目标／冲突目标、源块后来删除、词级与帧级时间码；一次撤销／重做，保存重开仍一致。
3. **性能和视觉收尾。** 接入局部新增事务与增量刷新；在约 6000 条字幕的独立副本测量复制少量、粘贴少量、批量复制、拖动开始／每帧／松手及撤销，记录真实耗时与快照大小。校验 ASS 预览、绑定样式及导出未改变。

本轮验证：Node 内存最小工程复现了两种错误落点，无原工程读写、无付费服务请求；产品代码未修改，完整浏览器及性能验收留到实施阶段。
