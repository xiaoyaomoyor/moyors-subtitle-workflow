## ASS 换行

- MSW 在视频坐标系测量换行，统一写入 ASS 的显式换行；`WrapStyle: 2` 防止渲染器再按播放器 CSS 宽度换行。保留自动适配画面和按字数换行两种现有规则。
- `test_subtitle_wrapping`、`test_msw_subtitle_style` 通过；Node 换行与说话人跟随用例共 14 项通过。
- 浏览器既有按字数用例通过，新增长句自动换行＋主副手动换行的 1440／960 窗口对照通过。两种尺寸均逐行比对 Chromium libass 与 FFmpeg 实际图像，行数一致、行位置误差小于 3 px，原工程正文未改变。
- 新测试首次因合成工程含 undefined、样式未通过正常接口应用、字体初始化等待不足而失败；修正夹具并等待渲染完成后通过。没有据此改动产品换行规则。

## 独立标记与日志日期

- 保留“标记字幕 → 独立标记”，从主／副一侧操作均解除目标绑定组的引用并保留当前说话人；未选组、原引用源及其他跟随者保持不变。Node 验证还覆盖锁定保护、跨显示侧引用、切分删除与稳定 ID。
- `speaker-follow.spec.mjs` 全部 7 项通过：包括右键菜单、实心／空心变化、单次撤销／重做、自动跟随、磁盘保存重开及 SRT／ASS 名称输出。补充独立标记保存重开和无关字幕不变的断言。
- 日志测试使用 `_now().timestamp() - 30 天`，与生产清理传入时钟一致，不依赖运行当天。现有按天滚动、旧文件清理、近期文件保留及每日只清理一次用例通过。
